# 

좋습니다. **1시간 수업**이라면 정규식 문법을 전부 다루기보다, 학생들이 실제 개발에서 바로 쓸 수 있는 패턴을 중심으로 **기초 → 검색 → 그룹 → 치환 → 검증 → 실전 패턴** 순서로 구성하는 것이 좋습니다.

아래 구성은 **비전공자·초보 개발자 기준 약 60분** 분량입니다.

## 파이썬 정규식 1시간 수업 구성

| 시간 | 내용 | 핵심 |
|---|---|---|
| 0~10분 | 정규식 개념과 `re` 모듈 | search, findall |
| 10~20분 | 기본 패턴 | `.`, `\d`, `\w`, `\s` |
| 20~30분 | 반복과 범위 | `*`, `+`, `?`, `{n,m}`, `[]` |
| 30~40분 | 그룹과 추출 | `()`, group, named group |
| 40~50분 | 치환과 분리 | sub, split |
| 50~60분 | 실전 검증 | 전화번호, 이메일, 로그, 파일명 |

# 1. 정규식이란?

정규식은 문자열을 하나씩 비교하는 대신 **문자열의 규칙을 표현하는 방법**입니다.

예를 들어 문자열에서 숫자를 찾는다고 할 때:

```python
text = "상품가격은 15000원이고 배송비는 3000원입니다."
```

일반적인 방법:

```python
for ch in text:
    if ch.isdigit():
        print(ch)
```

정규식:

```python
import re

result = re.findall(r"\d+", text)
print(result)
```

결과:

```text
['15000', '3000']
```

핵심적으로 정규식은 다음과 같습니다.

```text
문자열
   ↓
규칙(pattern)
   ↓
찾기 / 추출 / 검사 / 치환
```

# 10. 가장 중요한 기본 패턴

수업에서는 이것만 먼저 정리해도 충분합니다.

| 패턴 | 의미 |
|---|---|
| `.` | 임의의 문자 1개 |
| `\d` | 숫자 |
| `\D` | 숫자가 아닌 문자 |
| `\w` | 문자/숫자/_ |
| `\W` | `\w`가 아닌 것 |
| `\s` | 공백 |
| `\S` | 공백이 아닌 것 |

예:

```python
import re

text = "abc123 XYZ"

print(re.findall(r"\d+", text))
print(re.findall(r"\w+", text))
print(re.findall(r"\S+", text))
```

결과:

```text
['123']

['abc123', 'XYZ']

['abc123', 'XYZ']
```

# 19. `match()`와 `search()` 차이

초보자가 많이 혼동합니다.



이유:

```text

→ 문자열 시작 부분부터 검사

search()
→ 문자열 전체를 검색
```

실무에서는 보통 `search()`를 더 자주 사용합니다.

# 35. `.bat`, `.exe` 제외하기

조금 고급 예제로 적당합니다.

```python
import re

files = [
    "python.exe",
    "test.py",
    "start.bat",
    "image.jpg",
    "data.csv"
]

pattern = r"^(?!.*\.(exe|bat)$).+$"

for file in files:
    if re.fullmatch(pattern, file):
        print(file)
```

결과:

```text
test.py
image.jpg
data.csv
```

여기에서:

```text
(?! ...)
```

은 **부정형 전방 탐색(Negative Lookahead)** 입니다.

1시간 강의에서는 "이런 고급 기능도 있다" 정도로 소개하면 충분합니다.

# 36. Greedy 문제

고급 내용으로 한 가지 정도 보여주면 좋습니다.

```python
import re

text = "<h1>Hello</h1><p>Python</p>"

result = re.findall(r"<.*>", text)

print(result)
```

결과:

```text
['<h1>Hello</h1><p>Python</p>']
```

학생들은 보통 다음처럼 예상합니다.

```text
<h1>
</h1>
<p>
</p>
```

하지만 `*`는 기본적으로 최대한 많이 가져가려고 합니다.

이를 **Greedy**라고 합니다.

# 40. 로그 분석 예제

# 46. 실습 문제 5 — 개인정보 마스킹

다음:

```text
010-1234-5678
```

을

```text
010-1234-****
```

로 변환합니다.

정답:

```python
import re

phone = "010-1234-5678"

result = re.sub(
    r"(\d{3})-(\d{4})-(\d{4})",
    r"\1-\2-****",
    phone
)

print(result)
```

# 47. 수업에서 반드시 정리할 핵심

학생들에게 모든 문법을 외우라고 하기보다는 다음 정도를 기억시키는 것을 권합니다.

```text
\d      숫자
\w      문자/숫자
\s      공백

[ ]     문자 범위
[^ ]    제외

+       1번 이상
*       0번 이상
?       0번 또는 1번

{3}     3번
{2,4}   2~4번

^       시작
$       끝

()      그룹
|       OR
```

그리고 파이썬에서는:

```text
search()      하나 검색
findall()     모두 검색
fullmatch()   전체 검증
sub()         치환
split()       분리
```

정도로 정리하면 됩니다.

# 48. 수업 마지막에 보여주기 좋은 종합 예제

학생들에게 다음 데이터를 줍니다.

```python
data = """
홍길동,010-1234-5678,hong@test.com
김철수,010-9876-5432,kim@example.com
이영희,010-5555-7777,lee@gmail.com
"""
```

전화번호와 이메일을 추출합니다.

```python
import re

phones = re.findall(
    r"010-\d{4}-\d{4}",
    data
)

emails = re.findall(
    r"[\w.-]+@[\w.-]+\.[A-Za-z]{2,}",
    data
)

print("전화번호")
for phone in phones:
    print(phone)

print()

print("이메일")
for email in emails:
    print(email)
```

그리고 개인정보를 마스킹합니다.

```python
masked = re.sub(
    r"(010-\d{4})-\d{4}",
    r"\1-****",
    data
)

print(masked)
```

이 예제 하나에:

```text
검색
패턴
반복
그룹
추출
치환
```

이 모두 들어갑니다.

## 1시간 강의에서는 이 흐름을 추천합니다

```text
문자열
   ↓
정규식 Pattern
   ↓
┌──────────────┬──────────────┬──────────────┐
│ 찾기          │ 검증          │ 가공          │
├──────────────┼──────────────┼──────────────┤
│ search       │ fullmatch    │ sub          │
│ findall      │              │ split        │
└──────────────┴──────────────┴──────────────┘
   ↓
전화번호 / 이메일 / 날짜 / 파일 / 로그
```

특히 **AX 풀스택 과정 학생들**에게는 정규식 자체를 깊게 파는 것보다, `입력 검증 → 로그 분석 → 개인정보 마스킹 → 파일명 필터링`까지 연결해서 설명하는 편이 훨씬 효과적입니다. 이후 FastAPI의 Pydantic 입력 검증과 연결하면 정규식이 실제 백엔드에서 왜 필요한지도 자연스럽게 이해시킬 수 있습니다.
