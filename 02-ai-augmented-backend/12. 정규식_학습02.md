좋습니다. **1시간 수업**이라면 정규식 문법을 전부 다루기보다, 학생들이 실제 개발에서 바로 쓸 수 있는 패턴을 중심으로 **기초 → 검색 → 그룹 → 추출 → 치환** 위주로 구성하는 것이 효과적입니다.

아래 구성은 **비전공자·초보 개발자 기준 약 60분** 분량입니다。

## 파이썬 정규식 1시간 수업 구성

| 시간 | 내용 | 핵심 |
|---|---|---|
| 0~10분 | 정규식 개념과 `re` 모듈 | search, findall |
| 10~20분 | 기본 패턴 | `.`, `\d`, `\w`, `\s` |
| 20~30분 | 반복과 범위 | `*`, `+`, `?`, `{n,m}`, `[]` |
| 30~40분 | 그룹과 추출 | `()`, group, named group |
| 40~50분 | 치환과 분리 | sub, split |
| 50~60분 | 실전 검증 | 전화번호, 이메일, 로그, 파일명 |

# 1. 정규식이란?

정규식은 문자열을 하나씩 비교하는 대신 **문자열의 규칙을 표현하는 방법**입니다。

예를 들어 문자열에서 숫자를 찾는다고 할 때:

```python
text = "상품가격은 15000원이고 배송비는 3000원입니다。"
```

일반적인 방법:

```python
for ch in text:
    if ch.isdigit():
        print(ch)
```

정규식:

```python
import re

result = re.findall(r"\d+", text)
print(result)
```

결과:

```text
['15000', '3000']
```

핵심적으로 정규식은 다음과 같습니다。

```text
문자열
   ↓
규칙(pattern)
   ↓
찾기 / 추출 / 검사 / 치환
```

# 3. `search()` : 문자열에서 찾기

```python
import re

text = "Python programming"

result = re.search("Python", text)

print(result)
```

결과:

```text
<re.Match object ...>
```

찾았는지 확인하려면:

```python
if result:
    print("찾았습니다。")
```

# 4. 실제 문자열 가져오기

```python
import re

text = "Python programming"

result = re.search("Python", text)

if result:
    print(result.group())
```

결과:

```text
Python
```

위치 확인:

```python
print(result.start())
print(result.end())
print(result.span())
```

예:

```text
0
6
(0, 6)
```

# 5. `findall()` : 모두 찾기

수업에서 가장 먼저 익히게 하기 좋은 함수입니다。

```python
import re

text = "apple banana apple orange"

result = re.findall("apple", text)

print(result)
```

결과:

```text
['apple', 'apple']
```

# 6. 숫자 찾기 `\d`

`\d`는 digit, 즉 **숫자 한 개**를 의미합니다。

```python
import re

text = "Python 3 버전은 2026년에 사용되고 있습니다。"

result = re.findall(r"\d", text)

print(result)
```

결과:

```text
['3', '2', '0', '2', '6']
```

---

# 7. 숫자 여러 개 찾기 `\d+`

`+`는 **1개 이상 반복**입니다。

```python
import re

text = "상품가격 15000원 배송비 3000원"

result = re.findall(r"\d+", text)

print(result)
```

결과:

```text
['15000', '3000']
```

학생들에게 가장 먼저 다음 의미를 강조하면 좋습니다。

```text
\d     숫자 1개
\d+    숫자 1개 이상
```

# 8. 문자 찾기 `\w`

```python
import re

result = re.findall(r"\w+", text)

print(result)
```

결과:

```text

```

# 10. 가장 중요한 기본 패턴

수업에서는 이것만 먼저 정리해도 충분합니다。

| 패턴 | 의미 |
|---|---|
| `.` | 임의의 문자 1개 |
| `\d` | 숫자 |
| `\D` | 숫자가 아닌 문자 |
| `\w` | 문자/숫자/_ |
| `\W` | `\w`가 아닌 것 |
| `\s` | 공백 |
| `\S` | 공백이 아닌 것 |

예:

```python
import re

text = "abc123 XYZ"

print(re.findall(r"\d+", text))
print(re.findall(r"\w+", text))
print(re.findall(r"\S+", text))
```

결과:

```text
['123']

['abc123', 'XYZ']

['abc123', 'XYZ']
```

# 11. 문자 범위 `[]`

`[]` 안에 찾고 싶은 문자 범위를 표현합니다。

```python
import re

text = "abcABC123"

print(re.findall(r"[abc]", text))
```

결과:

```text
['a', 'b', 'c']
```

범위도 가능합니다。

```python
print(re.findall(r"[a-z]", text))
```

```text
['a', 'b', 'c']
```

영문 대문자：

```python
print(re.findall(r"[A-Z]", text))
```

숫자：

```python
print(re.findall(r"[0-9]", text))
```

# 13. 문자 제외 `[^ ]`

`^`가 대괄호 안에서 사용되면 **제외**라는 의미입니다。

```python
import re

text = "abc123"

result = re.findall(r"[^0-9]", text)

print(result)
```

결과：

```text
['a', 'b', 'c']
```

즉：

```text
[0-9]   숫자
[^0-9]  숫자가 아닌 문자
```

# 14. 반복 표현

정규식에서 가장 중요한 문법입니다。

|---|---|

```python
import re
```

# 16. `{n}` : 정확한 개수

```python
import re

text = "123 1234 12345"

result = re.findall(r"\d{4}", text)

print(result)
```

결과：

```text
['1234', '1234']
```

주의할 부분입니다。

`12345`의 앞 4자리도 매칭됩니다。

문자열 전체가 정확히 4자리인지 확인하려면 `fullmatch()`가 좋습니다。

```python
print(re.fullmatch(r"\d{4}", "1234"))
```

# 17. `{n,m}` : 범위 지정

```python
import re

result = re.findall(r"\d{2,4}", text)

print(result)
```

결과：

```text
['12', '123', '1234', '1234']
```

# 18. 시작과 끝 `^`, `$`

```python
import re

text = "Python programming"

print(re.search(r"^Python", text))
```

`Python`으로 시작하면 검색됩니다。

끝 검사：

```python
print(re.search(r"programming$", text))
```

개념은 다음과 같습니다。

```text
^Python

Python으로 시작

Python$

Python으로 끝
```

# 19. `match()`와 `search()` 차이

초보자가 많이 혼동합니다。

```python
import re

text = "I like Python"

print(re.match("Python", text))
print(re.search("Python", text))
```

결과：

```text
None
<re.Match object ...>
```

이유：

```text
match()
→ 문자열 시작 부분부터 검사

search()
→ 문자열 전체를 검색
```

실무에서는 보통 `search()`를 더 자주 사용합니다。

# 20. `fullmatch()` : 전체 문자열 검사

입력값 검증에서 아주 중요합니다。

```python
import re

value = "123456"

result = re.fullmatch(r"\d{6}", value)

if result:
    print("정상 입력")
else:
    print("잘못된 입력")
```

# 21. 전화번호 검증

실전 첫 번째 예제로 좋습니다。

```python
import re

phone = "010-1234-5678"

pattern = r"010-\d{4}-\d{4}"

result = re.fullmatch(pattern, phone)

if result:
    print("올바른 전화번호")
else:
    print("잘못된 전화번호")
```

패턴을 해석하면：

```text
010-
\d{4}
-
\d{4}
```

즉：

```text
010-숫자4자리-숫자4자리
```
