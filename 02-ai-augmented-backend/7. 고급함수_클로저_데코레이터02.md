좋습니다. 이 세 주제는 처음 배우면 서로 비슷해 보여서 헷갈리기 쉽습니다. 그래서 **“왜 필요한가 → 가장 단순한 예제 → 실제 프로그램 예제”** 순서로 설명하겠습니다.

## 07-2 클로저와 데코레이터

### 1. 클로저란?

클로저는 **함수 안에 만든 함수가 바깥 함수의 변수를 기억하는 구조**입니다.

가장 단순한 예제입니다.

```python
def outer():
    message = "안녕하세요"

    def inner():
        print(message)

    return inner


func = outer()
func()
```

출력:

```text
안녕하세요
```

중요한 점은 `outer()` 함수는 이미 실행이 끝났는데도 `inner()`가 `message`를 기억한다는 것입니다.

구조를 보면 다음과 같습니다.

```text
outer()
 ├─ message = "안녕하세요"
 └─ inner()
      └─ message를 사용

outer() 종료 후에도
inner()는 message를 기억
```

---

### 2. 클로저 예제: 할인 계산기

학생 할인과 VIP 할인을 각각 만들어봅시다.

```python
def make_discount(rate):

    def discount(price):
        return price * (1 - rate)

    return discount


student_discount = make_discount(0.1)
vip_discount = make_discount(0.2)

print(student_discount(10000))
print(vip_discount(10000))
```

출력:

```text
9000.0
8000.0
```

여기서 `student_discount`는 `0.1`을 기억하고, `vip_discount`는 `0.2`를 기억합니다.

즉:

```text
student_discount
    → rate = 0.1 기억

vip_discount
    → rate = 0.2 기억
```

---

### 3. 클로저 예제: 카운터

```python
def make_counter():

    count = 0

    def increase():

        nonlocal count

        count += 1

        return count

    return increase


counter = make_counter()

print(counter())
print(counter())
print(counter())
```

출력:

```text
1
2
3
```

여기서는 `nonlocal`이 중요합니다.

```python
nonlocal count
```

의 의미는:

> 바깥 함수에 있는 `count` 변수를 수정하겠다.

입니다.

# 4. 데코레이터란?

데코레이터는 기존 함수를 수정하지 않고 **기능을 앞뒤로 추가하는 기능**입니다.

예를 들어 다음 함수가 있습니다.

```python
def hello():
    print("안녕하세요")
```

실행 전후에 메시지를 추가하고 싶다고 가정합니다.

```python
def decorator(func):

    def wrapper():

        print("함수 실행 전")

        func()

        print("함수 실행 후")

    return wrapper


def hello():
    print("안녕하세요")


hello = decorator(hello)

hello()
```

출력:

```text
함수 실행 전
안녕하세요
함수 실행 후
```

---

### 5. @ 문법 사용하기

위 코드는 보통 다음처럼 작성합니다.

```python
def decorator(func):

    def wrapper():

        print("함수 실행 전")

        func()

        print("함수 실행 후")

    return wrapper


@decorator
def hello():
    print("안녕하세요")


hello()
```

다음 두 코드는 같은 의미입니다.

```python
hello = decorator(hello)
```

```python
@decorator
def hello():
    ...
```

---

### 6. 데코레이터 예제: 로그인 확인

웹 프로그램과 연결해서 생각하면 이해하기 좋습니다.

```python
is_login = True


def login_required(func):

    def wrapper():

        if not is_login:
            print("로그인이 필요합니다.")
            return

        func()

    return wrapper


@login_required
def mypage():
    print("마이페이지입니다.")


mypage()
```

출력:

```text
마이페이지입니다.
```

`is_login = False`로 바꾸면:

```text
로그인이 필요합니다.
```

이 개념은 FastAPI의 다음 문법을 이해하는 데도 도움이 됩니다.

```python
@app.get("/users")
def get_users():
    ...
```

`@app.get()`도 데코레이터입니다.

---

### 7. 매개변수가 있는 함수에 데코레이터 적용

실제 함수는 대부분 매개변수를 갖습니다.

```python
def log(func):

    def wrapper(*args, **kwargs):

        print("함수 시작")

        result = func(*args, **kwargs)

        print("함수 종료")

        return result

    return wrapper


@log
def add(a, b):
    return a + b


print(add(10, 20))
```

출력:

```text
함수 시작
함수 종료
30
```

여기서 중요한 것이:

```python
*args
**kwargs
```

입니다.

어떤 함수가 들어오더라도 처리할 수 있도록 만들어줍니다.

---

### 8. 실용적인 데코레이터: 실행 시간 측정

```python
import time


def timer(func):

    def wrapper(*args, **kwargs):

        start = time.time()

        result = func(*args, **kwargs)

        end = time.time()

        print(f"실행시간: {end - start:.5f}초")

        return result

    return wrapper


@timer
def work():

    total = 0

    for i in range(1000000):
        total += i

    return total


print(work())
```

이런 데코레이터는 성능 측정이나 로그 기록에 많이 활용됩니다.

# 07-3 이터레이터와 제너레이터

## 1. 먼저 반복 가능한 객체

다음 객체들은 반복할 수 있습니다.

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

리스트, 튜플, 문자열, 딕셔너리 등은 반복 가능한 객체입니다.

이를 **Iterable**이라고 합니다.

---

## 2. 이터레이터란?

이터레이터는 값을 하나씩 꺼내주는 객체입니다.

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

출력:

```text
10
20
30
```

한 번 더 실행하면:

```python
print(next(iterator))
```

다음 예외가 발생합니다.

```text
StopIteration
```

---

## 3. for문의 실제 동작

우리가 쓰는:

```python
for number in numbers:
    print(number)
```

는 내부적으로 대략 다음처럼 동작합니다.

```python
iterator = iter(numbers)

while True:

    try:
        number = next(iterator)

        print(number)

    except StopIteration:
        break
```

즉 `for`문은 내부에서 자동으로 `iter()`와 `next()`를 사용합니다.

---

## 4. 직접 이터레이터 만들기

1부터 5까지 값을 반환하는 클래스를 만들어봅시다.

```python
class Counter:

    def __init__(self, max_value):

        self.current = 0
        self.max_value = max_value

    def __iter__(self):

        return self

    def __next__(self):

        if self.current >= self.max_value:
            raise StopIteration

        self.current += 1

        return self.current


counter = Counter(5)

for number in counter:
    print(number)
```

출력:

```text
1
2
3
4
5
```

중요한 메서드는 두 개입니다.

```python
__iter__()
__next__()
```

---

# 5. 제너레이터란?

이터레이터를 직접 만들려면 코드가 꽤 복잡합니다.

제너레이터는 이를 쉽게 만들어주는 방법입니다.

핵심은:

```python
yield
```

입니다.

```python
def number_generator():

    yield 1
    yield 2
    yield 3


for number in number_generator():
    print(number)
```

출력:

```text
1
2
3
```

---

## 6. return과 yield 차이

일반 함수:

```python
def test():

    return 1
    return 2
    return 3
```

첫 번째 `return`에서 함수가 종료됩니다.

```python
print(test())
```

결과:

```text
1
```

반면 제너레이터는:

```python
def test():

    yield 1
    yield 2
    yield 3
```

각각의 값을 차례대로 반환합니다.

```python
for value in test():
    print(value)
```

---

## 7. 성적 데이터를 하나씩 반환하는 제너레이터

```python
def student_generator():

    yield {
        "name": "홍길동",
        "score": 90
    }

    yield {
        "name": "이순신",
        "score": 85
    }

    yield {
        "name": "김유신",
        "score": 95
    }


for student in student_generator():

    print(
        student["name"],
        student["score"]
    )
```

---

## 8. 대용량 데이터 처리

제너레이터의 가장 큰 장점은 모든 데이터를 메모리에 한꺼번에 만들 필요가 없다는 것입니다.

리스트 방식:

```python
numbers = [
    i
    for i in range(1000000)
]
```

100만 개를 메모리에 만들어 둡니다.

제너레이터 방식:

```python
def numbers():

    for i in range(1000000):

        yield i
```

필요할 때 하나씩 만듭니다.

```python
for number in numbers():

    if number > 10:
        break

    print(number)
```

즉:

```text
리스트
→ 데이터를 먼저 모두 생성
→ 메모리 많이 사용

제너레이터
→ 필요할 때 하나씩 생성
→ 메모리 절약
```

---

## 9. 제너레이터 표현식

리스트 컴프리헨션:

```python
numbers = [
    i * 2
    for i in range(10)
]
```

제너레이터 표현식:

```python
numbers = (
    i * 2
    for i in range(10)
)
```

차이는 `[]`와 `()`입니다.

```python
print(type(numbers))
```

출력:

```text
<class 'generator'>
```

# 07-4 파이썬 타입 어노테이션

## 1. 타입 어노테이션이란?

파이썬은 원래 변수의 자료형을 지정하지 않습니다.

```python
name = "홍길동"
age = 20
score = 95.5
```

타입 어노테이션을 사용하면 다음처럼 표현합니다.

```python
name: str = "홍길동"
age: int = 20
score: float = 95.5
```

의미는:

```text
name은 문자열로 사용할 예정
age는 정수로 사용할 예정
score는 실수로 사용할 예정
```

입니다.

---

## 2. 함수 타입 어노테이션

일반 함수:

```python
def add(a, b):
    return a + b
```

타입을 추가하면:

```python
def add(a: int, b: int) -> int:

    return a + b
```

다음 의미입니다.

```text
a     : int
b     : int
return: int
```

---

## 3. 성적 계산 함수

```python
def calculate_average(
    kor: int,
    eng: int,
    math: int
) -> float:

    return (
        kor + eng + math
    ) / 3


avg = calculate_average(
    90,
    80,
    70
)

print(avg)
```

코드를 읽는 사람도 어떤 데이터를 넣어야 하는지 바로 알 수 있습니다.

---

## 4. 리스트 타입

```python
scores: list[int] = [
    90,
    80,
    70
]
```

의미:

```text
정수들이 들어있는 리스트
```

문자열 리스트:

```python
names: list[str] = [
    "홍길동",
    "이순신",
    "김유신"
]
```

---

## 5. 딕셔너리 타입

```python
student: dict[str, int | str] = {

    "name": "홍길동",
    "score": 90
}
```

의미:

```text
Key
→ str

Value
→ int 또는 str
```

---

## 6. 반환값이 없을 때

```python
def hello(name: str) -> None:

    print(
        f"{name}님 안녕하세요"
    )
```

`None`은 함수가 값을 반환하지 않는다는 의미입니다.

---

## 7. None이 반환될 수도 있는 함수

```python
def find_student(
    name: str
) -> str | None:

    if name == "홍길동":

        return "학생을 찾았습니다."

    return None
```

즉 반환값은:

```text
str

또는

None
```

입니다.

---

## 8. 클래스에서 타입 어노테이션

```python
class Student:

    def __init__(
        self,
        name: str,
        kor: int,
        eng: int,
        math: int
    ) -> None:

        self.name = name
        self.kor = kor
        self.eng = eng
        self.math = math

    def total(self) -> int:

        return (
            self.kor
            + self.eng
            + self.math
        )

    def average(self) -> float:

        return self.total() / 3
```

사용:

```python
student = Student(
    "홍길동",
    90,
    80,
    70
)

print(student.total())
print(student.average())
```

# 세 가지 개념을 하나의 프로그램으로 연결

성적관리 프로그램에 모두 적용해보겠습니다.

```python
from functools import wraps


def log(func):

    @wraps(func)
    def wrapper(*args, **kwargs):

        print(
            f"[실행] {func.__name__}"
        )

        result = func(
            *args,
            **kwargs
        )

        return result

    return wrapper


class Student:

    def __init__(
        self,
        name: str,
        score: int
    ) -> None:

        self.name = name
        self.score = score


class StudentManager:

    def __init__(self) -> None:

        self.students: list[
            Student
        ] = []

    @log
    def add_student(
        self,
        student: Student
    ) -> None:

        self.students.append(
            student
        )

    def get_students(self):

        for student in self.students:

            yield student


manager = StudentManager()

manager.add_student(
    Student("홍길동", 90)
)

manager.add_student(
    Student("이순신", 85)
)

manager.add_student(
    Student("김유신", 95)
)


for student in manager.get_students():

    print(
        student.name,
        student.score
    )
```

이 프로그램에는 다음 세 개가 모두 들어 있습니다.

```text
@log
    ↓
데코레이터

yield
    ↓
제너레이터

name: str
score: int
-> None
    ↓
타입 어노테이션
```

### 세 개념의 차이를 한 번에 정리하면

| 개념 | 핵심 질문 | 핵심 문법 | 주요 목적 |
|---|---|---|---|
| 클로저 | 함수가 값을 기억할 수 있는가? | 내부 함수, `nonlocal` | 상태 유지 |
| 데코레이터 | 기존 함수에 기능을 추가할 수 있는가? | `@decorator` | 로그, 인증, 측정 |
| 이터레이터 | 데이터를 하나씩 꺼낼 수 있는가? | `iter()`, `next()` | 반복 처리 |
| 제너레이터 | 데이터를 필요할 때 하나씩 만들 수 있는가? | `yield` | 대용량 처리 |
| 타입 어노테이션 | 어떤 데이터가 들어오고 나가는가? | `: int`, `-> str` | 가독성, 오류 예방 |

특히 수업에서는 **클로저 → 데코레이터**, 그리고 **이터레이터 → 제너레이터**를 각각 한 묶음으로 설명하는 것이 좋습니다. 클로저를 이해해야 데코레이터가 자연스럽고, 이터레이터를 이해해야 `yield`가 왜 편리한지 이해하기 쉽습니다.
