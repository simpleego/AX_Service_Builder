
### 문제: FastAPI 세션 기반 장바구니 만들기

다음 조건을 만족하는 FastAPI 프로그램을 작성하세요.

사용자가 로그인하면 서버는 세션에 사용자 이름을 저장합니다. 로그인한 사용자는 상품을 장바구니에 추가할 수 있으며, 장바구니 내용도 세션에 저장되어야 합니다. 사용자가 `/cart`를 호출하면 현재 장바구니에 들어 있는 상품 목록을 확인할 수 있어야 하며, `/logout`을 호출하면 로그인 정보와 장바구니 정보가 모두 삭제되어야 합니다.

구현해야 할 API는 다음과 같습니다.

| 기능 | HTTP Method | URL | 설명 |
|---|---|---|---|
| 로그인 | GET | `/login?username=홍길동` | 사용자 이름을 세션에 저장 |
| 상품 추가 | GET | `/cart/add?item=노트북` | 상품을 장바구니에 추가 |
| 장바구니 조회 | GET | `/cart` | 현재 장바구니 목록 출력 |
| 로그아웃 | GET | `/logout` | 세션 전체 삭제 |

### 요구사항

`SessionMiddleware`를 사용하여 상태를 유지하세요.

로그인하지 않은 사용자가 `/cart` 또는 `/cart/add`를 호출하면 다음과 같이 출력하세요.

```json
{
    "message": "로그인이 필요합니다."
}
```

장바구니는 여러 개의 상품을 저장할 수 있도록 `list` 자료형을 사용하세요.

## 입력 및 출력 예시

### 1. 로그인

입력

```text
GET /login?username=홍길동
```

출력

```json
{
    "message": "홍길동님 로그인 성공"
}
```

세션 상태:

```python
session = {
    "username": "홍길동"
}
```

---

### 2. 첫 번째 상품 추가

입력

```text
GET /cart/add?item=노트북
```

출력

```json
{
    "message": "노트북 상품이 장바구니에 추가되었습니다."
}
```

세션 상태:

```python
session = {
    "username": "홍길동",
    "cart": ["노트북"]
}
```

---

### 3. 두 번째 상품 추가

입력

```text
GET /cart/add?item=마우스
```

출력

```json
{
    "message": "마우스 상품이 장바구니에 추가되었습니다."
}
```

세션 상태:

```python
session = {
    "username": "홍길동",
    "cart": ["노트북", "마우스"]
}
```

---

### 4. 장바구니 조회

입력

```text
GET /cart
```

출력

```json
{
    "username": "홍길동",
    "cart": [
        "노트북",
        "마우스"
    ],
    "count": 2
}
```

---

### 5. 로그아웃

입력

```text
GET /logout
```

출력

```json
{
    "message": "로그아웃되었습니다."
}
```

세션 상태:

```python
session = {}
```

### 6. 로그아웃 후 장바구니 조회

입력


출력

