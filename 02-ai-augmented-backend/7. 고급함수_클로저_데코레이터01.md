# 고급함수

- 클로저: **함수가 만들어질 당시의 값을 기억하는 함수**
- 데코레이터: **기존 함수를 수정하지 않고 기능을 덧붙이는 함수**
- 이터레이터: **`next()`로 값을 하나씩 꺼내는 객체**
- 제너레이터: **`yield`를 이용해 이터레이터를 쉽게 만드는 함수**

> 클로저를 “외부 함수의 변수를 기억하는 내부 함수”로 설명하고, 데코레이터는 기존 함수에 기능을 덧붙이는 방식으로 설명합니다.   
> :chatgpt-content-reference{index="0"} 이터레이터는 `next()`로 값을 하나씩 꺼내며, 제너레이터는 `yield`에서 실행을 잠시 멈추고 다음 호출 때 이어서 실행하는 구조입니다. :chatgpt-content-reference{index="1"}

## 1. 클로저 — RPG 캐릭터 공격력 만들기

“공격력 배율을 기억하는 스킬”로 설명하면 쉽습니다.

```python
def make_attack(skill_power):
    print(f"⚔ 스킬 생성: 공격력 {skill_power}배")

    def attack(damage):
        return damage * skill_power

    return attack


fire_attack = make_attack(2)
critical_attack = make_attack(3)

print("🔥 화염 공격:", fire_attack(100))
print("💥 치명타 공격:", critical_attack(100))
```

실행 결과:

```text
⚔ 스킬 생성: 공격력 2배
⚔ 스킬 생성: 공격력 3배
🔥 화염 공격: 200
💥 치명타 공격: 300
```

여기서 중요한 질문을 학생들에게 던질 수 있습니다.

```python
fire_attack = make_attack(2)
```

`make_attack()` 함수는 이미 실행이 끝났는데 왜 `fire_attack(100)`에서 `2`를 기억할까요?

바로 이것이 **클로저**입니다.

```text
make_attack(2)

skill_power = 2
       ↓

attack 함수가 이 값을 기억
       ↓

fire_attack(100)
```

원문의 `mul(3)`, `mul(5)` 예제도 같은 구조입니다. 외부 함수가 끝나도 반환된 내부 함수가 값을 기억합니다. :chatgpt-content-reference{index="2"}

## 2. 클로저 — 게임 캐릭터 생성기

조금 더 재미있게 확장할 수 있습니다.

```python
def make_character(name, power):

    def attack(monster):
        print(f"{name}이(가) {monster}를 공격합니다!")
        print(f"💥 데미지: {power}")

    return attack


warrior = make_character("전사", 100)
wizard = make_character("마법사", 150)

warrior("슬라임")
wizard("드래곤")
```

출력:

```text
전사이(가) 슬라임를 공격합니다!
💥 데미지: 100

마법사이(가) 드래곤를 공격합니다!
💥 데미지: 150
```

학생들에게는 이렇게 설명하면 좋습니다.

> `warrior`라는 함수 안에는 `"전사"`와 `100`이라는 정보가 숨어 있다.

즉 함수가 **데이터까지 기억하고 있는 상태**입니다.

# 클로저 추가 예시

클로저는 **“함수가 값을 기억한다”**는 개념이 핵심이므로, 이번에는 게임이 아닌 **할인 계산기** 예시가 비전공자에게 이해하기 좋습니다.

## 클로저 예시 — 할인율을 기억하는 할인 계산기

```python
def make_discount(rate):

    def discount(price):
        discount_price = price * (1 - rate)
        return int(discount_price)

    return discount


# 10% 할인 함수
discount_10 = make_discount(0.10)

# 20% 할인 함수
discount_20 = make_discount(0.20)

print("10% 할인:", discount_10(10000))
print("20% 할인:", discount_20(10000))
```

실행 결과:

```text
10% 할인: 9000
20% 할인: 8000
```

핵심은 다음 부분입니다.

```python
discount_10 = make_discount(0.10)
```

`make_discount()` 함수는 실행이 끝났지만, 반환된 `discount()` 함수는 여전히

```python
rate = 0.10
```

을 기억하고 있습니다.

그래서 나중에

```python
discount_10(10000)
```

을 호출하면 내부적으로는 다음과 같이 계산됩니다.

```text
10000 × (1 - 0.10)
       ↓
      9000
```

반면

```python
discount_20 = make_discount(0.20)
```

은 `rate = 0.20`을 별도로 기억합니다.

즉, 같은 `discount()` 함수라도 각자 기억하고 있는 값이 다릅니다.

```text
make_discount(0.10)
       ↓
discount_10
       ↓
rate = 0.10 기억


make_discount(0.20)
       ↓
discount_20
       ↓
rate = 0.20 기억
```

> **클로저는 함수가 자신이 만들어질 당시의 주변 값을 기억하는 기능이다.**

조금 더 재미있게 바꾸면 쇼핑몰 쿠폰으로도 만들 수 있습니다.

```python
def make_coupon(name, rate):

    def use_coupon(price):
        discount = int(price * rate)
        final_price = price - discount

        print(f"🎟 {name} 쿠폰")
        print(f"상품가격 : {price:,}원")
        print(f"할인금액 : {discount:,}원")
        print(f"결제금액 : {final_price:,}원")

    return use_coupon


welcome_coupon = make_coupon("신규회원 10% 할인", 0.10)
vip_coupon = make_coupon("VIP 30% 할인", 0.30)


welcome_coupon(50000)

print()

vip_coupon(50000)
```

실행 결과:

```text
🎟 신규회원 10% 할인 쿠폰
상품가격 : 50,000원
할인금액 : 5,000원
결제금액 : 45,000원

🎟 VIP 30% 할인 쿠폰
상품가격 : 50,000원
할인금액 : 15,000원
결제금액 : 35,000원
```

이 예제는 **“함수마다 서로 다른 상태를 기억할 수 있다”**는 점을 직관적으로 이해

# 3. 데코레이터 — 게임 입장 검사

데코레이터는 “함수 앞에 경비원을 세운다”고 설명하면 아주 쉽습니다.

```python
def check_level(func):

    def wrapper(level):
        print("🚪 던전 입장 검사 중...")

        if level < 10:
            print("❌ 레벨이 부족합니다.")
            return

        print("✅ 입장 가능합니다.")
        func(level)

    return wrapper


@check_level
def enter_dungeon(level):
    print("⚔ 던전에 입장했습니다!")


enter_dungeon(5)

print()

enter_dungeon(15)
```

결과:

```text
🚪 던전 입장 검사 중...
❌ 레벨이 부족합니다.

🚪 던전 입장 검사 중...
✅ 입장 가능합니다.
⚔ 던전에 입장했습니다!
```

원리는 다음과 같습니다.

```text
enter_dungeon()

        ↓

check_level

        ↓

wrapper

        ↓

원래 enter_dungeon 실행
```

즉:

```python
@check_level
def enter_dungeon():
    ...
```

는 사실상

```python
enter_dungeon = check_level(enter_dungeon)
```

과 같은 의미입니다.

원문에서도 데코레이터는 기존 함수를 수정하지 않고 실행 시간 측정 같은 기능을 추가하는 방식으로 설명합니다. :chatgpt-content-reference{index="3"}

# 4. 데코레이터 — 함수 실행시간 측정 게임

원문의 실행시간 측정 예제를 학생들에게 친숙하게 바꿀 수 있습니다.

```python
import time


def timer(func):

    def wrapper(*args, **kwargs):

        print("⏱ 게임 시작")

        start = time.time()

        result = func(*args, **kwargs)

        end = time.time()

        print(f"⏱ 수행 시간: {end - start:.2f}초")

        return result

    return wrapper


@timer
def fight(monster):
    print(f"⚔ {monster}와 전투 중...")
    time.sleep(2)
    print("🏆 승리!")


fight("드래곤")
```

결과:

```text
⏱ 게임 시작
⚔ 드래곤와 전투 중...
🏆 승리!
⏱ 수행 시간: 2.00초
```

여기서 `*args`, `**kwargs`도 함께 복습할 수 있습니다. 원문에서도 데코레이터가 다양한 함수의 입력값을 받을 수 있도록 `*args`, `**kwargs`를 사용하는 구조를 설명합니다. :chatgpt-content-reference{index="4"}

# 5. 이터레이터 — 보물상자 하나씩 열기

이터레이터는 “한 번에 전부 꺼내지 않고 하나씩 꺼낸다”고 설명하면 좋습니다.

```python
treasures = ["💰 금화", "💎 다이아몬드", "🗡 전설의 검"]

box = iter(treasures)

print(next(box))
print(next(box))
print(next(box))
```

결과:

```text
💰 금화
💎 다이아몬드
🗡 전설의 검
```

한 번 더 실행하면:

```python
print(next(box))
```

결과:

```text
StopIteration
```

원문에서도 이터레이터는 `next()`로 값을 하나씩 가져오고, 값이 모두 소진되면 `StopIteration`이 발생한다고 설명합니다. :chatgpt-content-reference{index="5"}

학생에게는 이렇게 설명하면 됩니다.

```text
리스트 = 보물상자

iter() = 상자를 여는 사람

next() = 하나 꺼내기
```

# 6. 직접 만드는 이터레이터 — 몬스터 출현 시스템

`__iter__`, `__next__`를 재미있게 경험할 수 있습니다.

```python
class MonsterIterator:

    def __init__(self):
        self.monsters = [
            "🐌 슬라임",
            "👺 고블린",
            "🐉 드래곤"
        ]

        self.index = 0

    def __iter__(self):
        return self

    def __next__(self):

        if self.index >= len(self.monsters):
            raise StopIteration

        monster = self.monsters[self.index]

        self.index += 1

        return monster


game = MonsterIterator()

for monster in game:
    print("⚔ 몬스터 출현:", monster)
```

결과:

```text
⚔ 몬스터 출현: 🐌 슬라임
⚔ 몬스터 출현: 👺 고블린
⚔ 몬스터 출현: 🐉 드래곤
```

원문에서도 직접 이터레이터를 만들 때 `__iter__()`와 `__next__()`를 구현해야 한다고 설명합니다. :chatgpt-content-reference{index="6"}

핵심은:

```text
__iter__()
→ 반복 가능한 객체

__next__()
→ 다음 데이터 반환
```

입니다.

# 7. 제너레이터 — 몬스터 한 마리씩 등장

위 이터레이터 클래스를 제너레이터로 바꾸면 훨씬 간단해집니다.

```python
def monster_generator():

    print("게임 시작!")

    yield "🐌 슬라임"

    print("다음 스테이지")

    yield "👺 고블린"

    print("보스 등장!")

    yield "🐉 드래곤"


game = monster_generator()

print(next(game))
print(next(game))
print(next(game))
```

실행:

```text
게임 시작!
🐌 슬라임
다음 스테이지
👺 고블린
보스 등장!
🐉 드래곤
```

여기서 학생들이 반드시 이해해야 할 핵심은:

```python
yield
```

를 만나면

```text
종료 ❌
일시정지 ⭕
```

라는 것입니다.

원문에서는 이것을 음악 플레이어의 **재생/일시정지**에 비유합니다. :chatgpt-content-reference{index="7"}

# 8. 제너레이터 — 로또번호 하나씩 생성하기

수업에서 특히 반응이 좋을 만한 예제입니다.

```python
import random


def lotto_generator():

    numbers = random.sample(range(1, 46), 6)

    for number in numbers:
        yield number


lotto = lotto_generator()

print("🎱 첫 번째 번호:", next(lotto))
print("🎱 두 번째 번호:", next(lotto))
print("🎱 세 번째 번호:", next(lotto))
print("🎱 네 번째 번호:", next(lotto))
print("🎱 다섯 번째 번호:", next(lotto))
print("🎱 여섯 번째 번호:", next(lotto))
```

이 예제를 `for`문으로 바꾸면 더 간단합니다.

```python
for number in lotto_generator():
    print("🎱 번호:", number)
```

# 9. 제너레이터의 핵심 — 필요한 만큼만 계산

이 부분은 학생들에게 제너레이터의 필요성을 알려주는 데 가장 중요합니다.

먼저 일반 리스트 방식입니다.

```python
def make_numbers():

    result = []

    for i in range(1, 1_000_001):
        result.append(i)

    return result


numbers = make_numbers()

print(numbers[0])
```

100만 개를 전부 만들어 메모리에 저장합니다.

반면 제너레이터:

```python
def make_numbers():

    for i in range(1, 1_000_001):
        yield i


numbers = make_numbers()

print(next(numbers))
print(next(numbers))
print(next(numbers))
```

필요한 값만 생성합니다.

```text
리스트

1
2
3
4
5
...
1000000

전부 생성


제너레이터

next()
 ↓
1

next()
 ↓
2
```

원문에서도 이를 **lazy evaluation, 느긋한 계산법**이라고 설명하며 대용량 데이터 처리, 오래 걸리는 작업, 무한 데이터 스트림에서 유용하다고 설명합니다. :chatgpt-content-reference{index="8"}

# 10. 네 가지를 한 번에 사용하는 미니게임

마지막 실습으로는 이 예제가 좋습니다.

## 몬스터 사냥 게임

```python
import time
import random


# -------------------------
# 1. 클로저
# -------------------------

def make_attack(power):

    def attack(monster_hp):
        damage = random.randint(power - 10, power + 10)

        print(f"💥 공격 데미지: {damage}")

        return monster_hp - damage

    return attack


# -------------------------
# 2. 데코레이터
# -------------------------

def battle_log(func):

    def wrapper(*args, **kwargs):

        print()
        print("⚔ 전투 시작!")

        start = time.time()

        result = func(*args, **kwargs)

        end = time.time()

        print(f"⏱ 전투시간: {end - start:.2f}초")
        print("🏁 전투 종료")

        return result

    return wrapper


# -------------------------
# 3. 제너레이터
# -------------------------

def monster_generator():

    monsters = [
        ("🐌 슬라임", 30),
        ("👺 고블린", 50),
        ("🐉 드래곤", 100)
    ]

    for monster in monsters:
        yield monster


# -------------------------
# 4. 게임
# -------------------------

@battle_log
def fight(name, hp, attack):

    print(f"{name} 등장! HP={hp}")

    while hp > 0:

        hp = attack(hp)

        if hp > 0:
            print(f"❤️ 남은 HP: {hp}")

        time.sleep(0.5)

    print(f"🏆 {name} 처치!")


# 공격력 30을 기억하는 클로저
hero_attack = make_attack(30)

# 몬스터 제너레이터
monsters = monster_generator()


for monster_name, monster_hp in monsters:

    fight(
        monster_name,
        monster_hp,
        hero_attack
    )
```

이 코드 하나에:

```text
클로저
→ 공격력 기억

데코레이터
→ 전투시간 기록

제너레이터
→ 몬스터 한 마리씩 생성

이터레이션
→ for문으로 몬스터 순회
```

가 모두 들어 있습니다.

---

## 수업에서는 이 순서가 가장 좋습니다

```text
1. 클로저
   "함수가 값을 기억한다"

       ↓

2. 데코레이터
   "함수를 다른 함수가 감싼다"

       ↓

3. 이터레이터
   "데이터를 하나씩 꺼낸다"

       ↓

4. 제너레이터
   "yield로 이터레이터를 쉽게 만든다"

       ↓

5. 게임 실습
```

특히 에게는 네 개의 개념을 따로 외우게 하기보다 **“기억한다 → 감싼다 → 하나씩 꺼낸다 → 필요할 때 만든다”**라는 문장으로 연결해 주면 훨씬 이해하기 쉽습니다.
