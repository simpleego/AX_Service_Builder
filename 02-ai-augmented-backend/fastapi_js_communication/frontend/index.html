클라이언트 ↔ 서버 통신 실습

Vanilla JavaScript + FastAPI | 17가지 전송 방식별 버튼을 눌러 결과 비교

서버 상태: 확인 전

01. URL Path Parameter

GET /students/{id} — 경로에 식별자 포함

02. Query String

GET /search?keyword=...&page=...

03. 전통 HTML Form

POST + 페이지 이동 (현재 탭에서 JSON 대신 HTML 응답)

04. XMLHttpRequest / AJAX

XHR 객체로 GET, 페이지 변경 없이 데이터 수신

05. Fetch API GET

fetch() + response.json()

06. JSON POST / 성적 계산

JSON.stringify() → Pydantic 검증 → 평균/학점

07. REST API CRUD

조회 GET / 등록 POST / 수정 PUT / 삭제 DELETE

08. URLSearchParams

application/x-www-form-urlencoded 전송

09. FormData

multipart/form-data 입력 전송

10. 파일 업로드

FormData + UploadFile / 최대 5MB, 저장하지 않음

11. HTTP Header

X-API-Key: demo-key-123 (교육용 고정 키)

12. Cookie

HttpOnly Cookie 설정 → 다음 요청에 자동 포함

13. Polling

2초마다 GET /status 반복

14. Long Polling

서버가 5초 후 응답하는 대기 방식 시연

15. SSE

EventSource: 서버에서 진행률을 연속으로 전송

16. WebSocket

WebSocket 양방향 메시지 송수신

17. Streaming Response

ReadableStream / TextDecoder로 텍스트 조각 수신
