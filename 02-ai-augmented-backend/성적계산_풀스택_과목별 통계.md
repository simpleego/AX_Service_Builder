변경된 기능은 다음과 같습니다.

| 위치             | 구성 및 동작                             |
| -------------- | ----------------------------------- |
| 학생 입력 행 오른쪽    | 총점·평균·평점을 `readonly input`으로 배치     |
| 학생별 계산 버튼      | 전체 학생의 점수를 서버에 전송하고 오른쪽 결과 칸에 표시    |
| 각 과목 열 하단      | 총점·평균·최고점·최저점 입력란을 항상 표시            |
| 국어·영어·수학 계산 버튼 | 클릭할 때마다 현재 입력값을 서버에 보내 해당 과목 통계를 갱신 |

**계산 규칙**

* 빈 점수는 **0점**으로 계산합니다.
* 어떤 계산 버튼을 눌러도 **화면의 모든 과목 점수**가 0~100 정수인지 검사합니다.
* 과목 평균은 **현재 표시된 학생 수**로 나눕니다. 빈 점수도 인원수와 최저점에 포함됩니다.
* 과목별 계산은 이름·학과를 입력하기 전에도 가능합니다.
* 입력을 수정하면 결과 칸은 유지하고 이전 계산값만 비웁니다.
* 처음 1명으로 시작하며 최대 10명까지 추가할 수 있습니다.

압축을 풀고 `student_scores_v2` 폴더의 터미널에서 실행하세요.

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn main:app --reload
```

이전 서버가 실행 중이라면 먼저 `Ctrl+C`로 종료하세요. 실행 후 [http://127.0.0.1:8000](http://127.0.0.1:8000)에 접속하면 됩니다.

서버 계산·빈 점수 처리·입력 제한 테스트와 JavaScript 문법 검사를 통과했습니다. 브라우저 자동 동작 검증은 환경 제약으로 수행하지 못했습니다.
