03 · 10분 assert를 이용한 기초 테스트

assert 조건식은 조건이 거짓이면 AssertionError를 발생시킵니다.

def add(a, b):
    return a + b

assert add(10, 20) == 30
print("테스트 통과!")

입력값 변경 실습

아래 실습은 JavaScript로 구현한 동작 원리 시뮬레이션이며, 실제 Python 코드를 실행하는 것은 아닙니다.

입력값을 설정하고 검사 실행을 누르세요.

의도적으로 실패시키기

assert add(10, 20) == 40  # AssertionError

05 · 10분 정상·경계·예외 테스트

시험 점수는 0~100점 범위라고 가정합니다. 0, 100은 경계값이고 -1, 101은 잘못된 값입니다.

score.py

def validate_score(score):
    if score < 0 or score > 100:
        raise ValueError("점수는 0~100이어야 합니다.")
    return score

test_score.py

import pytest
from score import validate_score

def test_normal():
    assert validate_score(80) == 80

def test_minimum():
    assert validate_score(0) == 0

def test_maximum():
    assert validate_score(100) == 100

def test_invalid():
    with pytest.raises(ValueError):
        validate_score(-1)
pytest.raises(ValueError) 안에서는 ValueError가 발생해야 테스트가 통과합니다.

실습 문제 ②

101점을 입력할 때 ValueError가 발생하는 테스트를 추가하세요.

실습 ② 정답 보기
def test_over_maximum():
    with pytest.raises(ValueError):
        validate_score(101)

06 · 10분 parametrize로 여러 값 테스트

@pytest.mark.parametrize는 동일한 테스트를 여러 값으로 독립 실행하게 해 줍니다.

import pytest
from score import validate_score

@pytest.mark.parametrize("score", [0, 50, 100])
def test_valid_score(score):
    assert validate_score(score) == score

@pytest.mark.parametrize("score", [-1, 101])
def test_invalid_score(score):
    with pytest.raises(ValueError):
        validate_score(score)

여기서는 총 5개 테스트를 실행합니다. mark는 마커 접근 인터페이스이며, parametrize는 매개변수화 마커입니다.

07 · 10분 종합 실습: 학생 성적 계산 테스트

국어·영어·수학 점수로 총점, 평균, 학점을 계산합니다. 잘못된 점수는 ValueError가 발생해야 합니다.

입력 점수확인 사항
90, 90, 90총점 270
80, 80, 80평균 80
100, 90, 80A학점
70, 70, 70C학점
-1, 80, 90ValueError
80, 101, 90ValueError

grades.py

def calculate_scores(korean, english, math):
    scores = [korean, english, math]
    if any(s < 0 or s > 100 for s in scores):
        raise ValueError("점수는 0~100이어야 합니다.")

    total = sum(scores)
    average = total / 3

    if average >= 90:
        grade = "A"
    elif average >= 80:
        grade = "B"
    elif average >= 70:
        grade = "C"
    else:
        grade = "F"

    return {"total": total, "average": average, "grade": grade}
7-4. 모범 정답 전체 보기 (test_grades.py)
import pytest
from grades import calculate_scores

def test_total():
    result = calculate_scores(90, 90, 90)
    assert result["total"] == 270

def test_average():
    result = calculate_scores(80, 80, 80)
    assert result["average"] == 80

@pytest.mark.parametrize("scores, expected_grade", [
    ((100, 90, 80), "A"),
    ((70, 70, 70), "C"),
])
def test_grade(scores, expected_grade):
    result = calculate_scores(*scores)
    assert result["grade"] == expected_grade

@pytest.mark.parametrize("scores", [
    (-1, 80, 90),
    (80, 101, 90),
])
def test_invalid_scores(scores):
    with pytest.raises(ValueError):
        calculate_scores(*scores)

실행: python -m pytest -v → 위 코드에서는 총 6개 테스트 케이스가 실행됩니다.

*scores는 튜플의 요소를 함수의 위치 인자로 풀어서 전달합니다.

09 AI 시대, 무엇을 공부해야 할까?

AI가 테스트 코드를 생성하더라도 개발자는 무엇을 검사할지, 올바른 결과가 무엇인지, 테스트가 충분한지를 판단해야 합니다.

단계개발자AI
계획검증 조건 정의테스트 항목 제안
작성기대 결과 확인pytest 코드 생성
실행실패 원인 판단진단 지원
수정변경 적절성 검토코드 수정 제안
AI에 요청할 프롬프트

학생 성적 계산 함수 calculate_scores()를 대상으로 pytest 테스트 코드를 작성해줘. 정상값, 0점과 100점의 경계값, 잘못된 점수, 학점 경계조건을 포함해줘. 각 테스트의 목적과 기대 결과도 설명해줘.

테스트가 모두 PASS여도 테스트하지 않은 조건에서 버그가 발생할 수 있습니다.
