## 2. 테스트란 무엇인가? (5분)

### 2-1. 쉬운 비유: 자동차 출고 검사

자동차를 만들었다고 해서 곧바로 판매할 수 있을까요? 브레이크가 잘 작동하는지, 속도계가 정확한지, 안전벨트가 정상인지 확인해야 합니다.

프로그램도 마찬가지입니다.

개발

프로그램 작성

테스트

결과 검증

완성

테스트의 기본 원리

입력값 → 프로그램 실행 → 실제 결과와 기대 결과 비교

예를 들어 두 수를 더하는 함수에 `10, 20`을 입력했을 때 결과가 `30`이라면 테스트가 통과합니다. `40`이 나온다면 테스트에 실패합니다.

## 3. `assert`를 이용한 기초 테스트 (10분)

### 3-1. 첫 번째 테스트 함수

우선 다음과 같은 덧셈 함수를 작성합니다.

```pyth
def add(a, b):    return a + bresult = add(10, 20)print(result)  # 30
```

그런데 출력 결과가 30이라는 것을 사람이 직접 확인하는 대신, 프로그램이 자동으로 검사하도록 하려면 어떻게 해야 할까요?

이때 `assert`를 사용합니다.

```python
def add(a, b):    return a + bassert add(10, 20) == 30print("테스트 통과!")
```

`assert`는 파이썬에서 제공하는 검증 명령문입니다.

```python
assert 조건식
```

- 조건이 `True` → 정상적으로 다음 코드 실행
- 조건이 `False` → `AssertionError` 발생

직접 실행해 보는 assert 실습

입력 a

입력 b

기대 결과

실행되는 검사

assert add(10, 20) == 30

PASS — 테스트 통과

실제 결과: 30 / 기대 결과: 30

값을 변경하면 조건식의 참·거짓을 즉시 확인할 수 있습니다.

### 3-2. 의도적으로 테스트 실패시키기

```python
assert add(10, 20) == 40
```

실행 결과:

```python
AssertionError
```

강의 포인트: 테스트가 실패했다고 반드시 테스트 코드가 잘못된 것은 아닙니다. 프로그램에 결함이 있거나, 기대 결과를 잘못 설정했거나, 요구사항을 오해했을 수도 있습니다.

## 5. 정상·경계·예외 테스트 (10분)

실무에서는 정상적인 입력값뿐 아니라 잘못된 입력값도 확인해야 합니다.

예를 들어 시험 점수는 0점부터 100점까지만 허용한다고 가정하겠습니다.

### 5-1. 테스트 대상 함수

score.py

```python
def validate_score(score):
    if score < 0 or score > 100:
        raise ValueError("점수는 0~100이어야 합니다.")

    return score
```

### 5-2. 어떤 값을 테스트해야 할까?

| 구분     | 입력값 | 기대 결과      |
| ------ | --- | ---------- |
| 정상값    | 80  | 80 반환      |
| 최솟값 경계 | 0   | 0 반환       |
| 최댓값 경계 | 100 | 100 반환     |
| 잘못된 값  | -1  | ValueError |
| 잘못된 값  | 101 | ValueError |

실제 코드에서는 다음처럼 작성합니다.

test_score.py

```python
import pytest
from score import validate_score

def test_normal():
    assert validate_score(80) == 80

def test_minimum():
    assert validate_score(0) == 0

def test_maximum():
    assert validate_score(100) == 100

def test_invalid():
    with pytest.raises(ValueError):
        validate_score(-1)
```

여기서 새로운 기능이 등장합니다.

```python
with pytest.raises(ValueError):
  validate_score(-1)
```

이 코드는 ValueError가 발생해야 테스트를 통과합니다.

`pytest.raises()`는 지정한 예외가 발생했는지 검증하는 도구입니다.&#x20;

## 6. parametrize를 이용한 반복 테스트 (10분)

앞의 예제는 각각 테스트 함수를 작성해야 했습니다.

하지만 `pytest.mark.parametrize()`를 사용하면 하나의 함수로 여러 입력값을 테스트할 수 있습니다.

```python
import pytest
from score import validate_score

@pytest.mark.parametrize("score", [0, 50, 100])
def test_valid_score(score):
    assert validate_score(score) == score

@pytest.mark.parametrize("score", [-1, 101])
def test_invalid_score(score):
    with pytest.raises(ValueError):
        validate_score(score)
```

실행 결과는 총 5개의 테스트입니다.

```python
test_valid_score[0]    PASSED
test_valid_score[50]   PASSED
test_valid_score[100]  PASSED
test_invalid_score[-1] PASSED
test_invalid_score[101] PASSED

5 passed
```

### 핵심 문법 해석

```python
@pytest.mark.parametrize("score", [-1, 101])
```

- `@` : 데코레이터
- `pytest.mark` : 테스트에 마커를 적용하는 인터페이스
- `parametrize` : 여러 입력값으로 테스트를 반복 실행
- `"score"` : 테스트 함수의 매개변수 이름
- `[-1, 101]` : 테스트할 데이터

관련 공식 문서: [pytest Parametrizing tests](https://docs.pytest.org/en/stable/how-to/parametrize.html?utm_source=chatgpt.com)

### 6-1. 직접 확인하는 매개변수 테스트

## 7. 종합 실습: 학생 성적 계산 테스트 (10분)

이번에는 지금까지 학습한 `assert`, `pytest.raises`, `parametrize`를 하나의 프로그램에 적용합니다.

### 7-1. 실습 요구사항

학생의 국어·영어·수학 점수를 입력받아 총점, 평균, 학점을 계산하는 함수입니다.

처리 조건

- 각 과목 점수는 0\~100점
- 총점은 세 과목의 합계
- 평균이 90점 이상이면 A, 80점 이상 B, 70점 이상 C, 나머지는 F
- 잘못된 점수는 `ValueError` 발생

### 7-2. 테스트 대상 프로그램

**grades.py**
```python

def calculate_scores(korean, english, math):
    scores = [korean, english, math]

    if any(s < 0 or s > 100 for s in scores):
        raise ValueError("점수는 0~100이어야 합니다.")

    total = sum(scores)
    average = total / 3

    if average >= 90:
        grade = "A"
    elif average >= 80:
        grade = "B"
    elif average >= 70:
        grade = "C"
    else:
        grade = "F"

    return {
        "total": total,
        "average": average,
        "grade": grade
    }
```

## 10. 강사용 수업 운영 팁

60분 수업에서는 다음 순서로 진행하면 좋습니다.

- 처음에는 `assert`만으로 테스트하여 학습자가 기본 원리를 이해하도록 합니다.
- `pytest`로 자동 수집과 실행을 경험하게 합니다.
- 일부러 잘못된 기대값을 설정하여 FAIL 메시지를 읽게 합니다.
- `pytest.raises`로 오류가 발생하는 상황도 테스트할 수 있음을 보여줍니다.
