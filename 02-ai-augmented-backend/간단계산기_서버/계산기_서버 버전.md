# 사칙연산 계산기 서버 버전으로 전환

```text
HTML 입력
   ↓
JavaScript fetch()
   ↓
FastAPI 서버
   ↓
Python으로 계산
   ↓
JSON 응답
   ↓
JavaScript
   ↓
화면에 결과 출력
```

하도록 바꾸는 것입니다.

처음 실습에서는 `POST + JSON`보다 **GET + Query Parameter** 방식이 서버 호출 과정을 눈으로 확인하기 쉬워 더 적합합니다. FastAPI에서는 함수의 일반 매개변수를 자동으로 Query Parameter로 처리하고 타입 변환 및 검증도 수행합니다. ([FastAPI][1])

## 1. 프로젝트 구조

가장 간단하게 두 파일만 사용하겠습니다.

```text
fastapi_calc/
│
├── main.py
└── index.html
```

# 2. FastAPI 서버 코드

`main.py`

```python
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# HTML과 FastAPI 서버의 주소가 다르므로 CORS 허용
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/")
def home():
    return {"message": "계산기 서버가 실행중입니다."}


@app.get("/calc")
def calc(num1: float, num2: float, op: str):

    if op == "+":
        result = num1 + num2

    elif op == "-":
        result = num1 - num2

    elif op == "*":
        result = num1 * num2

    elif op == "/":
        if num2 == 0:
            raise HTTPException(
                status_code=400,
                detail="0으로 나눌 수 없습니다."
            )

        result = num1 / num2

    else:
        raise HTTPException(
            status_code=400,
            detail="잘못된 연산자입니다."
        )

    return {
        "num1": num1,
        "num2": num2,
        "op": op,
        "result": result
    }
```

여기서 핵심은 사실 이 부분입니다.

```python
@app.get("/calc")
def calc(num1: float, num2: float, op: str):
```

예를 들어 브라우저에서 다음 요청을 보낸다고 생각하면 됩니다.

```text
/calc?num1=10&num2=20&op=+
```

서버에서는

```python
num1 = 10
num2 = 20
op = "+"
```

처럼 받게 됩니다.

# 5. 기존 HTML을 FastAPI 서버와 연결

기존 HTML 구조를 최대한 유지하면서 JavaScript 계산을 서버 호출 방식으로 바꾸겠습니다.

`index.html`

```html
<!DOCTYPE html>
<html lang="ko">

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>FastAPI 계산기</title>

    <style>

        input {
            padding: 8px;
            background-color: #ddd;
            text-align: right;
        }

        .container {
            width: 220px;
            margin: 0 auto;
        }

        .calc {
            border: 10px solid #ddd;
            padding: 10px;
            border-radius: 10%;
        }

        button {
            margin: 2px;
            padding: 5px 10px;
        }

        #result {
            font-weight: bold;
        }

    </style>

</head>

<body>

<div class="container">

    <h1>계산기</h1>

    <form class="calc" onsubmit="calculateSelect(event)">

        <label>숫자 1:</label>

        <input
            type="number"
            id="num1"
            value="0"
            required
        >

        <br><br>

        <label>숫자 2:</label>

        <input
            type="number"
            id="num2"
            value="0"
            required
        >

        <br><br>

        <label>연산 선택:</label>

        <select id="operation">

            <option value="+">더하기 (+)</option>
            <option value="-">빼기 (-)</option>
            <option value="*">곱하기 (*)</option>
            <option value="/">나누기 (/)</option>

        </select>

        <br><br>


        <!-- 각각의 버튼으로 계산 -->

        <button type="button"
                onclick="calculate('+')">
            +
        </button>

        <button type="button"
                onclick="calculate('-')">
            -
        </button>

        <button type="button"
                onclick="calculate('*')">
            *
        </button>

        <button type="button"
                onclick="calculate('/')">
            /
        </button>

        <br><br>


        <!-- select에서 선택한 연산 실행 -->

        <button type="submit">
            계산하기
        </button>

        <button type="reset">
            초기화
        </button>

        <br><br>


        <label>계산 결과:</label>

        <output id="result">
            여기에 결과가 표시됩니다.
        </output>

    </form>

</div>


<script>

    async function calculate(op) {

        // 1. HTML 입력값 가져오기

        const num1 =
            document.getElementById("num1").value;

        const num2 =
            document.getElementById("num2").value;


        // 2. 서버 주소 만들기

        const params = new URLSearchParams({
            num1: num1,
            num2: num2,
            op: op
        });


        const url =
            "http://127.0.0.1:8000/calc?" + params;


        // 3. FastAPI 서버 호출

        const response = await fetch(url);


        // 4. 서버 응답을 JSON으로 변환

        const data = await response.json();


        // 5. 오류 확인

        if (!response.ok) {

            document.getElementById("result").innerHTML
                = data.detail;

            return;
        }


        // 6. 결과 화면 출력

        document.getElementById("result").innerHTML
            = data.result;
    }



    function calculateSelect(event) {

        // form 기본 전송 방지

        event.preventDefault();


        // select에서 선택한 연산자 가져오기

        const op =
            document.getElementById("operation").value;


        // 서버 계산 요청

        calculate(op);
    }

</script>

</body>

</html>
```

# 6. 가장 중요한 JavaScript

학생들에게는 우선 전체 JavaScript 중 이것만 집중해서 설명해도 됩니다.

```javascript
async function calculate(op) {

    const num1 =
        document.getElementById("num1").value;

    const num2 =
        document.getElementById("num2").value;


    const params = new URLSearchParams({
        num1: num1,
        num2: num2,
        op: op
    });


    const response = await fetch(
        "http://127.0.0.1:8000/calc?" + params
    );


    const data = await response.json();


    document.getElementById("result").innerHTML
        = data.result;
}
```

핵심은 **`fetch()`**입니다.

기존 프로그램은 JavaScript가 직접 계산했습니다.

```javascript
result = num1 + num2;
```

이제는 이 코드가 없어집니다.

대신:

```javascript
fetch(...)
```

를 사용하여 Python 서버에게 계산을 요청합니다.

# 7. JavaScript와 Python의 역할 비교

이 예제에서 역할이 명확하게 분리됩니다.

| 영역         | 역할            |
| ---------- | ------------- |
| HTML       | 숫자 입력, 버튼     |
| CSS        | 화면 디자인        |
| JavaScript | 입력값 수집, 서버 호출 |
| `fetch()`  | FastAPI와 통신   |
| FastAPI    | 요청 받기         |
| Python     | 실제 계산         |
| JSON       | 계산 결과 전달      |

따라서 기존에는:

```text
HTML
 ↓
JavaScript
 ↓
계산
 ↓
화면 출력
```

이었습니다.

FastAPI를 적용하면:

```text
HTML
 ↓
JavaScript
 ↓
fetch()
 ↓
--------------------
       인터넷
--------------------
 ↓
FastAPI
 ↓
Python 계산
 ↓
JSON
 ↓
--------------------
       인터넷
--------------------
 ↓
JavaScript
 ↓
HTML 출력
```

이 구조가 됩니다.

## 8. 실제 서버 요청을 눈으로 확인

예를 들어 학생이

```text
숫자1 : 10
숫자2 : 20
연산 : +
```

를 입력하면 JavaScript가 다음과 같은 요청을 생성합니다.

```text
http://127.0.0.1:8000/calc?num1=10&num2=20&op=%2B
```

여기서 `%2B`는 `+`를 URL에서 안전하게 표현한 값입니다.

FastAPI에서는:

```python
@app.get("/calc")
def calc(num1: float, num2: float, op: str):
```

로 데이터를 받습니다. FastAPI는 이런 Query Parameter를 함수 인자로 연결하고 선언된 `float`, `str` 타입에 맞춰 변환·검증합니다. ([FastAPI][1])

그리고:

```python
result = num1 + num2
```

를 수행한 다음

```python
return {
    "result": result
}
```

를 반환합니다.

브라우저에서는:

```json
{
    "num1": 10,
    "num2": 20,
    "op": "+",
    "result": 30
}
```

을 받습니다.

# 9. 왜 CORS 코드가 필요한가?

FastAPI에는 다음 코드가 들어 있습니다.

```python
from fastapi.middleware.cors import CORSMiddleware
```

그리고:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)
```

예를 들어 HTML을 VS Code Live Server로 실행하면:

```text
http://127.0.0.1:5500
```

이고 FastAPI는:

```text
http://127.0.0.1:8000
```

입니다.

포트가 다르므로 브라우저 입장에서는 서로 다른 Origin입니다.

```text
Frontend
127.0.0.1:5500

        ↓ fetch

Backend
127.0.0.1:8000
```

그래서 실습용 서버에서는 CORS를 허용해 줍니다. FastAPI는 `CORSMiddleware`를 통해 허용 Origin, HTTP Method, Header 등을 설정할 수 있습니다. ([FastAPI][2])

실서비스에서는 보통 `"*"` 대신 실제 프론트엔드 주소만 지정합니다.

# 10. 수업에서는 이 부분을 가장 강조하면 됩니다

학생들에게 처음에는 FastAPI 코드도 다음처럼 생각하도록 하면 쉽습니다.

```python
@app.get("/calc")
def calc(num1: float, num2: float, op: str):

    # ① 요청 데이터 받기

    # ② 계산하기

    # ③ 결과 보내기

    return {"result": result}
```

즉, 백엔드 서버의 기본 구조는 결국:

```text
요청 받기
   ↓
처리하기
   ↓
응답하기
```

입니다.

그리고 프론트엔드는:

```text
입력받기
   ↓
서버에 요청
   ↓
응답받기
   ↓
화면 출력
```

입니다.

### 이 계산기 실습 다음 단계

이 예제는 **1단계 서버 실습으로 상당히 적합**합니다. 그다음 수업에서는 같은 계산기를 그대로 사용하면서 다음 순서로 확장하면 FastAPI 학습 흐름이 자연스럽습니다.

```text
1. GET + Query Parameter        ← 현재 예제
            ↓
2. POST + JSON
            ↓
3. Pydantic BaseModel
            ↓
4. 계산 결과 DB 저장
            ↓
5. PostgreSQL 연결
            ↓
6. React → FastAPI 호출
            ↓
7. FastAPI → AI/LLM 호출
```

특히 **GET 계산기 → POST 계산기 → 회원가입 POST → PostgreSQL 저장** 순서로 진행하면 비전공자도 `프론트엔드 → API → 백엔드 → DB`의 전체 웹 서비스 구조를 비교적 직관적으로 연결할 수 있습니다.
