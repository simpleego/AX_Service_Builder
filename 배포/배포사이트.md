# 대표적인 배포 사이트

> GitHub Pages 외에도 HTML, CSS, JS로 만든 정적 웹사이트를 **무료로 간편하게 배포**할 수 있는 대표적인 플랫폼들은 다음과 같습니다.

* **Netlify (넷리파이)**
* **특징**: 프론트엔드 개발자들이 가장 선호하는 서비스 중 하나입니다. GitHub 저장소와 연동해 두면 코드를 푸시할 때마다 자동으로 빌드되고 배포됩니다.
* **장점**: 별도의 복잡한 설정 없이 드래그 앤 드롭만으로도 즉시 웹사이트 배포가 가능하며, 기본 무료 플랜에서도 HTTPS(SSL 보안 인증서), 커스텀 도메인 연결, 폼(Form) 제출 기능 등을 무료로 지원합니다.


* **Vercel (버셀)**
* **특징**: Next.js를 만든 회사에서 제공하는 플랫폼이지만, 일반적인 순수 HTML, CSS, JS 정적 파일 배포도 매우 강력하고 속도가 빠릅니다.
* **장점**: GitHub, GitLab, Bitbucket 등과의 연동이 매우 매끄럽고 직관적입니다. 배포 속도가 빛의 속도 수준으로 매우 빠르며, 무료 플랜(Hobby 계정)에서도 전 세계적인 글로벌 CDN을 무료로 이용할 수 있습니다.


* **Cloudflare Pages (클라우드플레어 페이지)**
* **특징**: 세계적인 보안 및 CDN 기업인 클라우드플레어에서 제공하는 무료 정적 웹 호스팅 서비스입니다.
* **장점**: 무료 플랜의 트래픽 제한이 사실상 무제한(Unlimited)에 가까울 정도로 매우 관대합니다. 대규모 접속자가 몰려도 트래픽 비용 걱정 없이 안정적으로 운영할 수 있어 가성비가 뛰어납니다.


* **GitHub Pages (기타 대안들과 비교 시)**
* **특징**: 지금 사용하고 계신 깃허브에서 자체 제공하는 서비스입니다.
* **장점**: 별도의 회원가입이나 외부 플랫폼 연동 없이, 소스코드를 관리하는 깃허브 공간 안에서 모든 것을 해결할 수 있어 개발 학습용이나 포트폴리오 배포용으로 가장 접근성이 좋습니다.
