# 깃허브 배포 기능
> 깃허브(GitHub)에 코드를 업로드하고 무료로 웹사이트를 배포하는 가장 쉽고 빠른 방법은 **GitHub Pages**를 사용하는 것입니다.
> 별도의 서버 설정 없이 클릭 몇 번으로 가능합니다.

---

### **1단계: 깃허브 저장소(Repository) 생성**

1. [GitHub](https://github.com/)에 로그인합니다.
2. 우측 상단의 **`+`** 버튼을 누르고 `New repository`를 선택합니다.
3. **Repository name**을 입력합니다. (예: `vending-machine`)
4. 공개 설정은 **Public**으로 선택합니다. (GitHub Pages 무료 배포는 Public 저장소에서 가능합니다.)
5. 맨 아래 **`Create repository`** 버튼을 누릅니다.

### **2단계: 코드 파일 업로드하기**

가장 간단한 웹 브라우저 업로드 방식을 사용합니다.

1. 생성된 저장소 페이지에서 **`uploading an existing file`** 링크를 클릭합니다.
2. 준비한 `index.html`, `style.css`, `script.js` 파일들을 마우스로 드래그해서 브라우저 화면에 놓습니다.
* **주의**: 메인 페이지 파일 이름은 반드시 `index.html`이어야 합니다.


3. 파일들이 업로드 목록에 뜨면, 아래쪽 **`Commit changes`** 버튼을 눌러 저장합니다.

### **3단계: GitHub Pages로 배포하기**

1. 저장소 상단의 탭 메뉴에서 **`Settings`** (설정)로 들어갑니다.
2. 왼쪽 사이드바에서 **`Pages`** 메뉴를 클릭합니다.
3. **Build and deployment** 섹션의 **Branch** 설정에서 아래와 같이 변경합니다.
* `None`을 **`main`** (또는 `master`)으로 선택합니다.
* 폴더는 `/ (root)` 그대로 둡니다.

> **하위 폴더에 배포할 코드가 있다면 하위폴도까지 경로명을 추가로 입력해야 최종적인 배포주소가 된다.**


4. **`Save`** 버튼을 누릅니다.

### **4단계: 배포된 사이트 확인하기**

1. 설정 저장 후 1~2분 정도 기다린 뒤, 페이지를 새로고침합니다.
2. `Pages` 설정 상단에 **`Your site is live at...`** 이라는 초록색 문구와 함께 웹사이트 주소가 나타납니다.
3. 해당 주소를 클릭하면 배포된 자판기 화면을 누구나 볼 수 있습니다.
