> 실제 UI 구현 과정에서 발주자가 손그림 형태로 배치도를 여러 차례 제시했고, 이를 근거로 화면을
> 반복 수정했다. 본 문서는 **최종 확정된 배치**를 와이어프레임 형태로 정리한 것이다.

## 1. 소비자 화면 (자판기 앞면) — 3열 가로 구조

실물 자판기 전면부를 모사한 3열 구조. 왼쪽은 음료 진열, 가운데는 투입 관련, 오른쪽은 관리/반환
버튼 계열이다.

```mermaid
flowchart TB
  title["🥤 자판기 (소비자)"]

  subgraph ROW1[" "]
    direction LR
    subgraph COL1["① 음료 배치 – 가로 3개씩, 세로 스크롤"]
      direction LR
      d1["물\n450원"]
      d2["커피\n500원"]
      d3["이온음료\n550원"]
    end
    subgraph COL2["② 투입금액 + 투입구 (하나의 영역)"]
      direction TB
      amt["투입 금액\n0원"]
      slot["🪙 투입구\n(드래그하여 투입)"]
    end
    subgraph COL3a["③ 관리자"]
      adminBtn["관리자 버튼"]
    end
  end

  subgraph ROW2[" "]
    direction LR
    subgraph COL1b["음료 배치 (계속, 스크롤 영역)"]
      d4["고급커피"]
      d5["탄산음료"]
      d6["사이다"]
      d7["콜라"]
    end
    subgraph COL2b["동전/지폐 트레이"]
      coins["10 · 50 · 100 · 500원 동전 칩"]
      bills["1,000 · 5,000원 지폐 칩"]
    end
    subgraph COL3b["잔돈반환"]
      returnBtn((("잔돈\n반환")))
    end
  end

  subgraph ROW3[" "]
    direction LR
    dispense["상품 배출구 (상시 노출, 음료1+음료2 폭)"]
    returnBox["동전 반환구 + '동전 비우기' 버튼"]
  end

  title --> ROW1 --> ROW2 --> ROW3
```

### 배치 원칙

| 원칙 | 설명 |
|---|---|
| 3열 고정 | 좌(음료) / 중(투입) / 우(관리·반환)로 열을 고정하고, 행 높이만 콘텐츠에 맞춰 늘어난다 |
| 통합 영역 | "투입금액"과 "투입구"는 하나의 카드 안에 위·아래로 묶어 시각적으로 한 기능처럼 보이게 한다 |
| 분리 배치 | "동전/지폐 트레이"(입력)와 "잔돈반환 버튼"(출력)은 서로 다른 열에 두어 입력/출력 동작을 구분한다 |
| 상시 노출 | 상품 배출구는 구매 전에도 항상 보이는 자리이며, 내용만 갱신된다(숨김 처리 금지) |
| 내부 스크롤 | 음료 목록·동전 트레이는 각 영역 안에서만 스크롤되며, 전체 화면 골격은 흔들리지 않는다 |
| 색상 규칙 | 구매가능=굵은 오렌지 테두리(배경 채우지 않음) / 품절=배경 채움(빨강) / 투입금액·투입구=`#ddd` 배경 + 검정 글자 |

## 2. 관리자 화면 — 사이드바 + 콘텐츠 와이드 구조

```mermaid
flowchart TB
  topbar["🔒 관리자 모드    총 매출액 / 보유 현금            [로그아웃]"]
  subgraph BODY[" "]
    direction LR
    subgraph SIDEBAR["탭 사이드바 (세로 고정폭)"]
      direction TB
      t1["음료 관리"]
      t2["잔돈 관리"]
      t3["매출 조회"]
      t4["비밀번호 변경"]
      t5["수금"]
      t6["테마 설정"]
    end
    content["선택한 탭의 콘텐츠 (넓은 영역, 표/폼/카드)"]
  end
  msg["처리 결과 메시지 영역"]
  topbar --> BODY --> msg
```

- 로그인 전에는 관리자 화면 자체가 `hidden` 처리되어 렌더링되지 않는다(공간도 차지하지 않음).
- 로그인은 소비자 화면 위에 뜨는 **팝업**으로 처리하고, 성공 시에만 이 레이아웃이 나타난다.

## 3. 매출 차트 화면 — 별도 전체 화면

```mermaid
flowchart TB
  ctop["매출 차트                     [← 관리자 모드로]"]
  controls["차트종류: 막대·선·파이     기준: 일자별·상품별     (기간: 일별·월별)"]
  chartTitle["차트 제목 (예: 일별 매출 추이 - 막대 차트)"]
  chart["Google Charts 렌더링 영역 (X/Y축 제목·단위 포함)"]
  secondary["(막대+일자별+일별일 때만) 일별 상품별 판매량 누적 막대그래프"]
  ctop --> controls --> chartTitle --> chart --> secondary
```

## 4. 화면 전환 관계

세 화면(소비자/관리자/차트)은 **동시에 하나만** 보인다. 전환은 `hidden` 속성 + opacity 트랜지션으로
처리한다.

```mermaid
flowchart LR
  A[소비자 화면] -- 관리자 버튼: 로그인 성공 --> B[관리자 화면]
  B -- 로그아웃 --> A
  B -- 매출조회: 차트보기 --> C[차트 화면]
  C -- 뒤로: 관리자 모드로 --> B
```
