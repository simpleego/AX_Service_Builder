# 소담상점 미니 쇼핑몰

HTML, CSS, JavaScript를 처음 배우는 사람을 위한 다중 페이지 쇼핑몰 예제입니다.

## 파일 안내

- `index.html`: 상품 목록과 검색
- `login.html`: 회원 로그인 폼
- `product.html`: 상품 상세 정보
- `cart.html`: 장바구니와 수량 변경
- `checkout.html`: 배송 정보와 결제 폼
- `complete.html`: 주문 완료 화면
- `style.css`: 모든 페이지의 디자인
- `script.js`: 검색, 장바구니, 폼 처리 기능

`index.html`을 브라우저에서 열면 시작할 수 있습니다. 장바구니 데이터는 브라우저의 `localStorage`에 저장됩니다.
