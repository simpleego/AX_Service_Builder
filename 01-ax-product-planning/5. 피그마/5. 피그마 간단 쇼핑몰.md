# 피그마 쇼핑몰 만들기

## 1. 최종적으로 만들 화면

간단한 상품 목록 페이지를 만든다고 하겠습니다.

```text
┌──────────────────────────────────────────────┐
│ SIMPLE SHOP                         장바구니 │
├──────────────────────────────────────────────┤
│                                              │
│           인기 상품                          │
│                                              │
│   ┌─────────┐ ┌─────────┐ ┌─────────┐       │
│   │ 이미지  │ │ 이미지  │ │ 이미지  │       │
│   │ 노트북  │ │ 키보드  │ │ 마우스  │       │
│   │120만원  │ │ 8만원   │ │ 5만원   │       │
│   │ [구매]  │ │ [구매]  │ │ [구매]  │       │
│   └─────────┘ └─────────┘ └─────────┘       │
│                                              │
└──────────────────────────────────────────────┘
```

이 화면을 Figma에서는 다음 계층으로 설계합니다.

```text
Section : 쇼핑몰 상품관리
│
└─ Frame : ProductPage
    │
    ├─ Frame : Header
    │    ├─ Text : SIMPLE SHOP
    │    └─ Button : 장바구니
    │
    └─ Frame : Main
         │
         ├─ Text : 인기 상품
         │
         └─ Frame : ProductList
              │
              ├─ Instance : ProductCard
              ├─ Instance : ProductCard
              └─ Instance : ProductCard
```

여기서 `Header`, `Main`, `ProductList`, `ProductCard`에는 Auto Layout을 적용합니다.

# 2. Figma Section 만들기

먼저 Section을 만듭니다.

```text
Section 이름
쇼핑몰 상품관리
```

예를 들어 크기는 다음 정도면 충분합니다.

```text
1600 × 1100
```

하지만 이 숫자는 중요한 것이 아닙니다.

Section은 다음 Frame을 정리하기 위한 영역일 뿐입니다.

```text
Section
┌───────────────────────────────────────────┐
│                                           │
│       Frame : ProductPage                 │
│       ┌───────────────────────────┐       │
│       │                           │       │
│       │       실제 디자인         │       │
│       │                           │       │
│       └───────────────────────────┘       │
│                                           │
└───────────────────────────────────────────┘
```

Figma에서도 Section은 관련 디자인 요소를 묶어 정리하는 컨테이너로 사용됩니다. ([Figma 도움말 센터][2])

따라서 여기까지는 **HTML 코드가 생기지 않는다고 생각하는 것이 좋습니다.**

```text
Figma Section
     ↓
HTML 변환 대상 아님
     ↓
디자인 파일 관리용
```

# 3. 실제 웹페이지 Frame 만들기

Section 안에 Frame을 만듭니다.

```text
Frame 이름 : ProductPage

Width  : 1440
Height : 900
```

이 Frame부터 실제 웹페이지에 대응한다고 생각하면 됩니다.

```text
Figma

Frame : ProductPage
```

HTML에서는:

```html
<div class="product-page">

</div>
```

또는 HTML의 의미까지 고려하면:

```html
<body>

</body>
```

에 대응시킬 수도 있습니다.

여기서 중요한 점은 **Figma Frame = 무조건 `<div>`는 아니다**라는 것입니다.

# 4. ProductPage에 Auto Layout 적용

ProductPage 안에는 크게 두 영역이 있습니다.

```text
Header
Main
```

위에서 아래로 배치합니다.

따라서 ProductPage에:

```text
Auto Layout

Direction : Vertical
Gap       : 0
```

을 설정합니다.

Figma 구조:

```text
ProductPage
    ↓ Vertical Auto Layout

Header
↓
Main
```

CSS에서는:

```css
.product-page {
    display: flex;
    flex-direction: column;
}
```

즉,

```text
Figma Auto Layout : Vertical
               ↓
CSS
display: flex;
flex-direction: column;
```

입니다.

Auto Layout이 Frame 내부 요소의 간격과 배치를 관리한다는 것이 Figma의 기본적인 사용 방식입니다. ([Figma 도움말 센터][3])

# 5. Header 만들기

Header 안에는:

```text
로고                         장바구니
```

가 들어갑니다.

Figma 구조:

```text
Frame : Header

Auto Layout
Direction : Horizontal
Justify   : Space Between
Align     : Center
Padding   : 24px 40px
```

즉:

```text
┌─────────────────────────────────────┐
│ SIMPLE SHOP               장바구니 │
└─────────────────────────────────────┘
```

CSS로 바꾸면 거의 그대로입니다.

```css
.header {
    display: flex;

    flex-direction: row;

    justify-content: space-between;
    align-items: center;

    padding: 24px 40px;
}
```

이 부분이 학생들에게 **Auto Layout과 Flexbox의 관계를 설명하기 가장 좋은 부분**입니다.

| Figma         | CSS                             |
| ------------- | ------------------------------- |
| Auto Layout   | `display:flex`                  |
| Horizontal    | `flex-direction:row`            |
| Vertical      | `flex-direction:column`         |
| Space Between | `justify-content:space-between` |
| Center        | `align-items:center`            |
| Gap 20        | `gap:20px`                      |
| Padding 24    | `padding:24px`                  |

2026년 현재 Figma의 새로운 Auto Layout은 이런 CSS Flexbox 대응을 더 직접적으로 하도록 설계되어 있고 Dev Mode 코드도 Flexbox 속성에 더 직접적으로 매핑됩니다. ([Figma 도움말 센터][4])

# 6. Main 영역 만들기

Main은:

```text
인기 상품

상품목록
```

구조입니다.

따라서 Vertical Auto Layout을 적용합니다.

```text
Frame : Main

Auto Layout
Direction : Vertical

Gap     : 24
Padding : 40px
```

Figma:

```text
Main
│
├─ 인기 상품
│
└─ ProductList
```

CSS:

```css
.main {
    display: flex;
    flex-direction: column;

    gap: 24px;
    padding: 40px;
}
```

HTML은 의미를 고려해서 다음처럼 만들 수 있습니다.

```html
<main class="main">

</main>
```

여기서 Figma의 `Frame Main`을 실제 HTML에서는 `<div>`가 아니라 `<main>`으로 바꾼 것입니다.

이 부분은 AI를 이용한 변환에서도 중요합니다.

```text
Figma 구조 분석
        +
HTML 의미 분석
        ↓
적절한 시맨틱 태그 결정
```

# 7. ProductList 만들기

상품 카드를 옆으로 배치합니다.

```text
[상품1] [상품2] [상품3]
```

따라서:

```text
Frame : ProductList

Auto Layout
Direction : Horizontal

Gap  : 24
Wrap : On
```

으로 설정합니다.

CSS:

```css
.product-list {
    display: flex;

    flex-direction: row;
    flex-wrap: wrap;

    gap: 24px;
}
```

이것도 거의 1:1입니다.

```text
Figma
Horizontal
Wrap
Gap 24

        ↓

CSS

display:flex;
flex-direction:row;
flex-wrap:wrap;
gap:24px;
```

# 8. ProductCard Component 만들기

이제 가장 중요한 Component입니다.

상품 하나의 구조는:

```text
ProductCard

┌─────────────────┐
│                 │
│     이미지      │
│                 │
├─────────────────┤
│ 노트북          │
│ ₩1,200,000      │
│                 │
│    구매하기     │
└─────────────────┘
```

Figma에서는:

```text
Component : ProductCard

Auto Layout
Direction : Vertical
Gap       : 12
Padding   : 16

Width     : 280
Height    : Hug
```

레이어는:

```text
ProductCard
│
├─ Image
├─ ProductName
├─ Price
└─ Button
```

입니다.

Figma Component는 재사용 가능한 디자인 요소이고, Main Component에서 만들어진 복사본이 Instance입니다. ([Figma 도움말 센터][5])

CSS는:

```css
.product-card {
    width: 280px;

    display: flex;
    flex-direction: column;

    gap: 12px;
    padding: 16px;

    border: 1px solid #ddd;
    border-radius: 10px;
}
```

# 9. Component를 Instance로 반복 사용

Main Component는 한 번만 만듭니다.

```text
Main Component
ProductCard
```

그 다음 실제 ProductList에는 Instance를 넣습니다.

```text
ProductList
│
├─ ProductCard Instance
├─ ProductCard Instance
└─ ProductCard Instance
```

Figma의 핵심은:

```text
Component
    ↓
Instance
Instance
Instance
```

입니다.

HTML에서는 동일한 클래스를 반복 사용합니다.

```html
<div class="product-card">
    ...
</div>

<div class="product-card">
    ...
</div>

<div class="product-card">
    ...
</div>
```

즉:

```text
Figma Component
       ↓
CSS Class

ProductCard
       ↓
.product-card
```

이라고 초보자에게 설명해도 상당히 이해하기 쉽습니다.

# 10. 완성된 Figma Layers 구조

실제 왼쪽 Layers 패널은 이런 모습이 됩니다.

```text
▼ Section : 쇼핑몰 상품관리

    ▼ Frame : ProductPage
        │
        ├─ ▼ Header
        │     ├─ Logo
        │     └─ CartButton
        │
        └─ ▼ Main
              │
              ├─ Title
              │
              └─ ▼ ProductList
                    │
                    ├─ ◇ ProductCard Instance
                    ├─ ◇ ProductCard Instance
                    └─ ◇ ProductCard Instance
```

그리고 별도로 Main Component가 있습니다.

```text
Components

◆ ProductCard
    ├─ Image
    ├─ ProductName
    ├─ Price
    └─ BuyButton
```

# 11. 이것을 HTML로 변환

전체 HTML은 다음처럼 만들 수 있습니다.

```html
<!DOCTYPE html>

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Simple Shop</title>

    <link rel="stylesheet" href="style.css">
</head>

<body>

<div class="product-page">

    <header class="header">

        <h1 class="logo">
            SIMPLE SHOP
        </h1>

        <button class="cart-button">
            장바구니
        </button>

    </header>


    <main class="main">

        <h2>인기 상품</h2>


        <section class="product-list">

            <article class="product-card">

                <div class="product-image">
                    상품 이미지
                </div>

                <h3>노트북</h3>

                <p class="price">
                    ₩1,200,000
                </p>

                <button>
                    구매하기
                </button>

            </article>


            <article class="product-card">

                <div class="product-image">
                    상품 이미지
                </div>

                <h3>키보드</h3>

                <p class="price">
                    ₩80,000
                </p>

                <button>
                    구매하기
                </button>

            </article>


            <article class="product-card">

                <div class="product-image">
                    상품 이미지
                </div>

                <h3>마우스</h3>

                <p class="price">
                    ₩50,000
```

여기서 주목할 점은 Figma에는:


```html

<main>
<section>

```

같은 **시맨틱 태그로 개선했다는 것**입니다.

# 13. 이제 Figma와 코드를 나란히 보면 핵심이 보입니다

| Figma 작업                | HTML/CSS                              |
| ----------------------- | ------------------------------------- |
| Section `쇼핑몰 상품관리`      | 코드 변환 없음                              |
| Frame `ProductPage`     | `.product-page`                       |
| Vertical Auto Layout    | `display:flex; flex-direction:column` |
| Frame `Header`          | `<header>`                            |
| Horizontal Auto Layout  | `flex-direction:row`                  |
| Space Between           | `justify-content:space-between`       |
| Center                  | `align-items:center`                  |
| Padding 24 / 40         | `padding:24px 40px`                   |
| Frame `Main`            | `<main>`                              |
| Frame `ProductList`     | `<section>`                           |
| Horizontal + Wrap       | `display:flex; flex-wrap:wrap`        |
| Gap 24                  | `gap:24px`                            |
| Component `ProductCard` | `.product-card`                       |
| ProductCard Instance    | `<article class="product-card">`      |
| Gap 12                  | `gap:12px`                            |
| Padding 16              | `padding:16px`                        |
| Corner radius 10        | `border-radius:10px`                  |

여기서 학생들에게 보여주고 싶은 핵심은 **CSS를 나중에 억지로 작성하는 것이 아니라 Figma에서 이미 레이아웃 규칙을 정의했다**는 것입니다.

# 14. 특히 중요한 개념: 디자인의 “모양”이 아니라 “규칙”을 변환한다

잘못 만든 Figma라면 상품 카드 세 개를 이렇게 놓을 수도 있습니다.

```text
상품1 위치 X = 100
상품2 위치 X = 404
상품3 위치 X = 708
```

그러면 변환 프로그램은 잘못하면:

```css
.card1 {
    position: absolute;
    left: 100px;
}

.card2 {
    position: absolute;
    left: 404px;
}

.card3 {
    position: absolute;
    left: 708px;
}
```

같은 코드를 만들어낼 수도 있습니다.

좋은 Figma 설계는 이렇게 합니다.

```text
ProductList

Auto Layout : Horizontal
Gap         : 24
Wrap        : On
```

그러면 코드에서도:

```css
.product-list {
    display: flex;
    gap: 24px;
    flex-wrap: wrap;
}
```

가 됩니다.

즉 수업에서는 다음 문장을 강조하면 좋습니다.

> **Figma를 HTML/CSS로 잘 변환하려면 화면을 예쁘게 그리는 것보다 레이아웃의 규칙을 제대로 설계해야 한다.**

# 15. 그래서 실제 변환 과정은 이렇게 이해하면 됩니다

```text
                 Figma
                   │
                   ▼
        Section : 프로젝트 정리
                   │
                   ▼
        Frame : 실제 화면 구조
                   │
                   ▼
        Auto Layout : 배치 규칙
                   │
           ┌───────┴────────┐
           ▼                ▼
      Horizontal         Vertical
           │                │
           ▼                ▼
       Flex Row        Flex Column
                   │
                   ▼
        Component : 반복 UI
                   │
                   ▼
        CSS Class / Component
                   │
                   ▼
              HTML + CSS
```

그리고 **Figma → 웹 개발 교육에서 가장 중요한 연결 관계**는 사실 다음 한 줄로 압축됩니다.

```text
Figma
Frame + Auto Layout + Component
                ↓
HTML/CSS
Semantic HTML + Flex/Grid + Reusable Class
```

이 예제를 학생들과 실제 실습한다면 **1단계 Figma 제작 → 2단계 Figma 구조표 작성 → 3단계 HTML만 작성 → 4단계 Auto Layout을 보고 CSS Flex 작성 → 5단계 Component 반복 적용** 순서로 진행하는 것이 좋습니다. 이렇게 하면 학생들이 Figma와 HTML/CSS를 별개의 기술로 배우지 않고 **“같은 UI 구조를 디자인 언어와 코드 언어로 각각 표현하는 것”**이라고 이해하게 됩니다.
