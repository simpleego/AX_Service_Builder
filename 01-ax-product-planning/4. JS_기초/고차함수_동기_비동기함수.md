질문의 “동기/비동시”는 **동기·비동기 함수**를 의미하는 것으로 보고 설명하겠습니다.

먼저 두 개념은 구분해야 합니다.

* **고차함수**: 함수를 인수로 받거나, 함수를 반환하는 함수입니다.
* **동기·비동기**: 작업을 실행하고 결과를 처리하는 방식의 차이입니다.

따라서 **고차함수라고 반드시 비동기 함수인 것은 아닙니다.** 예를 들어 `map()`은 고차함수이지만, 전달받은 콜백을 동기적으로 호출합니다.

---

**1. 고차함수를 이해하기 위한 출발점: 함수도 값이다**

자바스크립트에서는 숫자나 문자열처럼 **함수도 변수에 저장하고, 다른 함수에 전달하고, 반환할 수 있습니다.**

```javascript
// 숫자를 변수에 저장
const price = 10000;

// 함수를 변수에 저장
const greet = function (name) {
    return `${name}님, 안녕하세요.`;
};

// 변수에 저장한 함수 실행
console.log(greet("심플"));
```

화살표 함수로도 같은 역할을 표현할 수 있습니다.

```javascript
const greet = (name) => {
    return `${name}님, 안녕하세요.`;
};

console.log(greet("심플"));
```

여기서 가장 중요한 구분은 **함수 자체와 함수 실행 결과**입니다.

```javascript
function sayHello() {
    return "안녕하세요.";
}

console.log(sayHello);   // 함수 자체
console.log(sayHello()); // 함수를 실행한 결과: "안녕하세요."
```

| 표현           | 의미         | 비유          |
| ------------ | ---------- | ----------- |
| `sayHello`   | 함수 자체      | 요리법         |
| `sayHello()` | 함수를 실행한 결과 | 요리법으로 만든 음식 |

다른 함수에 작업을 맡길 때는 보통 **실행 결과가 아니라 함수 자체**를 전달합니다.

**2. 고차함수 실습 ①: 함수를 인수로 전달하기**

계산기를 만들 때, 숫자뿐 아니라 **계산 방법까지 전달**할 수 있습니다.

다음 코드는 브라우저 개발자 도구의 Console에서 실행할 수 있습니다.

```javascript
// 계산 방법 1
function add(a, b) {
    return a + b;
}

// 계산 방법 2
function multiply(a, b) {
    return a * b;
}

// 계산 방법을 전달받는 고차함수
function calculate(a, b, operation) {
    return operation(a, b);
}

console.log(calculate(10, 3, add));      // 13
console.log(calculate(10, 3, multiply)); // 30
```

`calculate(10, 3, add)`의 실행 과정을 풀어 쓰면 다음과 같습니다.

```javascript
// 전달되는 값
a = 10;
b = 3;
operation = add;

// calculate 내부에서 실행하는 코드
operation(a, b);

// 결국 다음과 같은 계산
add(10, 3);
```

위 코드는 실행 과정을 설명하기 위한 표현이며, 실제 실행은 첫 번째 코드만 하면 됩니다.

이때 용어를 구분하면 다음과 같습니다.

| 대상                    | 이름    | 이유                |
| --------------------- | ----- | ----------------- |
| `calculate`           | 고차함수  | 다른 함수를 인수로 받음     |
| 전달된 `add`, `multiply` | 콜백 함수 | 전달받은 함수가 내부에서 호출됨 |

**콜백 함수는 “나중에 호출하도록 전달한 함수”이며, 여기서 ‘나중’이 반드시 비동기를 뜻하지는 않습니다.** 위 예시는 즉시 순서대로 실행되는 동기 코드입니다.

화살표 함수를 직접 전달하면 더 짧게 작성할 수 있습니다.

```javascript
console.log(calculate(10, 3, (a, b) => a - b)); // 7
console.log(calculate(10, 3, (a, b) => a / b)); // 약 3.33
```

실습 과제:

1. 나머지를 계산하는 함수를 전달해 보세요.
2. 두 수 중 큰 수를 반환하는 함수를 전달해 보세요.

정답:

```javascript
console.log(calculate(10, 3, (a, b) => a % b)); // 1

console.log(
    calculate(10, 3, (a, b) => a > b ? a : b)
); // 10
```

**3. 고차함수 실습 ②: 배열 처리에 활용하기**

상품 목록처럼 여러 데이터를 처리할 때 고차함수를 자주 사용합니다.

```javascript
const products = [
    { id: 1, name: "마우스", price: 20000, stock: 5 },
    { id: 2, name: "키보드", price: 50000, stock: 0 },
    { id: 3, name: "모니터", price: 200000, stock: 3 }
];
```

**① `forEach()` — 각 항목에 대해 작업하기**

```javascript
products.forEach((product) => {
    console.log(`${product.name}: ${product.price}원`);
});
```

출력:

```text
마우스: 20000원
키보드: 50000원
모니터: 200000원
```

`forEach()` 자체의 반환값은 `undefined`입니다. 새로운 배열을 만드는 목적이라면 `map()`을 사용합니다.

**② `map()` — 항목을 변환한 새 배열 만들기**

```javascript
const productNames = products.map((product) => {
    return product.name;
});

console.log(productNames);
// ["마우스", "키보드", "모니터"]
```

각 상품에 할인 가격을 추가할 수도 있습니다.

```javascript
const discountedProducts = products.map((product) => {
    return {
        ...product,
        discountPrice: product.price * 0.9
    };
});

console.table(discountedProducts);
```

여기서는 각 상품을 새 객체로 만들었으므로 원래 상품 객체에 할인 가격을 추가하지 않습니다.

**③ `filter()` — 조건에 맞는 항목만 선택하기**

```javascript
const availableProducts = products.filter((product) => {
    return product.stock > 0;
});

console.table(availableProducts);
// 마우스, 모니터
```

**④ `find()` — 조건에 맞는 첫 번째 항목 찾기**

```javascript
const selectedProduct = products.find((product) => {
    return product.id === 2;
});

console.log(selectedProduct);
// { id: 2, name: "키보드", price: 50000, stock: 0 }
```

**⑤ `reduce()` — 여러 값을 하나의 결과로 누적하기**

```javascript
const cart = [
    { name: "마우스", price: 20000, quantity: 2 },
    { name: "키보드", price: 50000, quantity: 1 }
];

const totalPrice = cart.reduce((total, item) => {
    return total + item.price * item.quantity;
}, 0);

console.log(totalPrice); // 90000
```

`reduce()`의 마지막 인수인 `0`은 누적값의 시작값입니다.

| 단계  | 기존 `total` |   이번 상품 금액 | 반환하는 누적값 |
| --- | ---------: | ---------: | -------: |
| 시작  |          0 |          — |        0 |
| 마우스 |          0 | 20,000 × 2 |   40,000 |
| 키보드 |     40,000 | 50,000 × 1 |   90,000 |

핵심을 비교하면 다음과 같습니다.

| 함수        | 콜백이 반환할 내용   | 전체 결과               |
| --------- | ------------ | ------------------- |
| `forEach` | 일반적으로 반환 불필요 | `undefined`         |
| `map`     | 변환한 값        | 새 배열                |
| `filter`  | 선택 여부        | 조건에 맞는 새 배열         |
| `find`    | 일치 여부        | 첫 항목 또는 `undefined` |
| `reduce`  | 다음 누적값       | 최종 누적 결과            |

**4. 고차함수 실습 ③: 함수를 반환하기**

고차함수는 다른 함수를 받아야만 하는 것이 아닙니다. **함수를 반환하는 함수도 고차함수**입니다.

```javascript
function createDiscountCalculator(rate) {
    return function (price) {
        return price * (1 - rate);
    };
}

// 할인율이 설정된 함수를 생성
const normalDiscount = createDiscountCalculator(0.1);
const vipDiscount = createDiscountCalculator(0.2);

// 만들어진 함수 사용
console.log(normalDiscount(10000)); // 9000
console.log(vipDiscount(10000));    // 8000
```

두 단계로 이해하면 쉽습니다.

```javascript
// 1단계: 할인율을 정하여 계산기 만들기
const vipDiscount = createDiscountCalculator(0.2);

// 2단계: 만들어진 계산기에 상품 가격 넣기
const result = vipDiscount(10000);
```

반환된 함수가 자신이 만들어질 때의 `rate`에 접근할 수 있는 것은 **클로저(closure)** 덕분입니다.

학생들에게는 **“할인율을 기억하는 계산기를 만든다”**고 설명하면 직관적입니다.

**5. 동기 처리: 현재 작업이 끝난 뒤 다음 작업 실행**

동기 코드는 현재 작업이 끝나야 다음 코드로 넘어갑니다.

```javascript
function calculateTotal(price, quantity) {
    console.log("2. 금액 계산");
    return price * quantity;
}

console.log("1. 주문 시작");

const total = calculateTotal(20000, 3);

console.log("3. 결제 금액:", total);
console.log("4. 주문 종료");
```

출력 순서:

```text
1. 주문 시작
2. 금액 계산
3. 결제 금액: 60000
4. 주문 종료
```

앞에서 본 `map()`도 콜백을 동기적으로 호출합니다.

```javascript
console.log("1. 변환 시작");

const result = [1, 2, 3].map((number) => {
    console.log("2. 변환 중:", number);
    return number * 10;
});

console.log("3. 변환 결과:", result);
```

출력:

```text
1. 변환 시작
2. 변환 중: 1
2. 변환 중: 2
2. 변환 중: 3
3. 변환 결과: [10, 20, 30]
```

**동기 처리가 나쁘다는 뜻은 아닙니다.** 간단한 계산과 데이터 변환에는 자연스러운 방식입니다. 다만 브라우저의 메인 스레드에서 긴 계산을 동기적으로 수행하면 화면 갱신이나 클릭 처리가 지연될 수 있습니다.

---

**6. 비동기 처리: 완료를 기다리는 동안 다른 코드 진행**

서버 요청이나 타이머처럼 기다림이 있는 작업은 비동기 방식으로 처리할 수 있습니다.

```javascript
console.log("1. 시작");

setTimeout(() => {
    console.log("2. 예약한 작업 실행");
}, 2000);

console.log("3. 다음 작업");
```

실제 출력 순서:

```text
1. 시작
3. 다음 작업
2. 예약한 작업 실행
```

실행 과정은 다음과 같습니다.

1. `"1. 시작"`을 출력합니다.
2. 콜백을 약 2초 뒤 실행할 수 있도록 예약합니다.
3. 기다리지 않고 `"3. 다음 작업"`을 출력합니다.
4. 시간이 지나고 실행 가능한 시점에 콜백을 실행합니다.

`2000`은 밀리초 단위이며 2초를 뜻합니다. **정확히 2초에 실행된다는 보장은 없고**, 다른 작업 때문에 더 늦게 실행될 수 있습니다.

또한 비동기는 곧 “자바스크립트 코드 여러 개를 동시에 실행한다”는 뜻은 아닙니다. 이 예시에서는 **타이머를 기다리는 시간에 다음 코드를 진행하는 것**입니다.

---

**7. 비동기 실습: Promise와 async/await**

**① Promise — 나중에 정해질 작업 결과**

`Promise`는 비동기 작업의 완료 여부와 결과를 다루는 객체입니다.

| 상태          | 의미           |
| ----------- | ------------ |
| `pending`   | 결과를 기다리는 중   |
| `fulfilled` | 성공하여 결과가 정해짐 |
| `rejected`  | 실패하여 오류가 정해짐 |

실제 AI 서버 없이, 2초 뒤 답변하는 함수를 만들어 보겠습니다.

```javascript
function requestAI(question) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            if (question.trim() === "") {
                reject(new Error("질문이 비어 있습니다."));
                return;
            }

            resolve(`"${question}"에 대한 AI 응답입니다.`);
        }, 2000);
    });
}
```

* `resolve(결과)`: 성공 결과를 전달합니다.
* `reject(오류)`: 실패를 전달합니다.
* `setTimeout()`: 서버 응답을 기다리는 상황을 흉내 냅니다.

이 예시의 `new Promise(...)` 안에 전달한 함수는 즉시 실행되지만, 타이머 콜백이 나중에 실행되므로 결과는 나중에 정해집니다.

**② `.then()` — 성공 결과 처리하기**

```javascript
console.log("1. 질문 전송");

requestAI("자바스크립트란?")
    .then((answer) => {
        console.log("3. 답변 도착:", answer);
    })
    .catch((error) => {
        console.log("오류:", error.message);
    });

console.log("2. 다른 작업 진행");
```

출력:

```text
1. 질문 전송
2. 다른 작업 진행
3. 답변 도착: "자바스크립트란?"에 대한 AI 응답입니다.
```

**③ `async/await` — 비동기 처리 순서를 읽기 쉽게 표현하기**

앞의 코드를 `async/await`으로 표현하면 다음과 같습니다.

```javascript
async function runChat() {
    console.log("1. 질문 전송");

    try {
        const answer = await requestAI("자바스크립트란?");
        console.log("3. 답변 도착:", answer);
    } catch (error) {
        console.log("오류:", error.message);
    }

    console.log("4. 질문 처리 종료");
}

runChat();

console.log("2. 다른 작업 진행");
```

출력:

```text
1. 질문 전송
2. 다른 작업 진행
3. 답변 도착: "자바스크립트란?"에 대한 AI 응답입니다.
4. 질문 처리 종료
```

**`await`은 브라우저 전체를 멈추지 않습니다.** 해당 `async` 함수의 다음 단계 진행을 잠시 중단하고, 기다리는 동안 다른 코드가 실행될 수 있도록 합니다.

또한 `async` 함수는 항상 Promise를 반환합니다.

```javascript
async function getNumber() {
    return 10;
}

console.log(getNumber()); // Promise 객체

getNumber().then((number) => {
    console.log(number); // 10
});
```

`async`를 붙인다고 오래 걸리는 계산이 자동으로 별도 스레드에서 실행되지는 않습니다.

        <p id="answer" aria-live="polite">답변 대기 중</p>

    <script>

**9. 추가 실습: 순차 요청과 동시 요청**

독립적인 데이터를 여러 개 받아야 할 때는 요청 방식에 따라 대기 시간이 달라집니다.

공통으로 사용할 모의 요청 함수입니다.

```javascript
function getData(name, delay) {
    return new Promise((resolve) => {
        setTimeout(() => {
            resolve(`${name} 조회 완료`);
        }, delay);
    });
}
```

**① 순차 요청: 첫 작업 완료 후 다음 작업 시작**

```javascript
async function runSequential() {
    console.time("순차 요청");

    const products = await getData("상품", 2000);
    const notices = await getData("공지사항", 2000);

    console.log(products);
    console.log(notices);

    console.timeEnd("순차 요청");
}

runSequential();
```

총 대기 시간은 약 4초입니다.

**② 동시 요청: 두 작업을 먼저 시작한 뒤 모두 기다리기**

```javascript
async function runConcurrent() {
    console.time("동시 요청");

    const [products, notices] = await Promise.all([
        getData("상품", 2000),
        getData("공지사항", 2000)
    ]);

    console.log(products);
    console.log(notices);

    console.timeEnd("동시 요청");
}

runConcurrent();
```

총 대기 시간은 약 2초입니다.

두 요청은 배열을 만드는 과정에서 먼저 시작됩니다. `Promise.all()`은 두 결과를 모아 기다립니다.

| 상황                       | 적절한 방식 | 이유                |
| ------------------------ | ------ | ----------------- |
| 상품 목록과 공지사항 조회           | 동시 요청  | 서로 결과가 필요하지 않음    |
| 로그인 후 사용자 주문 조회          | 순차 요청  | 앞 작업의 인증 결과가 필요함  |
| 문서 검색 후 검색 내용으로 AI 답변 생성 | 순차 요청  | 검색 결과가 AI 입력에 필요함 |

`Promise.all()`은 하나라도 실패하면 실패로 처리됩니다. 이미 시작한 다른 작업을 자동으로 취소하지는 않습니다.

**10. 학생들이 자주 혼동하는 부분**

**① 함수를 전달해야 하는 자리에 실행 결과를 전달하기**

```javascript
// 잘못된 의도: 즉시 sayHello를 실행하고 그 반환값을 전달
button.addEventListener("click", sayHello());

// 올바른 방식: 클릭했을 때 실행할 함수를 전달
button.addEventListener("click", sayHello);

// 인수가 필요하면 함수로 감싸서 전달
button.addEventListener("click", () => {
    greet("심플");
});
```

**② `await` 없이 비동기 결과를 사용하기**

```javascript
// answer는 문자열이 아니라 Promise
const answer = requestAI("안녕하세요");
console.log(answer);
```

결과를 사용하려면 `async` 함수 안에서 기다리거나 `.then()`을 사용합니다.

```javascript
async function showAnswer() {
    const answer = await requestAI("안녕하세요");
    console.log(answer);
}

showAnswer();
```

**③ `forEach(async ...)`가 전체 완료를 기다린다고 생각하기**

```javascript
const names = ["상품", "주문", "배송"];

names.forEach(async (name) => {
    const result = await getData(name, 1000);
    console.log(result);
});

console.log("전체 완료"); // 조회 결과보다 먼저 출력됨
```

`forEach()`는 각 콜백이 반환한 Promise를 기다리지 않습니다.

순서대로 완료하려면:

```javascript
async function loadSequentially() {
    for (const name of names) {
        const result = await getData(name, 1000);
        console.log(result);
    }

    console.log("전체 완료");
}

loadSequentially();
```

함께 시작하고 모두 완료되기를 기다리려면:

```javascript
async function loadTogether() {
    const results = await Promise.all(
        names.map((name) => getData(name, 1000))
    );

    console.log(results);
    console.log("전체 완료");
}

loadTogether();
```

이 마지막 예시는 **고차함수인 `map()`으로 비동기 작업의 Promise 배열을 만들고, `Promise.all()`로 전체 결과를 기다리는 방식**입니다.

수업에서는 **함수 전달 → 배열 고차함수 → 타이머 실행 순서 → Promise → async/await → 여러 요청 처리** 순서로 실습하면 각 개념이 자연스럽게 연결됩니다.
