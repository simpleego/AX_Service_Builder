# 7. 고차함수 이해 
> **함수도 데이터이다.**  
> 핵심은 **함수가 어떤 일을 수행하는 코드이면서도, 파이썬에서는 그 함수 자체를 하나의 값(value)처럼 저장·전달·반환할 수 있기 때문**입니다.

사과 비유를 그대로 사용하면 다음처럼 볼 수 있습니다.

```text
나
 │
 ├─ 사과 전달 ──────────→ 동생
 │                        ↑
 └─ 칼 전달 ─────────────┘
```

동생 입장에서 보면 두 가지를 전달받았습니다.

* 사과 → 처리해야 할 **일반 데이터**
* 칼 → 사과를 깎는 **기능을 가진 도구**

프로그래밍으로 바꾸면 다음과 비슷합니다.

```python
def peel(apple):
    return "껍질을 깎은 " + apple
```

여기서:

```text
apple
→ 일반 데이터

peel
→ 기능을 수행하는 함수
```

그런데 파이썬에서는 이 `peel` 자체를 다른 함수에게 넘겨줄 수 있습니다.

```python
def brother(tool, apple):
    return tool(apple)

def peel(apple):
    return "껍질을 깎은 " + apple

result = brother(peel, "사과")

print(result)
```

결과:

```text
껍질을 깎은 사과
```

이것을 실제 상황과 대응시키면 꽤 정확합니다.

```text
brother(peel, "사과")

        ↓

동생에게

칼     +    사과
peel        "사과"

를 함께 전달
```

여기서 `brother()` 입장에서는 `peel`이라는 함수가 **매개변수로 전달된 값**입니다.

그래서 “칼이 함수이면서 데이터인가?”라는 질문에는 **프로그래밍 비유로는 그렇다고 볼 수 있습니다.**

다만 더 정확히 표현하면:

> **칼은 기능을 수행할 수 있는 도구이고, 그 도구 자체를 다른 사람에게 전달할 수 있다는 점에서 함수 객체와 비슷하다.**

입니다.

---

## 왜 이것을 굳이 "함수도 데이터다"라고 할까?

일반적인 데이터는 변수에 저장할 수 있습니다.

```python
a = 10
name = "홍길동"
```

그런데 파이썬에서는 함수도 똑같이 변수에 넣을 수 있습니다.

```python
def peel(apple):
    return "깎은 " + apple

knife = peel
```

이제:

```python
knife("사과")
```

라고 해도 실행됩니다.

즉:

```text
peel ───────┐
            ↓
       함수 객체
            ↑
knife ──────┘
```

`knife`와 `peel`이 같은 함수 객체를 가리키게 됩니다.

---

## 여기서 아주 중요한 `()` 차이

이 개념을 이해할 때 가장 중요한 부분입니다.

```python
knife = peel
```

과

```python
knife = peel("사과")
```

는 완전히 다릅니다.

첫 번째:

```python
knife = peel
```

은

> **칼 자체를 전달한다**

라고 생각하면 됩니다.

두 번째:

```python
knife = peel("사과")
```

은

> **칼로 이미 사과를 깎은 결과를 전달한다**

에 가깝습니다.

즉:

```text
peel
→ 함수 자체
→ 칼 자체

peel("사과")
→ 함수 실행
→ 칼로 사과를 깎는 행위 실행
→ 그 결과
```

이 차이가 고차 함수, 콜백, 데코레이터를 이해하는 핵심입니다.

# 조금 더 정확하게 비유해 보면

동생에게 이렇게 말한다고 해보겠습니다.

> "사과를 줄 테니까 이 칼로 깎아줘."

프로그래밍에서는:

```python
brother(peel, apple)
```

입니다.

`brother()`는 어떤 도구를 받을지 미리 알 필요가 없습니다.

예를 들어 칼 대신 다른 도구를 전달할 수도 있습니다.

```python
def peel(apple):
    return "껍질 제거: " + apple

def cut(apple):
    return "4등분: " + apple

def wash(apple):
    return "세척: " + apple
```

그리고:

```python
def brother(tool, apple):
    return tool(apple)
```

이제:

```python
print(brother(peel, "사과"))
print(brother(cut, "사과"))
print(brother(wash, "사과"))
```

라고 할 수 있습니다.

즉 `brother()` 입장에서는:

```text
어떤 작업인가?
       ↓
tool이라는 데이터로 전달받음

무엇을 처리할 것인가?
       ↓
apple이라는 데이터로 전달받음
```

입니다.

이게 바로 **함수를 매개변수로 전달하는 고차 함수의 핵심 구조**입니다.

---

## 그래서 일반 데이터와 함수 데이터의 차이는?

이렇게 구분하면 좋습니다.

| 전달하는 것    | 역할              |
| --------- | --------------- |
| `"사과"`    | 무엇을 처리할 것인가     |
| `10`      | 어떤 값을 사용할 것인가   |
| `[1,2,3]` | 어떤 데이터를 처리할 것인가 |
| `peel`    | **어떻게 처리할 것인가** |

이 마지막이 중요합니다.

보통 데이터는:

> **무엇(What)**

을 전달합니다.

함수는 값처럼 전달되면서:

> **어떻게(How)**

를 전달합니다.

그래서 함수형 프로그래밍을 설명할 때는 이렇게 표현하면 상당히 직관적입니다.

> **일반 데이터는 '무엇을 처리할지'를 전달하고, 함수 데이터는 '어떻게 처리할지'를 전달한다.**

---

# 파이썬에서 이것이 가능한 근본적인 이유

파이썬에서는 함수가 **객체(object)**이기 때문입니다.

함수를 정의하면:

```python
def peel(apple):
    return apple
```

단순히 코드만 존재하는 것이 아니라 파이썬 내부에 **함수 객체**가 만들어집니다.

그래서 다음이 가능합니다.

```python
print(type(peel))
```

결과:

```text
<class 'function'>
```

즉 `peel`은 실제로 `function` 타입의 객체입니다.

그래서 다른 객체와 마찬가지로:

```text
변수에 저장       O
리스트에 저장     O
함수에 전달       O
함수에서 반환     O
딕셔너리에 저장   O
```

할 수 있습니다.

예를 들어:

```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b

operations = [add, sub]

print(operations[0](10, 5))
print(operations[1](10, 5))
```

결과:

```text
15
5
```

함수들이 리스트 안에 **데이터처럼 들어가 있습니다.**

## 사과 비유를 조금 확장하면 더 좋습니다

학생들에게는 다음과 같이 설명해도 좋겠습니다.

```text
동생에게 전달

┌──────────────┐
│ 사과         │ → 무엇을 처리할 것인가
│ 칼           │ → 어떻게 처리할 것인가
└──────────────┘
```

Python:

```python
brother(
    peel,       # 어떻게 처리할 것인가
    "사과"      # 무엇을 처리할 것인가
)
```

이렇게 보면 매우 직관적입니다.

그리고 여기에 하나만 더 추가하면 완벽합니다.

> **칼 자체를 전달하는 것이 `peel`이고, 칼로 실제 사과를 깎는 것이 `peel("사과")`이다.**

이 비유가 특히 중요합니다.

```text
peel
= 칼 자체

peel()
= 칼을 사용하는 행위

peel("사과")
= 칼을 사용해서 사과를 처리한 결과
```
