# 4. 파이썬의 **제어문과 반복문**

- 프로그램의 실행 흐름을 결정하는 핵심 문법입니다. 비전공자 기준으로 보면, **제어문은 “조건에 따라 선택”**, **반복문은 “같은 작업을 여러 번 수행”**한다고 이해하면 됩니다.

## 1. 제어문 `if`

조건이 참인지 거짓인지에 따라 실행할 코드를 결정합니다.

기본 구조는 다음과 같습니다.

```python
if 조건:
    실행문
```

예를 들어 성인 여부를 판단하면:

```python
age = 20

if age >= 19:
    print("성인입니다.")
```

`age >= 19`가 `True`이면 실행됩니다.

---

## 2. `if ~ else`

조건이 참일 때와 거짓일 때 각각 다른 작업을 수행합니다.

```python
age = 17

if age >= 19:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

실행 결과:

```text
미성년자입니다.
```

구조는 다음과 같습니다.

```text
조건 검사
   ↓
 참 ──→ 실행문1
   ↓
 거짓 ─→ 실행문2
```

---

## 3. `if ~ elif ~ else`

조건이 여러 개일 때 사용합니다.

예를 들어 점수에 따라 등급을 출력할 수 있습니다.

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

결과:

```text
B
```

중요한 점은 **위에서부터 순서대로 검사한다는 것**입니다.

```text
90 이상?
   ↓ 아니오

80 이상?
   ↓ 예

"B" 출력
```

따라서 조건의 순서도 중요합니다.

---

## 4. 비교 연산자

`if`와 함께 가장 많이 사용하는 연산자입니다.

| 연산자  | 의미     |
| ---- | ------ |
| `==` | 같다     |
| `!=` | 같지 않다  |
| `>`  | 크다     |
| `<`  | 작다     |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |

예:

```python
age = 20

if age == 20:
    print("20살입니다.")
```

주의할 점은:

```python
=
```

은 값을 저장하는 **대입 연산자**이고,

```python
==
```

는 같은지 비교하는 **비교 연산자**입니다.

---

## 5. 논리 연산자

조건을 여러 개 결합할 때 사용합니다.

| 연산자   | 의미      |
| ----- | ------- |
| `and` | 모두 참    |
| `or`  | 하나라도 참  |
| `not` | 참/거짓 반전 |

예를 들어:

```python
age = 25
money = 10000

if age >= 19 and money >= 5000:
    print("영화를 볼 수 있습니다.")
```

두 조건이 모두 참이어야 합니다.

### `and`

```python
if age >= 19 and age <= 65:
    print("성인입니다.")
```

### `or`

```python
day = "토요일"

if day == "토요일" or day == "일요일":
    print("주말입니다.")
```

### `not`

```python
login = False

if not login:
    print("로그인이 필요합니다.")
```

# 6. 중첩 `if`

`if` 안에 또 다른 `if`를 사용할 수도 있습니다.

```python
age = 25
member = True

if age >= 19:
    if member:
        print("성인 회원입니다.")
```

하지만 너무 많은 중첩은 코드가 복잡해질 수 있습니다.

다음처럼 `and`를 사용하는 것이 더 간단할 수도 있습니다.

```python
if age >= 19 and member:
    print("성인 회원입니다.")
```

# 7. 반복문 `for`

정해진 횟수만큼 반복할 때 주로 사용합니다.

```python
for 변수 in 반복가능한데이터:
    실행문
```

예:

```python
for i in range(5):
    print(i)
```

결과:

```text
0
1
2
3
4
```

---

# 8. `range()` 이해하기

파이썬 반복문에서 매우 중요합니다.

### `range(5)`

```python
for i in range(5):
    print(i)
```

생성되는 숫자:

```text
0 1 2 3 4
```

즉:

```text
0부터 5 바로 전까지
```

입니다.

---

### `range(1, 6)`

```python
for i in range(1, 6):
    print(i)
```

결과:

```text
1
2
3
4
5
```

형식:

```python
range(시작, 끝)
```

끝 숫자는 포함되지 않습니다.

---

### `range(1, 11, 2)`

```python
for i in range(1, 11, 2):
    print(i)
```

결과:

```text
1
3
5
7
9
```

형식:

```python
range(시작, 끝, 증가값)
```

# 9. 리스트와 `for`

`for`는 숫자 반복뿐 아니라 리스트의 데이터를 하나씩 가져오는 데도 많이 사용합니다.

```python
fruits = ["사과", "바나나", "딸기"]

for fruit in fruits:
    print(fruit)
```

결과:

```text
사과
바나나
딸기
```

이것이 파이썬 `for`문의 큰 특징입니다.

```text
리스트에서 하나 꺼내기
        ↓
변수에 저장
        ↓
실행
        ↓
다음 데이터
```

# 12. `while` 반복문

조건이 참인 동안 계속 반복합니다.

```python
while 조건:
    실행문
```

예:

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

결과:

```text
1
2
3
4
5
```

실행 과정은:

```text
i = 1

i <= 5 ?
   ↓ YES

출력
i 증가

다시 조건 검사
```

입니다.

---

# 13. `for`와 `while` 차이

학생들에게는 이렇게 설명하면 쉽습니다.

| 구분       | `for`        | `while`      |
| -------- | ------------ | ------------ |
| 반복 횟수    | 비교적 명확       | 조건에 따라 결정    |
| 주요 사용    | 리스트, 숫자 반복   | 조건 반복        |
| 대표 예     | 학생 10명 점수 처리 | 비밀번호가 맞을 때까지 |
| 무한 반복 위험 | 낮음           | 있음           |

예를 들어:

### 학생 5명 처리

```python
for i in range(5):
    print("학생 처리")
```

→ `for` 적합

### 비밀번호가 맞을 때까지

```python
password = ""

while password != "1234":
    password = input("비밀번호: ")
```

→ `while` 적합

# 14. `break`

반복문을 강제로 종료합니다.

```python
for i in range(10):

    if i == 5:
        break

    print(i)
```

결과:

```text
0
1
2
3
4
```

`i == 5`가 되면 반복문 자체가 끝납니다.

---

# 15. `continue`

현재 반복만 건너뛰고 다음 반복으로 이동합니다.

```python
for i in range(1, 6):

    if i == 3:
        continue

    print(i)
```

결과:

```text
1
2
4
5
```

`3`일 때만 출력하지 않습니다.

차이를 정리하면:

```text
break
→ 반복문 종료

continue
→ 현재 반복만 건너뜀
```

# 16. `for` + `if`

실제 프로그램에서는 가장 많이 사용하는 형태입니다.

예를 들어 1~10 중 짝수만 출력하면:


결과:

```text

4

8

```

여기서 `%`는 나머지 연산자입니다.

```python

```

은

> 2로 나눈 나머지가 0인가?

라는 뜻입니다.

# 17. 합계 구하기

반복문을 이용한 대표적인 예제입니다.

```python
total = 0

for i in range(1, 11):
    total += i

print(total)
```

결과:

```text
55
```

실행 과정을 보면:

```text
total = 0

total = 0 + 1
total = 1 + 2
total = 3 + 3
...
```

처럼 누적됩니다.

이런 변수를 **누적 변수**라고 설명할 수 있습니다.

# 20. 실생활 예제 — 메뉴 반복

`while`을 이용하면 프로그램 메뉴를 만들 수 있습니다.

```python
while True:

    print("1. 조회")
    print("2. 등록")
    print("3. 종료")

    menu = input("메뉴 선택: ")

    if menu == "1":
        print("조회합니다.")

    elif menu == "2":
        print("등록합니다.")

    elif menu == "3":
        print("프로그램을 종료합니다.")
        break
```

이 구조는 실제 프로그램에서 매우 많이 사용됩니다.

```text
while
   ↓
메뉴 출력
   ↓
사용자 입력
   ↓
if로 기능 선택
   ↓
종료 선택
   ↓
break
```

## 핵심 문법 한 번에 정리

| 문법         | 역할         | 대표 용도   |
| ---------- | ---------- | ------- |
| `if`       | 조건 판단      | 성인 여부   |
| `elif`     | 추가 조건      | 학점 구분   |
| `else`     | 나머지 경우     | 불합격 처리  |
| `for`      | 반복         | 리스트 처리  |
| `while`    | 조건 반복      | 메뉴 프로그램 |
| `range()`  | 숫자 범위 생성   | 1~10 반복 |
| `break`    | 반복 종료      | 종료 메뉴   |
| `continue` | 현재 반복 건너뛰기 | 특정 값 제외 |

가장 중요한 흐름은 다음처럼 정리할 수 있습니다.

```text
프로그램 실행
       │
       ├──── 조건에 따라 선택
       │          ↓
       │      if / elif / else
       │
       └──── 여러 번 반복
                  ↓
              for / while
                  │
             ┌────┴────┐
           break    continue
```

비전공자 수업이라면 **`if → if/else → elif → for → range → for+if → while → break/continue` 순서**로 가르치는 것이 이해하기 좋습니다. 특히 마지막에는 `리스트 + for + if`와 `while + input + if + break`를 묶은 실생활 프로그램을 만들어보게 하면 제어문과 반복문의 관계를 확실히 익힐 수 있습니다.
