# 6. 고급함수
- 람다
- 고차함수
- map / filter / sorted
- 가변 매개변수 *args / **kwargs
- 재귀함수
- 클로저
- 레코레이터
- 제너레이터 / yield

> 그 다음 단계에서는 **“함수를 값처럼 다루는 방법”과 “함수를 확장하는 방법”**을 중심으로 이해하면 됩니다.

고급 함수에서 특히 중요한 흐름은 다음과 같습니다.

```text
기본 함수
  ↓
함수를 변수처럼 다루기
  ↓
lambda
  ↓
고차 함수
  ↓
map / filter / sorted
  ↓
가변 매개변수 *args / **kwargs
  ↓
재귀 함수
  ↓
클로저
  ↓
데코레이터
  ↓
Generator / yield
```

# 1. `lambda` 함수

`lambda`는 **이름 없이 짧게 만드는 함수**입니다.

일반 함수:

```python
def add(a, b):
    return a + b

print(add(10, 20))
```

`lambda`로 바꾸면:

```python
add = lambda a, b: a + b

print(add(10, 20))
```

결과:

```text
30
```

형식은 다음과 같습니다.

```python
lambda 매개변수: 반환할_식
```

즉,

```python
lambda a, b: a + b
```

는 거의 다음과 같습니다.

```python
def 함수(a, b):
    return a + b
```

단, `lambda`는 보통 **간단한 한 줄 처리**에 사용합니다.

---

# 2. lambda가 필요한 이유

다음처럼 단순한 함수를 한번만 사용할 때 유용합니다.

```python
def square(x):
    return x ** 2

print(square(5))
```

이를:

```python
square = lambda x: x ** 2

print(square(5))
```

로 줄일 수 있습니다.

하지만 실제로 `lambda`의 장점은 단순히 코드를 줄이는 데 있는 것이 아니라, **다른 함수에 함수를 전달할 때** 가장 잘 나타납니다.

---

# 3. `sorted()`와 lambda

학생들에게 `lambda`를 가르칠 때 가장 이해하기 좋은 예제입니다.

학생 데이터가 있다고 하겠습니다.

```python
students = [
    ["홍길동", 80],
    ["김철수", 95],
    ["이영희", 70]
]
```

점수를 기준으로 정렬하고 싶습니다.

```python
result = sorted(students, key=lambda x: x[1])

print(result)
```

결과:

```text
[['이영희', 70], ['홍길동', 80], ['김철수', 95]]
```

여기에서

```python
lambda x: x[1]
```

의 의미는:

```text
학생 하나를 받는다.
       ↓
["홍길동", 80]
       ↓
두 번째 값 x[1]
       ↓
80을 정렬 기준으로 사용
```

입니다.

내림차순은:

```python
result = sorted(
    students,
    key=lambda x: x[1],
    reverse=True
)
```

입니다.

---

# 4. 딕셔너리와 lambda

실제 데이터 처리에서는 더 많이 사용합니다.

```python
products = [
    {"name": "노트북", "price": 1200000},
    {"name": "마우스", "price": 30000},
    {"name": "모니터", "price": 350000}
]
```

가격순 정렬:

```python
result = sorted(
    products,
    key=lambda x: x["price"]
)

for product in result:
    print(product)
```

따라서 학생들에게는

> `lambda`는 정렬 기준처럼 **작은 기능을 잠깐 함수로 만들어 전달할 때 특히 유용하다.**

라고 설명하면 좋습니다.

# 5. 함수도 데이터다

고급 함수를 이해하려면 가장 먼저 이 개념이 중요합니다.

파이썬에서는 함수도 숫자나 문자열처럼 **변수에 저장할 수 있습니다.**

```python
def hello():
    print("안녕하세요")


a = hello

a()
```

결과:

```text
안녕하세요
```

주의해야 할 차이가 있습니다.

```python
a = hello
```

는 함수를 저장하는 것입니다.

반면

```python
a = hello()
```

는 함수를 실행한 결과를 저장합니다.

즉:

```text
hello     → 함수 자체

hello()   → 함수 실행
```

입니다.

# 6. 함수를 다른 함수의 매개변수로 전달

```python
def add(a, b):
    return a + b


def calculate(func, a, b):
    return func(a, b)


result = calculate(add, 10, 20)

print(result)
```

결과:

```text
30
```

실행 구조:

```text
calculate(add, 10, 20)
        ↓
func = add
        ↓
func(10, 20)
        ↓
add(10, 20)
        ↓
30
```

이처럼 **함수를 매개변수로 받거나 함수를 반환하는 함수**를 일반적으로 고차 함수(Higher-order function)라고 합니다.

# 7. `map()`

`map()`은 여러 데이터에 동일한 함수를 적용합니다.

```python
numbers = [1, 2, 3, 4, 5]


def square(x):
    return x ** 2


result = map(square, numbers)

print(list(result))
```

결과:

```text
[1, 4, 9, 16, 25]
```

lambda를 사용하면:

```python
numbers = [1, 2, 3, 4, 5]

result = map(
    lambda x: x ** 2,
    numbers
)

print(list(result))
```

결과:

```text
[1, 4, 9, 16, 25]
```

개념은:

```text
1 → 제곱 → 1
2 → 제곱 → 4
3 → 제곱 → 9
4 → 제곱 → 16
5 → 제곱 → 25
```

입니다.

---

# 8. `filter()`

`filter()`는 조건에 맞는 데이터만 선택합니다.

```python
numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda x: x % 2 == 0,
    numbers
)

print(list(result))
```

결과:

```text
[2, 4, 6]
```

즉:

```text
map
→ 모든 데이터를 변환

filter
→ 조건에 맞는 데이터 선택
```

입니다.

---

# 9. map/filter와 리스트 컴프리헨션

파이썬에서는 실무적으로 리스트 컴프리헨션도 매우 많이 사용합니다.

`map()`:

```python
numbers = [1, 2, 3, 4]

result = list(
    map(lambda x: x * 2, numbers)
)
```

리스트 컴프리헨션:

```python
result = [
    x * 2
    for x in numbers
]
```

`filter()`:

```python
result = list(
    filter(lambda x: x % 2 == 0, numbers)
)
```

리스트 컴프리헨션:

```python
result = [
    x
    for x in numbers
    if x % 2 == 0
]
```

비전공자에게는 먼저 리스트 컴프리헨션을 이해시키고, 그 다음 `map/filter/lambda`를 비교해서 보여주는 것도 좋은 방법입니다.

# 10. `*args` 가변 매개변수

함수가 몇 개의 값을 받을지 미리 알 수 없을 때 사용합니다.

```python
def add(*numbers):
    print(numbers)


add(10)
add(10, 20)
add(10, 20, 30)
```

결과:

```text
(10,)
(10, 20)
(10, 20, 30)
```

`*numbers`는 전달된 데이터를 **튜플로 받습니다.**

따라서:

```python
def add(*numbers):

    total = 0

    for number in numbers:
        total += number

    return total


print(add(10, 20))
print(add(10, 20, 30, 40))
```

결과:

```text
30
100
```

```python
def student(**info):

    score=90

```

결과:

```text
{'name': '홍길동',
 'age': 20,
 'score': 90}
```

즉:

```text
*args
→ Tuple

**kwargs
→ Dictionary
```

라고 기억하면 쉽습니다.

# 12. 재귀 함수

재귀 함수(Recursive Function)는 **함수가 자기 자신을 다시 호출하는 함수**입니다.

```python
def count(n):

    print(n)

    if n > 1:
        count(n - 1)


count(5)
```

결과:

```text
5
4
3
2
1
```

실행 과정은:

```text
count(5)
  ↓
count(4)
  ↓
count(3)
  ↓
count(2)
  ↓
count(1)
```

입니다.

---

# 13. 재귀 함수에서 종료조건

재귀 함수에서는 **종료조건이 반드시 필요합니다.**

잘못 작성하면:

```python
def hello():
    print("Hello")
    hello()
```

자기 자신을 계속 호출합니다.

```text
hello()
 ↓
hello()
 ↓
hello()
 ↓
hello()
 ↓
...
```

결국 `RecursionError`가 발생합니다.

따라서 재귀함수는 기본적으로:

```python
def recursive():

    if 종료조건:
        return

    recursive()
```

형태를 가집니다.

---

# 14. 대표적인 재귀 예제 — 팩토리얼

5 팩토리얼은:

```text
5! = 5 × 4 × 3 × 2 × 1
```

입니다.

일반 함수 + 반복문으로 작성하면:

```python
def factorial(n):

    result = 1

    for i in range(1, n + 1):
        result *= i

    return result
```

재귀 함수로 작성하면:

```python
def factorial(n):

    if n == 1:
        return 1

    return n * factorial(n - 1)


print(factorial(5))
```

실행 구조:

```text
factorial(5)

5 × factorial(4)

5 × 4 × factorial(3)

5 × 4 × 3 × factorial(2)

5 × 4 × 3 × 2 × factorial(1)

5 × 4 × 3 × 2 × 1

120
```

---

# 15. 재귀 함수는 언제 사용하나?

일반 반복 작업이라면 대부분 `for`나 `while`이 더 이해하기 쉽습니다.

재귀는 특히 **구조 자체가 반복적으로 중첩되어 있는 데이터**를 처리할 때 유용합니다.

예:

```text
폴더
├─ 파일
├─ 폴더
│   ├─ 파일
│   └─ 폴더
│        └─ 파일
```

또는:

```text
메뉴
 ├─ 메뉴
 │   ├─ 메뉴
 │   └─ 메뉴
 └─ 메뉴
```

트리, 폴더 구조, 조직도 등을 처리할 때 재귀가 자연스럽습니다.

# 16. 클로저(Closure)

클로저는 **함수 내부의 값을 기억하는 함수**라고 이해하면 됩니다.

```python
def make_multiplier(x):

    def multiply(y):
        return x * y

    return multiply
```

사용:

```python
double = make_multiplier(2)

print(double(10))
print(double(20))
```

결과:

```text
20
40
```

여기서 `make_multiplier()` 실행은 끝났는데도:

```python
x = 2
```

라는 값을 `multiply()`가 기억합니다.

구조는:

```text
make_multiplier(2)

      ↓

x = 2

      ↓

multiply(y)

      ↓

2 × y
```

입니다.

---

# 17. 클로저 응용 — 할인 함수

```python
def make_discount(rate):

    def discount(price):
        return price * (1 - rate)

    return discount
```

다음처럼 사용할 수 있습니다.

```python
discount10 = make_discount(0.1)
discount20 = make_discount(0.2)

print(discount10(10000))
print(discount20(10000))
```

결과:

```text
9000.0
8000.0
```

각 함수가 다른 할인율을 기억하고 있는 것입니다.

# 18. 데코레이터(Decorator)

데코레이터는 **기존 함수를 수정하지 않고 기능을 추가하는 방법**입니다.

예를 들어 다음 함수가 있습니다.

```python
def hello():
    print("안녕하세요")
```

함수 실행 전후에 메시지를 추가하고 싶다고 하겠습니다.

```python
def decorator(func):

    def wrapper():

        print("함수 실행 시작")

        func()

        print("함수 실행 종료")

    return wrapper
```

적용:

```python
@decorator
def hello():
    print("안녕하세요")


hello()
```

결과:

```text
함수 실행 시작
안녕하세요
함수 실행 종료
```

---

# 19. `@decorator`의 실제 의미

다음 코드는:

```python
@decorator
def hello():
    print("안녕하세요")
```

사실상 다음과 같은 의미입니다.

```python
def hello():
    print("안녕하세요")


hello = decorator(hello)
```

따라서:

```text
원래 함수
   ↓
Decorator
   ↓
기능이 추가된 함수
```

가 됩니다.

# 20. 데코레이터 응용 — 로그인 확인

웹 프로그래밍과 연결하면 이해하기 좋습니다.

```python
def login_required(func):

    def wrapper():

        print("로그인 확인")

        func()

    return wrapper


@login_required
def mypage():

    print("마이페이지입니다.")


mypage()
```

결과:

```text
로그인 확인
마이페이지입니다.
```

이 개념은 나중에 FastAPI, Flask, Django 같은 웹 프레임워크를 학습할 때 매우 중요합니다.

예를 들어 FastAPI에서도:

```python
@app.get("/users")
def get_users():
    return {"users": []}
```

처럼 `@` 문법을 자주 만나게 됩니다.

# 21. 매개변수가 있는 함수에 데코레이터 적용

실제 데코레이터에서는 `*args`, `**kwargs`와 함께 사용하는 경우가 많습니다.

```python
def logger(func):

    def wrapper(*args, **kwargs):

        print("함수 실행:", func.__name__)

        result = func(*args, **kwargs)

        return result

    return wrapper
```

사용:

```python
@logger
def add(a, b):
    return a + b


print(add(10, 20))
```

결과:

```text
함수 실행: add
30
```

이 예제에서:

```text
Decorator
+
*args
+
**kwargs
```

가 결합됩니다.

# 22. Generator와 `yield`

함수와 관련된 고급 개념으로 `yield`도 알아두는 것이 좋습니다.

일반 함수는:

```python
def numbers():

    return [1, 2, 3, 4, 5]
```

결과를 한꺼번에 반환합니다.

Generator는:

```python
def numbers():

    yield 1
    yield 2
    yield 3
```

처럼 값을 하나씩 만들어냅니다.

사용:

```python
for number in numbers():
    print(number)
```

결과:

```text
1
2
3
```

---

# 23. return과 yield 차이

중요한 차이입니다.

```text
return
→ 결과를 반환하고 함수 종료

yield
→ 값을 하나 반환하고
   현재 상태를 기억
```

예:

```python
def count():

    yield 1
    yield 2
    yield 3
```

실행 과정은:

```text
count()

yield 1
  ↓
잠시 멈춤

다음 요청
  ↓
yield 2
  ↓
잠시 멈춤

다음 요청
  ↓
yield 3
```

입니다.

큰 데이터를 처리할 때 메모리 측면에서 유리합니다.

---

# 24. Generator 실용 예제

```python
def count_up_to(max_value):

    number = 1

    while number <= max_value:

        yield number

        number += 1


for number in count_up_to(5):
    print(number)
```

결과:

```text
1
2
3
4
5
```

# 25. 함수 Annotation

고급 함수까지 공부한다면 타입 힌트도 함께 가르칠 만합니다.

```python
def add(a: int, b: int) -> int:
    return a + b
```

의 의미는:

```text
a       → int 예상
b       → int 예상
return  → int 예상
```

입니다.

문자열 함수라면:

```python
def hello(name: str) -> str:
    return name + "님 안녕하세요"
```

타입 힌트는 타입을 강제하는 것이 아니라 **개발자와 IDE에게 함수의 의도를 알려주는 기능**입니다.

FastAPI를 공부할 때 특히 중요해집니다.

# 26. 콜백 함수

고차 함수와 연결해서 이해할 수 있는 개념입니다.

```python
def success():
    print("작업 성공")


def process(callback):

    print("작업 처리")

    callback()
```

사용:

```python
process(success)
```

결과:

```text
작업 처리
작업 성공
```

즉 어떤 작업이 끝났을 때 실행할 함수를 전달합니다.

```text
process()
   ↓
작업 수행
   ↓
callback()
   ↓
success()
```

JavaScript를 공부할 때도 동일한 개념이 등장합니다.

# 27. 함수 관련 고급 개념 전체 관계

이 부분은 수업에서 한 번에 보여주기 좋습니다.

```text
                         Python Function

                              │
          ┌───────────────────┼─────────────────────┐
          │                   │                     │
       함수 표현           함수 전달              함수 확장
          │                   │                     │
       lambda             고차 함수             Decorator
                              │
                     ┌────────┼─────────┐
                     │        │         │
                    map     filter    callback

                              │
                         함수 상태 유지
                              │
                           Closure

                              │
                         반복적 호출
                              │
                          Recursion

                              │
                        값 순차 생성
                              │
                           Generator
                            yield
```

## 고급 함수 핵심 비교

| 개념         | 핵심 의미       | 대표 사용           |
| ---------- | ----------- | --------------- |
| `lambda`   | 짧은 익명 함수    | 정렬 기준           |
| 고차 함수      | 함수를 전달/반환   | `map`, `filter` |
| `map()`    | 모든 값 변환     | 일괄 계산           |
| `filter()` | 조건에 맞는 값 선택 | 데이터 필터          |
| `*args`    | 여러 위치 인수    | 입력 개수 불명        |
| `**kwargs` | 여러 키워드 인수   | 옵션 전달           |
| 재귀         | 자기 자신 호출    | 트리, 폴더          |
| Closure    | 값을 기억하는 함수  | 설정 유지           |
| Decorator  | 기존 함수 기능 확장 | 인증, 로그          |
| Generator  | 값을 하나씩 생성   | 대용량 데이터         |
| Type Hint  | 입력/출력 타입 설명 | FastAPI 등       |
| Callback   | 실행할 함수 전달   | 이벤트 처리          |

교육 순서로는 **`함수도 데이터다 → lambda → sorted/map/filter → *args/**kwargs → 재귀 → 클로저 → 데코레이터 → generator`** 순서를 추천합니다.

특히 AX/웹 개발 과정이라면 **`lambda`, 고차 함수, `*args/**kwargs`, 데코레이터, 타입 힌트**를 상대적으로 중요하게 다루는 것이 좋습니다. 이후 FastAPI를 학습할 때 `@app.get()`, 타입 힌트, Dependency 등의 문법을 접했을 때 훨씬 수월하게 이해할 수 있기 때문입니다.
