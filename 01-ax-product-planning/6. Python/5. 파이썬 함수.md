# 5. 파이썬의 함수
>  - **반복해서 사용하는 코드를 하나의 이름으로 묶어두는 기능**입니다.
>  - 기본 함수만 잘 이해해도 프로그램을 훨씬 짧고 읽기 쉽게 만들 수 있습니다.
>  - 여기서는 `def`, 매개변수, 반환값, 기본값 정도까지만 다루고 `lambda`, 재귀함수, 데코레이터 같은 고급 내용은 제외하겠습니다.

## 1. 함수가 필요한 이유

예를 들어 학생 3명의 점수를 각각 출력한다고 하겠습니다.

```python
name1 = "홍길동"
score1 = 80

print(name1, "님의 점수는", score1, "점입니다.")

name2 = "김철수"
score2 = 90

print(name2, "님의 점수는", score2, "점입니다.")

name3 = "이영희"
score3 = 75

print(name3, "님의 점수는", score3, "점입니다.")
```

같은 형태의 코드가 계속 반복됩니다. 함수로 만들면 다음처럼 간단해집니다.

```python
def show_score(name, score):
    print(name, "님의 점수는", score, "점입니다.")

show_score("홍길동", 80)
show_score("김철수", 90)
show_score("이영희", 75)
```

즉 함수는 다음 구조라고 보면 됩니다.

```text
입력
 ↓
함수
 ↓
처리
 ↓
결과
```

# 2. 가장 기본적인 함수

함수를 만들 때 `def`를 사용합니다.

```python
def 함수이름():
    실행문
```

예:

```python
def hello():
    print("안녕하세요.")

hello()
```

결과:

```text
안녕하세요.
```

여기서

```python
def hello():
```

는 함수를 **정의**하는 것이고,

```python
hello()
```

는 함수를 **호출**하는 것입니다.

즉,

```text
정의
def hello():

호출
hello()
```

을 구분해야 합니다.

# 3. 매개변수가 있는 함수

함수에 데이터를 전달할 수 있습니다.

```python
def hello(name):
    print(name, "님 안녕하세요.")

hello("홍길동")
hello("김철수")
```

결과:

```text
홍길동 님 안녕하세요.
김철수 님 안녕하세요.
```

여기서 `name`을 **매개변수(parameter)**라고 합니다.

```python
def hello(name):
          ↑
       매개변수
```

그리고

```python
hello("홍길동")
      ↑
      전달하는 값
```

`"홍길동"` 같은 실제 값을 보통 **인수(argument)**라고 부릅니다.

# 5. 값을 반환하는 `return`

지금까지 함수는 결과를 바로 출력했습니다.

```python
def add(a, b):
    print(a + b)
```

그런데 실제 프로그램에서는 계산한 결과를 다시 사용해야 하는 경우가 많습니다.

이때 `return`을 사용합니다.

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

결과:

```text
30
```

함수의 흐름은 다음과 같습니다.

```text
10, 20
   ↓
add()
   ↓
10 + 20
   ↓
return 30
   ↓
result = 30
```

# 6. `print()`와 `return`의 차이

초보자가 가장 많이 혼동하는 부분입니다.

다음 함수는:

```python
def add1(a, b):
    print(a + b)
```

결과를 **화면에 보여주기만 합니다.**

반면:

```python
def add2(a, b):
    return a + b
```

는 값을 함수 밖으로 돌려줍니다.

따라서 다음이 가능합니다.

```python
result = add2(10, 20)

print(result * 2)
```

결과:

```text
60
```

정리하면:

| 구분     | `print()` | `return` |
| ------ | --------- | -------- |
| 목적     | 화면 출력     | 결과 반환    |
| 결과 재사용 | 어려움       | 가능       |
| 변수에 저장 | X         | O        |
| 추가 계산  | X         | O        |

실제 프로그램에서는 **계산 함수는 `return`을 사용하는 습관**을 들이는 것이 좋습니다.

# 10. 홀수·짝수 판단

```python
def check_number(number):

    if number % 2 == 0:
        return "짝수"

    return "홀수"


print(check_number(10))
print(check_number(7))
```

결과:

```text
짝수
홀수
```

함수를 만들 때 중요한 것은 **하나의 함수에 하나의 명확한 역할을 부여하는 것**입니다.

```text
check_number()
→ 숫자의 홀짝 판단
```

처럼 이름만 보고도 기능을 알 수 있으면 좋습니다.

# 14. BMI 계산 함수

```python
def calc_bmi(weight, height):

    height_m = height / 100

    bmi = weight / (height_m ** 2)

    return bmi


result = calc_bmi(70, 175)

print("BMI:", round(result, 1))
```

결과:

```text
BMI: 22.9
```

# 20. 가장 큰 값 찾기

```python
print(get_max(numbers))
```

결과:

```text
95
```

# 25. 함수 내부 변수

함수 안에서 만든 변수는 일반적으로 함수 밖에서 사용할 수 없습니다.

```python
def test():

    message = "안녕하세요"

    print(message)


test()
```

`message`는 함수 내부 변수입니다.

따라서 다음처럼 함수 밖에서 사용하려고 하면 문제가 발생합니다.

```python
print(message)
```

초보자에게는 일단 다음 정도로 이해하면 충분합니다.

> **함수 안에서 만든 변수는 기본적으로 그 함수 안에서 사용하는 변수이다.**

# 26. 주문 금액 계산 프로그램

여러 기본 함수 기능을 하나의 프로그램으로 연결해보겠습니다.

```python
def get_product_total(price, count):

    return price * count


def get_discount(total):

    if total >= 100000:
        return total * 0.1
    elif total >= 50000:
        return total * 0.05

    return 0


def get_shipping(total):

    if total >= 50000:
        return 0

    return 3000


price = 30000
count = 2

product_total = get_product_total(price, count)

discount = get_discount(product_total)

shipping = get_shipping(product_total)

final_price = product_total - discount + shipping


print("상품금액:", product_total)
print("할인금액:", discount)
print("배송비:", shipping)
print("최종금액:", final_price)
```

이 예제가 함수 사용의 핵심을 잘 보여줍니다.

하나의 긴 프로그램을

```text
상품금액 계산
할인 계산
배송비 계산
```

처럼 역할별로 분리했습니다.

## 28. 기본 함수 문법 총정리

| 형태              | 예제                       | 의미         |
| --------------- | ------------------------ | ---------- |
| 매개변수 없음 / 반환 없음 | `def hello():`           | 단순 실행      |
| 매개변수 있음         | `def hello(name):`       | 값을 전달받음    |
| 반환값 있음          | `return result`          | 계산 결과 반환   |
| 여러 매개변수         | `def add(a, b):`         | 여러 값 입력    |
| 기본 매개변수         | `def hello(name="홍길동"):` | 기본값 지정     |
| 여러 값 반환         | `return a, b`            | 두 개 이상 결과  |
| 함수 안 `if`       | 조건 판단                    | 성인, 학점, 할인 |
| 함수 안 `for`      | 반복 처리                    | 합계, 평균, 목록 |

## 29. 초보자가 기억해야 할 핵심

함수를 공부할 때는 **입력 → 처리 → 출력**이라는 구조로 이해하는 것이 가장 좋습니다.

```text
            함수

입력값
  ↓
매개변수
  ↓
┌─────────────────────┐
│        함수          │
│                     │
│ 계산                 │
│ if 조건 판단         │
│ for 반복             │
│                     │
└─────────────────────┘
  ↓
return
  ↓
결과값
```

예를 들어:

```python
def get_grade(score):

    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    else:
        return "C"
```

에서는

```text
score
  ↓
입력

if
  ↓
처리

A / B / C
  ↓
출력(return)
```

이 됩니다.

비전공자 수업에서는 **① 매개변수 없는 함수 → ② 매개변수 → ③ `return` → ④ `if`가 포함된 함수 → ⑤ `for`가 포함된 함수 → ⑥ 여러 함수를 결합한 작은 프로그램** 순서로 진행하는 것이 좋습니다. 특히 `할인 계산`, `배송비 계산`, `성적 처리`, `BMI 계산`, `쇼핑몰 주문금액 계산`처럼 학생들이 결과를 쉽게 예상할 수 있는 사례를 사용하면 함수가 왜 필요한지 빠르게 이해할 수 있습니다.
