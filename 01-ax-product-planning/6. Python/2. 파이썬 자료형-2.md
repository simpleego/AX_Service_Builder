# 파이썬 자료형 정리


# 📘 **02장 파이썬 자료형 — 일상 속 비유로 쉽게 이해하기**

자료형은 프로그래밍에서 **현실 세계의 다양한 정보를 표현하기 위한 방식**이야.  
우리가 살아가는 세상에는 숫자, 글자, 목록, 규칙, 참/거짓 같은 다양한 정보가 있지?  
파이썬은 이런 정보들을 각각 **자료형**으로 표현해.

아래는 “일상 속 사물”에 비유한 자료형 설명이야.

---

# 🟦 **1. 숫자형(Number) — 현실의 ‘수량·가격·시간’을 표현**




### ✔ 자료형 설명  
숫자형은 **숫자 그 자체**를 표현하는 자료형이야.  
계산, 시간, 거리, 가격 등 “수량”을 표현할 때 사용해.

### ✔ 일상 속 예시  
- 나이: `25`  
- 커피 가격: `4500`  
- 오늘 걸음 수: `10324`  
- 온도: `23.5`  

### ✔ 파이썬 예시
```python
age = 25
price = 4500
temperature = 23.5
```

---

# 🟩 **2. 문자열(String) — ‘말과 글’을 표현**




### ✔ 자료형 설명  
문자열은 **글자, 문장, 이름, 주소**처럼 텍스트를 표현하는 자료형이야.

### ✔ 일상 속 예시  
- 이름: `"jong"`  
- 주소: `"광주광역시"`  
- 오늘 기분: `"행복하다"`  
- 메시지: `"안녕!"`

### ✔ 파이썬 예시
```python
name = "jong"
message = "오늘도 좋은 하루!"
```

---

# 🟧 **3. 리스트(List) — ‘장바구니·할 일 목록’처럼 여러 개를 순서대로 담기**




### ✔ 자료형 설명  
리스트는 **여러 개의 데이터를 순서대로 담는 상자**야.  
장바구니나 할 일 목록처럼 “순서가 있는 모음”을 표현해.

### ✔ 일상 속 예시  
- 장바구니: `["우유", "빵", "계란"]`  
- 오늘 할 일: `["운동", "공부", "청소"]`  
- 좋아하는 영화 목록  

### ✔ 파이썬 예시
```python
shopping = ["우유", "빵", "계란"]
todo = ["운동", "공부", "청소"]
```

---

# 🟪 **4. 튜플(Tuple) — ‘변하지 않는 정보’**




### ✔ 자료형 설명  
튜플은 리스트와 비슷하지만 **변경할 수 없는 목록**이야.  
바뀌면 안 되는 정보를 표현할 때 사용해.

### ✔ 일상 속 예시  
- GPS 좌표: `(35.1595, 126.8526)`  
- 생년월일: `(1995, 7, 12)`  
- RGB 색상 값: `(255, 0, 0)`  

### ✔ 파이썬 예시
```python
location = (35.1595, 126.8526)
birthday = (1995, 7, 12)
```

---

# 🟥 **5. 딕셔너리(Dictionary) — ‘사전·회원 정보’처럼 이름과 값을 연결**




### ✔ 자료형 설명  
딕셔너리는 **이름(key)과 값(value)을 짝지어 저장하는 자료형**이야.  
사전처럼 “단어 → 뜻” 구조를 가진 정보에 적합해.

### ✔ 일상 속 예시  
- 회원 정보  
  ```python
  {"name": "jong", "age": 25, "city": "광주"}
  ```
- 제품 정보  
- 학생 성적표  

### ✔ 파이썬 예시
```python
user = {"name": "jong", "age": 25, "city": "광주"}
```

---

# 🟦 **6. 집합(Set) — ‘중복 없는 모음’**




### ✔ 자료형 설명  
집합은 **중복을 허용하지 않는 자료형**이야.  
수학의 집합 개념과 동일해.

### ✔ 일상 속 예시  
- 중복 없는 방문 도시 목록  
- 중복 없는 태그 목록  
- 중복 없는 친구 목록  

### ✔ 파이썬 예시
```python
visited = {"서울", "광주", "부산", "광주"}  # "광주"는 한 번만 저장됨
```

---

# 🟩 **7. 불(Boolean) — ‘참/거짓’**




### ✔ 자료형 설명  
불(Boolean)은 **참(True) 또는 거짓(False)**만 표현하는 자료형이야.  
조건문, 판단, 제어 흐름에 필수적이야.

### ✔ 일상 속 예시  
- 문이 열려 있는가? → `True`  
- 비가 오는가? → `False`  
- 로그인 성공했는가? → `True`  

### ✔ 파이썬 예시
```python
is_open = True
is_raining = False
```

---

# 🟧 **8. 변수(Variable) — ‘자료를 담는 이름표가 붙은 상자’**




### ✔ 자료형 설명  
변수는 **자료형의 값을 저장하는 공간**이야.  
자료형이 “내용물”이라면, 변수는 “이름표가 붙은 상자”라고 보면 돼.

### ✔ 일상 속 예시  
- `age = 25` → 나이를 담은 상자  
- `city = "광주"` → 도시 이름을 담은 상자  

### ✔ 파이썬 예시
```python
age = 25
city = "광주"
```
