**파이썬 자료형 — 우리 생활의 정보를 코드로 표현하는 방법**

우리는 매일 다양한 정보를 사용합니다. 물건의 가격을 계산하고, 친구의 이름을 기억하고, 장바구니에 상품을 담고, 주문한 물건이 배송되었는지 확인합니다.

컴퓨터로 이런 일을 처리하려면 정보를 알맞은 형태로 표현해야 합니다. **자료형은 ‘어떤 종류의 정보이며, 어떻게 다룰 수 있는가’를 정하는 방식**입니다.

---

**1. 우리 생활에는 서로 다른 종류의 정보가 있습니다**

온라인 쇼핑몰에서 물건을 산다고 생각해 봅시다.

| 일상에서 사용하는 정보 | 실제 예시              | 파이썬의 표현                    | 자료형  |
| ------------ | ------------------ | -------------------------- | ---- |
| 상품 가격        | 3,000원             | `3000`                     | 정수   |
| 상품 무게        | 1.5kg              | `1.5`                      | 실수   |
| 상품 이름        | 공책                 | `"공책"`                     | 문자열  |
| 장바구니 목록      | 공책, 볼펜, 지우개        | `["공책", "볼펜", "지우개"]`      | 리스트  |
| 상품 크기 한 묶음   | 가로 20, 세로 30       | `(20, 30)`                 | 튜플   |
| 상품의 상세 정보    | 이름은 공책, 가격은 3,000원 | `{"이름": "공책", "가격": 3000}` | 딕셔너리 |
| 구매한 상품의 종류   | 중복 없이 공책, 볼펜       | `{"공책", "볼펜"}`             | 집합   |
| 결제 완료 여부     | 완료 / 미완료           | `True` / `False`           | 불    |

같은 쇼핑몰에서도 **계산할 정보, 읽을 정보, 여러 개를 모을 정보, 여부를 판단할 정보**가 모두 필요합니다.

> 💡 자료형을 배운다는 것은 문법만 외우는 일이 아닙니다.
> ‘이 정보를 어떤 형태로 표현하면 사용하기 편할까?’를 배우는 과정입니다.

---

**2. 숫자형 — 수량을 세고 크기를 계산합니다**

🛒 **일상 속 예시:** 물건 가격, 구매 수량, 나이, 키, 온도

숫자형은 덧셈, 뺄셈, 곱셈처럼 **계산이 필요한 정보**를 표현합니다.

| 구분         | 의미        | 생활 속 예시            | 코드            |
| ---------- | --------- | ------------------ | ------------- |
| 정수 `int`   | 소수점이 없는 수 | 사과 3개, 가격 2,000원   | `3`, `2000`   |
| 실수 `float` | 소수점이 있는 수 | 체온 36.5도, 무게 1.2kg | `36.5`, `1.2` |

```python
# 사과 한 개의 가격과 구매 수량
price = 2000
quantity = 3

total = price * quantity

print(total)  # 6000
```

```python
# 아침과 낮의 온도 차이
morning = 18.5
afternoon = 25.0

print(afternoon - morning)  # 6.5
```

**생각해 보기:** 상품 가격을 숫자로 저장하면 수량이 바뀌어도 결제 금액을 다시 계산할 수 있습니다.

---

**3. 문자열 — 이름과 글, 각종 기호를 표현합니다**

🏷️ **일상 속 예시:** 사람 이름, 주소, 전화번호, 안내 문구, 상품 코드

문자열 `str`은 **글자로 다룰 정보**입니다. 작은따옴표 또는 큰따옴표로 감쌉니다.

```python
name = "김민수"
address = "대전광역시"
phone = "010-1234-5678"

print(name)
print(address)
print(phone)
```

문자열을 연결하여 안내 문구를 만들 수도 있습니다.

```python
name = "김민수"

message = name + "님, 환영합니다."

print(message)
# 김민수님, 환영합니다.
```

**숫자로 생겼다고 모두 숫자형은 아닙니다.**

| 정보     | 알맞은 표현          | 이유                    |
| ------ | --------------- | --------------------- |
| 구매 수량  | `3`             | 덧셈이나 곱셈으로 계산함         |
| 상품 가격  | `2000`          | 결제 금액 계산에 사용함         |
| 전화번호   | `"01012345678"` | 계산하지 않으며 앞자리 `0`도 중요함 |
| 사물함 번호 | `"007"`         | 개수를 뜻하지 않고 대상을 구별함    |

다음 두 코드는 결과가 다릅니다.

```python
print(100 + 200)      # 300
print("100" + "200")  # 100200
```

* 숫자에 `+`를 사용하면 **덧셈**을 합니다.
* 문자열에 `+`를 사용하면 **글자를 연결**합니다.

> 💡 자료형이 다르면 같은 기호를 사용해도 처리 방식이 달라집니다.

---

**4. 리스트 — 순서가 있는 여러 정보를 모읍니다**

🛒 **일상 속 예시:** 장바구니, 음악 재생 목록, 할 일 목록, 시험 점수

리스트 `list`는 **여러 값을 순서대로 모아 놓는 자료형**입니다. 대괄호 `[]`로 표현하며, 내용을 추가·수정·삭제할 수 있습니다.

장바구니를 그림처럼 살펴보면 다음과 같습니다.

| 위치 번호인 인덱스 | `0`   | `1`    | `2`    |
| ---------- | ----- | ------ | ------ |
| 장바구니의 상품   | 📓 공책 | 🖊️ 볼펜 | 🧽 지우개 |

```python
cart = ["공책", "볼펜", "지우개"]

print(cart[0])  # 공책
print(cart[1])  # 볼펜
```

**파이썬에서 첫 번째 위치의 인덱스는 `0`입니다.**

장바구니의 내용은 바뀔 수 있습니다.

```python
cart = ["공책", "볼펜", "지우개"]

cart.append("파일철")  # 마지막에 추가
cart[1] = "색연필"     # 두 번째 상품 수정
cart.remove("지우개")  # 상품 삭제

print(cart)
# ['공책', '색연필', '파일철']
```

리스트는 같은 값이 여러 번 들어가는 것도 허용합니다.

```python
orders = ["커피", "커피", "주스"]

print(orders.count("커피"))  # 2
```

**선택 기준:** 순서대로 관리하며 추가하거나 수정할 목록이라면 리스트를 생각할 수 있습니다.

---

**5. 튜플 — 여러 값을 변경하지 않는 한 묶음으로 표현합니다**

📐 **일상 속 예시:** 가로·세로 크기, 좌표, RGB 색상값

튜플 `tuple`은 여러 값을 묶는다는 점에서 리스트와 비슷하지만, **만든 뒤 각 위치의 값을 교체하거나 요소를 추가·삭제할 수 없습니다.** 보통 소괄호 `()`로 표현합니다.

예를 들어 한 상품의 가로와 세로를 한 묶음으로 저장할 수 있습니다.

| 튜플                | 첫 번째 값 `0` | 두 번째 값 `1` |
| ----------------- | ---------- | ---------- |
| `size = (20, 30)` | 가로 20cm    | 세로 30cm    |

```python
size = (20, 30)

width = size[0]
height = size[1]

print("가로:", width)
print("세로:", height)
print("넓이:", width * height)
```

튜플의 값을 직접 수정하려고 하면 오류가 발생합니다.

```python
size = (20, 30)

# 아래 코드의 주석을 해제하면 오류가 발생합니다.
# size[0] = 25
```

다른 크기가 필요하면 새 튜플을 만들어 변수에 연결할 수 있습니다.

```python
size = (20, 30)
size = (25, 30)

print(size)  # (25, 30)
```

**선택 기준:** 관련 있는 값들을 하나의 묶음으로 다루고, 그 묶음 안의 값을 직접 변경하지 않으려면 튜플을 사용할 수 있습니다.

---

**6. 딕셔너리 — 항목 이름과 값을 짝지어 저장합니다**

📇 **일상 속 예시:** 연락처, 학생 정보, 상품 정보, 음식점 메뉴판

딕셔너리 `dict`는 **‘항목 이름: 값’의 대응 관계**를 표현합니다. 항목 이름을 **키(key)**, 연결된 내용을 **값(value)**이라고 합니다.

상품 설명 카드가 좋은 예입니다.

| 키: 어떤 정보인가? | 값: 실제 내용 |
| ----------- | -------- |
| 이름          | 공책       |
| 가격          | 3000     |
| 재고          | 20       |

```python
product = {
    "이름": "공책",
    "가격": 3000,
    "재고": 20
}

print(product["이름"])  # 공책
print(product["가격"])  # 3000
```

리스트는 위치 번호로 값을 찾지만, 딕셔너리는 키로 값을 찾습니다.

```python
# 리스트: 두 번째 값이 가격이라는 사실을 알아야 합니다.
product_list = ["공책", 3000, 20]
print(product_list[1])

# 딕셔너리: "가격"이라는 키로 찾습니다.
product_dict = {"이름": "공책", "가격": 3000, "재고": 20}
print(product_dict["가격"])
```

정보를 수정하거나 새로운 항목을 추가할 수도 있습니다.

```python
product = {
    "이름": "공책",
    "가격": 3000,
    "재고": 20
}

product["가격"] = 3500       # 기존 항목 수정
product["분류"] = "문구류"   # 새로운 항목 추가

print(product)
```

**선택 기준:** 이름, 가격, 재고처럼 각 값이 무엇을 뜻하는지 구별해야 한다면 딕셔너리가 편리합니다.

**7. 집합 — 중복을 없애고 공통점과 차이점을 찾습니다**

🎨 **일상 속 예시:** 학생들이 선택한 취미 종류, 방문한 도시, 두 사람의 공통 관심사

집합 `set`은 **같은 값을 중복해서 저장하지 않는 자료형**입니다. 순서를 기준으로 다루지 않으며, 인덱싱을 사용할 수 없습니다.

예를 들어 다섯 학생이 선택한 취미를 살펴보겠습니다.

```python
hobbies = ["독서", "운동", "독서", "게임", "운동"]

unique_hobbies = set(hobbies)

print(len(hobbies))         # 응답 수: 5
print(len(unique_hobbies))  # 취미 종류 수: 3
print(unique_hobbies)
# {'독서', '운동', '게임'} — 출력 순서는 달라질 수 있습니다.
```

두 사람의 공통 관심사도 쉽게 찾을 수 있습니다.

```python
minsu = {"영화", "운동", "게임"}
jiyoung = {"독서", "영화", "운동"}

print(minsu & jiyoung)  # 공통 관심사
print(minsu | jiyoung)  # 두 사람의 관심사 전체
print(minsu - jiyoung)  # 민수에게만 있는 관심사
```

| 연산       | 의미                 | 위 예시의 결과에 포함되는 값 |
| -------- | ------------------ | ---------------- |
| `&` 교집합  | 양쪽에 모두 있는 값        | 영화, 운동           |
| `\|` 합집합 | 양쪽의 모든 값을 중복 없이 모음 | 영화, 운동, 게임, 독서   |
| `-` 차집합  | 왼쪽에만 있는 값          | 게임               |

**선택 기준:** “몇 번 나왔는가?”보다 “어떤 종류가 있는가?” 또는 “무엇이 공통인가?”가 중요할 때 집합을 사용합니다.

참고로 빈 집합은 `set()`으로 만듭니다. `{}`는 빈 딕셔너리입니다.

**8. 불 자료형 — 맞는지, 아닌지를 표현합니다**

💡 **일상 속 예시:** 결제 완료 여부, 로그인 여부, 재고 유무, 합격 여부

불 `bool`은 두 가지 값으로 상태나 판단 결과를 표현합니다.

| 값       | 의미 | 생활 속 예시     |
| ------- | -- | ----------- |
| `True`  | 참  | 결제가 완료됨     |
| `False` | 거짓 | 결제가 완료되지 않음 |

```python
is_paid = True
is_delivered = False

print("결제 완료:", is_paid)
print("배송 완료:", is_delivered)
```

숫자를 비교하면 불 값이 나옵니다.

```python
stock = 3
quantity = 5

can_order = stock >= quantity

print(can_order)  # False
```

재고는 3개인데 5개를 주문하려 하므로, “재고가 주문 수량 이상인가?”라는 질문의 답은 `False`입니다.

```python
score = 85
passed = score >= 60

print(passed)  # True
```

**주의:** `True`와 `"True"`는 다릅니다.

```python
is_paid = True        # 불: 참이라는 값
message = "True"      # 문자열: 네 글자로 된 문구
```

**9. 변수 — 값에 이름을 붙여 다시 사용합니다**

🏷️ **일상 속 비유:** 물건을 쉽게 찾도록 붙이는 이름표

변수는 별도의 자료형이 아닙니다. **값을 가리키는 이름**입니다.

```python
price = 3000
```

이 코드는 `3000`이라는 정숫값을 `price`라는 이름으로 사용할 수 있게 합니다.

| 변수 이름     | 연결된 값          | 값의 자료형 |
| --------- | -------------- | ------ |
| `price`   | `3000`         | 정수     |
| `name`    | `"공책"`         | 문자열    |
| `cart`    | `["공책", "볼펜"]` | 리스트    |
| `is_paid` | `False`        | 불      |

변수에 의미 있는 이름을 붙이면 코드를 이해하기 쉬워집니다.

```python
price = 3000
quantity = 2

total = price * quantity

print(total)  # 6000
```

`=`는 **오른쪽 계산 결과를 왼쪽 변수 이름에 연결하는 대입 기호**입니다.

```python
stock = 10
stock = stock - 2

print(stock)  # 8
```

처리 순서는 다음과 같습니다.

1. 오른쪽의 `stock - 2`를 계산합니다. 현재 `stock`은 10이므로 결과는 8입니다.
2. 계산 결과인 8을 `stock`에 다시 대입합니다.

그래서 프로그래밍의 `stock = stock - 2`는 수학의 등식과 의미가 다릅니다.

**10. 종합 예시 — 작은 문구점의 주문 정보**

지금까지 배운 자료형으로 하나의 주문을 표현해 보겠습니다.

```python
# 문자열: 고객 이름
customer = "김민수"

# 딕셔너리: 상품의 항목별 정보
product = {
    "이름": "공책",
    "가격": 3000,
    "재고": 10
}

# 정수: 주문 수량
quantity = 2

# 실수: 주문 상품의 포장 무게(kg)
weight = 0.5

# 리스트: 포장할 상품 목록
cart = ["공책", "공책"]

# 튜플: 포장 상자의 가로, 세로, 높이(cm)
box_size = (25, 35, 10)

# 집합: 주문한 상품 종류
product_types = set(cart)

# 불: 재고가 충분한지 확인
can_order = product["재고"] >= quantity

# 숫자 연산: 총 상품 금액
total = product["가격"] * quantity

print("고객:", customer)
print("상품:", product["이름"])
print("주문 수량:", quantity)
print("포장 무게:", weight)
print("장바구니:", cart)
print("상자 크기:", box_size)
print("상품 종류 수:", len(product_types))
print("주문 가능:", can_order)
print("총 상품 금액:", total)
```

실행 결과:

```text
고객: 김민수
상품: 공책
주문 수량: 2
포장 무게: 0.5
장바구니: ['공책', '공책']
상자 크기: (25, 35, 10)
상품 종류 수: 1
주문 가능: True
총 상품 금액: 6000
```

공책을 **2개** 주문했지만, 상품의 **종류는 1개**입니다. 리스트와 집합이 서로 다른 목적에 쓰인다는 것을 확인할 수 있습니다.

**11. 자료형을 선택하는 연습**

다음 상황에서 어떤 자료형을 사용할지 먼저 생각해 보세요.

| 표현하려는 정보            | 선택할 자료형 | 선택 이유              |
| ------------------- | ------- | ------------------ |
| 오늘 판매한 빵의 개수        | 정수      | 개수를 세거나 합산함        |
| 오늘의 체온              | 실수      | 소수점이 있는 수를 표현함     |
| 앞자리가 0인 우편번호        | 문자열     | 계산하지 않고 글자 형태를 유지함 |
| 순서대로 재생할 노래 목록      | 리스트     | 순서가 있고 곡을 추가·삭제함   |
| 직접 수정하지 않을 좌표 한 쌍   | 튜플      | 두 값을 하나의 묶음으로 다룸   |
| 학생 한 명의 이름·학번·점수    | 딕셔너리    | 항목 이름으로 값을 구별함     |
| 우리 반 학생들이 사는 도시의 종류 | 집합      | 같은 도시는 한 번만 포함함    |
| 과제 제출 여부            | 불       | 제출했는지 두 상태로 표현함    |

자료형을 확인하고 싶다면 `type()`을 사용할 수 있습니다.

```python
print(type(3000))           # <class 'int'>
print(type(36.5))           # <class 'float'>
print(type("공책"))         # <class 'str'>
print(type(["공책", "볼펜"])) # <class 'list'>
print(type((20, 30)))       # <class 'tuple'>
print(type({"가격": 3000})) # <class 'dict'>
print(type({"공책", "볼펜"})) # <class 'set'>
print(type(True))           # <class 'bool'>
```

**코드를 작성하기 전에는 “무엇을 저장할까?”와 함께 “그 정보로 무엇을 할까?”를 생각해 보세요.** 계산할지, 순서대로 관리할지, 이름으로 찾을지, 중복을 없앨지에 따라 알맞은 자료형이 달라집니다.
