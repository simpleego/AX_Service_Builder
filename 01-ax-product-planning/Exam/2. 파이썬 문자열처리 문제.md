아래 문제는 **파이썬 문자열의 인덱싱과 슬라이싱**을 처음 배우는 비전공자 기준으로 구성했습니다. 주민번호·학번·사번·상품코드처럼 **문자열의 위치별로 의미가 정해져 있는 데이터**를 이용하면 슬라이싱을 이해하기 좋습니다.

## 1. 문자열 슬라이싱 기본

파이썬에서 문자열의 일부를 잘라낼 때 다음 형식을 사용합니다.

```python
문자열[시작:끝]
```

중요한 점은 **시작 위치는 포함하고, 끝 위치는 포함하지 않는다**는 것입니다.

```python
text = "ABCDEFG"

print(text[0])      # A
print(text[1])      # B
print(text[0:3])    # ABC
print(text[2:5])    # CDE
print(text[:4])     # ABCD
print(text[4:])     # EFG
print(text[-3:])    # EFG
```

인덱스는 다음처럼 생각하면 됩니다.

```text
문자 : A B C D E F G
위치 : 0 1 2 3 4 5 6

음수 : -7 -6 -5 -4 -3 -2 -1
```

# 2. 구조가 있는 문자열 이해하기

## 주민등록번호 형식

실제 개인정보가 아닌 학습용 예시입니다.

```python
jumin = "990101-1ABCDEF"
```

구조를 보면 다음과 같습니다.

| 위치   | 의미          | 예      |
| ---- | ----------- | ------ |
| 0~1  | 출생년도        | 99     |
| 2~3  | 출생월         | 01     |
| 4~5  | 출생일         | 01     |
| 6    | 구분 기호       | -      |
| 7    | 성별/세기 구분 위치 | 1      |
| 8~13 | 학습용 임의 문자   | ABCDEF |

따라서 다음과 같이 추출할 수 있습니다.

```python
year = jumin[0:2]
month = jumin[2:4]
day = jumin[4:6]

print(year)     # 99
print(month)    # 01
print(day)      # 01
```

```text
연도 학과 번호
```

쇼핑몰에서 다음과 같은 상품코드를 사용한다고 가정합니다.


# 4. 정답

| 문제 | 핵심 코드                                                           |
| -- | --------------------------------------------------------------- |
| 1  | `jumin[0:2]`, `jumin[2:4]`, `jumin[4:6]`                        |
| 2  | `jumin[0:6]` 또는 `jumin[:6]`                                     |
| 3  | `student[:4]`                                                   |
| 4  | `student[4:6]`                                                  |
| 5  | `student[-3:]`                                                  |
| 6  | `employee[:3]`                                                  |
| 7  | `employee[4:8]`                                                 |
| 8  | `employee[-3:]`                                                 |
| 9  | `product[0:2]`, `product[3:5]`, `product[6:10]`, `product[-4:]` |
| 10 | `phone[:3]`, `phone[4:8]`, `phone[-4:]`                         |

예를 들어 **9번 문제의 완성 코드**는 다음과 같습니다.

```python
product = "EL-TV-2026-0158"

category = product[0:2]
kind = product[3:5]
year = product[6:10]
number = product[-4:]

print("대분류 :", category)
print("제품종류 :", kind)
print("등록년도 :", year)
print("상품번호 :", number)
```

실행 결과:

```text
대분류 : EL
제품종류 : TV
등록년도 : 2026
상품번호 : 0158
```

### 수업에서 강조할 핵심

```python
s[start:end]
```

에서 **end 위치의 문자는 포함되지 않는다**는 것이 가장 중요합니다.

```python
student = "2026AI037"

student[0:4]     # "2026"
student[4:6]     # "AI"
student[6:9]     # "037"

student[:4]      # "2026"
student[4:]      # "AI037"
student[-3:]     # "037"
student[:-3]     # "2026AI"
```

이 10문제를 먼저 풀게 한 뒤에는 **`[start:end:step]`을 이용한 문자열 뒤집기, 홀수/짝수 위치 문자 추출, `-` 제거 전후 비교** 문제로 발전시키면 슬라이싱을 훨씬 확실하게 익힐 수 있습니다.
