## 파이썬을 처음 배우는 학생을 위한 **변수·키보드 입력·기초 연산자 실습 20문제**입니다. 
- 앞부분에서는 변수와 기본 계산을 익히고, 뒷부분에서는 **나머지 연산자 `%`를 시간 변환, 자릿수 추출, 순환 등에 응용**합니다.

> 모든 문제는 **조건문과 반복문 없이** 풀 수 있습니다.  
> 입력값은 각 문제에서 제시한 조건에 맞게 입력한다고 가정합니다.

**학습에 필요한 기본 문법**

```python
# 문자열 입력
name = input("이름: ")

# 정수 입력
age = int(input("나이: "))

# 실수 입력
height = float(input("키(cm): "))

# 변수로 계산한 결과 저장
next_age = age + 1

# 출력
print(name, "님의 내년 나이는", next_age, "세입니다.")
```

`input()`으로 입력받은 값은 **문자열**입니다. 숫자로 계산하려면 `int()` 또는 `float()`로 변환해야 합니다.

| 연산자  | 의미     | 예시            | 결과         |
| ---- | ------ | ------------- | ---------- |
| `+`  | 덧셈     | `10 + 3`      | `13`       |
| `-`  | 뺄셈     | `10 - 3`      | `7`        |
| `*`  | 곱셈     | `10 * 3`      | `30`       |
| `/`  | 나눗셈    | `10 / 3`      | 약 `3.3333` |
| `//` | 몫      | `10 // 3`     | `3`        |
| `%`  | 나머지    | `10 % 3`      | `1`        |
| `**` | 거듭제곱   | `10 ** 3`     | `1000`     |
| `==` | 같은지 비교 | `10 % 2 == 0` | `True`     |

양의 정수에서 `//`는 **몇 묶음을 만들 수 있는지**, `%`는 **묶음을 만들고 몇 개가 남는지** 계산할 때 사용할 수 있습니다.

```python
candy = 17
people = 5

each = candy // people
left = candy % people

print("한 사람당:", each)  # 3
print("남는 사탕:", left)  # 2
```

**실습 문제 1~8: 변수와 기본 연산**

**1. 자기소개와 내년 나이**

이름과 현재 나이를 키보드로 입력받으세요.

* 이름은 `name`, 나이는 `age`에 저장합니다.
* 내년 나이를 계산해 `next_age`에 저장합니다.
* 이름과 현재 나이, 내년 나이를 출력합니다.

입력 예: `민수`, `20`
출력 예: `민수 님은 현재 20 세이고, 내년에는 21 세입니다.`

**2. 두 수의 계산 결과**

두 정수를 입력받아 `a`, `b`에 저장하세요. 단, 두 번째 수에는 `0`을 입력하지 않습니다.

* 합, 차, 곱, 나눗셈 결과를 각각 다른 변수에 저장합니다.
* 네 가지 결과를 출력합니다.

입력 예: `12`, `5`
출력 예: `합: 17 / 차: 7 / 곱: 60 / 나눗셈: 2.4`

**3. 직사각형의 넓이와 둘레**

직사각형의 가로와 세로 길이를 양의 실수로 입력받으세요.

* 넓이와 둘레를 각각 변수에 저장합니다.
* 넓이와 둘레를 출력합니다.
* 넓이: `가로 × 세로`
* 둘레: `(가로 + 세로) × 2`

입력 예: `5`, `3`
출력 예: `넓이: 15.0 / 둘레: 16.0`

**4. 세 과목의 총점과 평균**

국어, 영어, 수학 점수를 정수로 입력받으세요.

* 세 점수를 각각 변수에 저장합니다.
* 총점은 `total`, 평균은 `average`에 저장합니다.
* 총점과 평균을 출력합니다.

입력 예: `80`, `90`, `100`
출력 예: `총점: 270 / 평균: 90.0`

**5. 상품 구매 후 남은 돈**

가지고 있는 돈, 상품 한 개의 가격, 구매할 개수를 정수로 입력받으세요.

* 총 구매 금액을 계산합니다.
* 구매 후 남은 돈을 계산합니다.
* 계산 결과를 각각 변수에 저장하고 출력합니다.
* 가지고 있는 돈은 총 구매 금액 이상으로 입력합니다.

입력 예: `10000`, `1200`, `3`
출력 예: `구매 금액: 3600 원 / 남은 돈: 6400 원`

**6. 할인된 상품 가격**

상품의 원래 가격과 할인율을 정수로 입력받으세요. 할인율은 `0~100` 사이입니다.

* 할인 금액을 계산합니다.
* 최종 결제 금액을 계산합니다.
* 할인 금액: `원래 가격 × 할인율 ÷ 100`

입력 예: `50000`, `20`
출력 예: `할인 금액: 10000.0 원 / 결제 금액: 40000.0 원`

**7. 두 변수의 값 교환**

두 정수를 입력받아 `a`, `b`에 저장하세요.

* 임시 변수 `temp`를 사용하여 두 변수의 값을 서로 바꿉니다.
* 교환 전과 교환 후의 값을 출력합니다.
* `a, b = b, a` 문법은 사용하지 않습니다.

입력 예: `10`, `20`
출력 예: `교환 전: 10 20 / 교환 후: 20 10`

**8. 정사각형과 정육면체**

양의 정수 하나를 입력받아 `length`에 저장하세요.

* 해당 길이를 한 변으로 하는 정사각형의 넓이를 계산합니다.
* 해당 길이를 한 모서리로 하는 정육면체의 부피를 계산합니다.
* 거듭제곱 연산자 `**`를 사용합니다.

입력 예: `3`
출력 예: `정사각형 넓이: 9 / 정육면체 부피: 27`

**실습 문제 9~20: 나머지 연산자 `%` 응용**

**9. 사탕을 똑같이 나누기**

사탕 개수와 학생 수를 정수로 입력받으세요. 사탕은 `0`개 이상, 학생은 `1`명 이상입니다.

* 학생 한 명이 받는 사탕 개수를 계산합니다.
* 나누어 주고 남는 사탕 개수를 계산합니다.

입력 예: `23`, `5`
출력 예: `한 명당: 4 개 / 남는 사탕: 3 개`

**10. 짝수인지 확인하기**

`0` 이상의 정수를 입력받으세요.

* `2`로 나눈 나머지를 변수에 저장합니다.
* 나머지가 `0`인지 비교해 짝수 여부를 출력합니다.
* 조건문 없이 `True` 또는 `False`로 출력합니다.

입력 예: `14`
출력 예: `2로 나눈 나머지: 0 / 짝수인가요? True`

**11. 원하는 수의 배수인지 확인하기**

양의 정수 `number`와 기준이 되는 양의 정수 `base`를 입력받으세요.

* `number`가 `base`의 배수인지 확인합니다.
* 조건문 없이 `True` 또는 `False`로 출력합니다.

입력 예: `42`, `7`
출력 예: `배수인가요? True`

**12. 초를 분과 초로 바꾸기**

`0` 이상의 전체 초를 정수로 입력받으세요.

* 몇 분 몇 초인지 계산합니다.
* `60초 = 1분`을 이용합니다.

입력 예: `185`
출력 예: `3 분 5 초`

**13. 초를 시·분·초로 바꾸기**

`0` 이상의 전체 초를 정수로 입력받으세요.

* 몇 시간 몇 분 몇 초인지 계산합니다.
* 분과 초는 각각 `0~59` 범위가 되도록 계산합니다.
* 시간은 `24` 이상이어도 됩니다.

입력 예: `7384`
출력 예: `2 시간 3 분 4 초`

**14. 거스름돈을 동전으로 나누기**

거스름돈을 **10원 단위의 양의 정수**로 입력받으세요.

* `500원`, `100원`, `50원`, `10원` 동전으로 나누어 줍니다.
* 큰 동전부터 최대한 사용합니다.
* 각 동전의 개수를 출력합니다.
* 동전을 계산할 때마다 남은 금액을 변수에 다시 저장합니다.

입력 예: `1260`
출력 예: `500원: 2 개 / 100원: 2 개 / 50원: 1 개 / 10원: 1 개`

**15. 세 자리 정수의 자릿수 분리**

`100~999` 사이의 정수를 입력받으세요.

* 백의 자리, 십의 자리, 일의 자리 숫자를 각각 변수에 저장합니다.
* 문자열 변환 없이 `//`와 `%`로 계산합니다.

입력 예: `583`
출력 예: `백의 자리: 5 / 십의 자리: 8 / 일의 자리: 3`

**16. 네 자리 정수의 각 자릿수 합**

`1000~9999` 사이의 정수를 입력받으세요.

* 천의 자리, 백의 자리, 십의 자리, 일의 자리를 각각 구합니다.
* 네 숫자의 합을 출력합니다.
* 문자열 변환 없이 계산합니다.

입력 예: `4729`
출력 예: `각 자릿수의 합: 22`

**17. 세 자리 정수 뒤집기**

`100~999` 사이의 정수를 입력받으세요.

* 백의 자리와 일의 자리의 위치를 바꾼 정수를 만듭니다.
* 문자열 변환 없이 계산합니다.
* 뒤집은 결과 앞에 오는 `0`은 표시하지 않아도 됩니다.

입력 예: `583` → 출력 예: `385`
입력 예: `120` → 출력 예: `21`

**18. 일정 시간이 지난 뒤의 시각**

현재 시각의 ‘시’를 `0~23` 범위의 정수로, 경과 시간을 `0` 이상의 정수로 입력받으세요. 분은 고려하지 않습니다.

* 경과 시간 이후의 시각을 `0~23` 범위로 출력합니다.
* 자정을 몇 번 지났는지도 출력합니다.

입력 예: `22`, `5`
출력 예: `시각: 3 시 / 자정을 지난 횟수: 1`

**19. 며칠 뒤의 요일 계산**

오늘의 요일 번호와 며칠 뒤인지 입력받으세요.

| 요일 | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
| -- | - | - | - | - | - | - | - |
| 번호 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |

* 오늘의 요일 번호는 `0~6`, 경과 일수는 `0` 이상입니다.
* 계산한 요일도 **번호로만 출력**합니다.
* 일요일 다음 날은 월요일 번호 `0`이 되어야 합니다.

입력 예: `5`, `10`
출력 예: `10 일 뒤의 요일 번호: 1`

**20. 원형 게임판에서 이동하기**

칸 번호가 **1번부터 마지막 번호까지** 붙은 원형 게임판이 있습니다. 마지막 칸에서 한 칸 이동하면 다시 `1번`입니다.

전체 칸 수, 현재 칸 번호, 이동할 칸 수를 입력받으세요.

* 전체 칸 수는 `2` 이상입니다.
* 현재 칸 번호는 `1~전체 칸 수`입니다.
* 이동할 칸 수는 `0` 이상입니다.
* 이동 후 칸 번호를 출력합니다.

입력 예: `8`, `7`, `4`
출력 예: `이동 후 위치: 3 번`

힌트: **현재 번호에서 `1`을 빼서 계산한 뒤, 마지막에 다시 `1`을 더하세요.**

---



print("이동 후 위치:", next_cell, "번")
```

번호가 `1`부터 시작하므로 `1`을 빼서 `0`부터 시작하는 값으로 바꿉니다. 나머지를 계산한 다음 `1`을 더하면 결과가 다시 `1~전체 칸 수` 범위가 됩니다.
