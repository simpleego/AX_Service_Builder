**15. 상품 코드 정리와 출고 처리하기**

상품 코드는 `분류-상품번호-색상` 구조입니다.

| 구분   | 예시    | 의미       |
| ---- | ----- | -------- |
| 분류   | `TOP` | 상의       |
| 상품번호 | `101` | 상품 식별 번호 |
| 색상   | `RED` | 빨강       |


1. `raw_code`의 양 끝 공백을 제거하고 대문자로 바꾸어 `code`에 저장하세요.

3. `parts`의 인덱싱으로 분류, 상품번호, 색상을 각각 출력하세요.
4. `count()`로 해당 상품의 출고 전 재고 수를 구하세요.
5. `index()`로 해당 상품이 처음 등장하는 위치를 구하세요.
6. 그 위치의 상품을 `pop()`으로 꺼내 `shipped`에 저장하세요.
7. 출고 상품, 출고 후 해당 상품의 재고 수, 전체 재고 목록을 출력하세요.

출력 예시:

```text

분류: TOP
상품번호: 101
색상: RED
출고 전 해당 상품 수: 2
출고 상품: TOP-101-RED
출고 후 해당 상품 수: 1
전체 재고: ['BAG-205-BLACK', 'TOP-101-RED', 'SHO-310-WHITE']
```
