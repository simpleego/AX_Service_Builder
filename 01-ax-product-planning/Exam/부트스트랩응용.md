# Bootstrap 부분 수정 실습

## 문제 1. 버튼의 일부 디자인 수정

다음은 Bootstrap의 기본 버튼입니다.

### 요구사항

`주문하기` 버튼을 다음과 같이 수정하세요.

* Bootstrap의 `btn`, `btn-primary` 기능은 유지합니다.
* 배경색을 `orange`로 변경합니다.
* 글자색을 `white`로 변경합니다.
* 테두리 색상을 `orange`로 변경합니다.
* 모서리를 `20px`만큼 둥글게 만듭니다.
* 버튼의 좌우 padding을 `30px`로 설정합니다.
* Bootstrap 원본 CSS는 수정하지 않습니다.
* 필요한 경우 새로운 사용자 클래스를 추가합니다.

### HTML

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Bootstrap 문제 1</title>

    <link
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
        rel="stylesheet"
    >

    <link rel="stylesheet" href="style.css">
</head>

<body>

<div class="container mt-5">

    <h2>상품 주문</h2>

    <button class="btn btn-primary">
        주문하기
    </button>

</div>

</body>
</html>
```

