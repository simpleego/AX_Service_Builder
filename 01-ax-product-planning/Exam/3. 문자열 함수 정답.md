## 수업에서 강조하면 좋은 핵심

이 단계에서는 학생들이 메서드를 외우는 것보다 **「문자열 → 메서드 호출 → 새로운 결과」**의 구조를 이해하도록 하는 것이 좋습니다.

```python
문자열.메서드()
```

예를 들어:

```python
name = "python"

print(name.upper())       # PYTHON
print(name.count("p"))    # 1
print(name.find("t"))     # 2
```

그리고 학생들에게 다음 세 가지 유형을 구분하도록 설명하면 이후 조건문 학습과 자연스럽게 연결됩니다.

```python
# ① 문자열을 만들어 주는 메서드
upper()
lower()
strip()
replace()

# ② 숫자를 알려 주는 메서드
count()
find()
index()

# ③ True / False를 알려 주는 메서드
isalpha()
isdigit()
startswith()
endswith()
```

특히 **`isalpha()`, `isdigit()`, `startswith()`, `endswith()`는 다음 단계에서 `if` 조건문을 배울 때 매우 중요**합니다. 지금은 `True`, `False`가 출력되는 것까지만 익히고, 이후 조건문에서 `"참이면 처리한다"`는 개념으로 확장하면 학습 흐름이 자연스럽습니다.
