# 정답

## 문제 1 정답

### HTML 수정

기존 버튼에 `my-btn` 클래스를 추가합니다.

```html
<button class="btn btn-primary my-btn">
    주문하기
</button>
```

### CSS

```css
.my-btn {
    background-color: orange;
    color: white;

    border-color: orange;

    border-radius: 20px;

    padding-left: 30px;
    padding-right: 30px;
}
```

### 핵심

```html
class="btn btn-primary my-btn"
```

역할은 다음과 같습니다.

```text
btn
 └─ Bootstrap 버튼 기본 기능

btn-primary
 └─ Bootstrap 기본 색상

my-btn
 └─ 사용자가 추가한 디자인
```

Bootstrap 클래스는 그대로 사용하고 필요한 부분만 사용자 클래스로 변경하는 방법입니다.

# 문제 2 정답

두 번째 카드에 `recommend-card` 클래스를 추가합니다.

### HTML 수정

```html
<div class="col-md-4">

    <div class="card p-3 recommend-card">

        <h3 class="card-title">
            추천 상품
        </h3>

        <p class="card-text">
            가격: 20,000원
        </p>

        <button class="btn btn-primary">
            구매
        </button>

    </div>

</div>
```

### CSS

```css
.recommend-card {
    border: 3px solid tomato;
    border-radius: 20px;
}

.recommend-card .card-title {
    color: tomato;
}
```

다음과 같이 작성하면 안 됩니다.

```css
.card {
    border: 3px solid tomato;
}
```

이 경우 모든 카드가 변경됩니다.

또한 다음 코드도 모든 카드의 제목을 변경합니다.

```css
.card-title {
    color: tomato;
}
```

따라서 특정 영역만 수정할 때는 다음처럼 범위를 제한하는 것이 좋습니다.

```css
.recommend-card .card-title {
    color: tomato;
}
```

# 문제 3 정답

### CSS

```css
.navbar-nav .login-menu {

    background-color: navy;

    color: white;

    border-radius: 10px;

    padding-left: 15px;
    padding-right: 15px;
}


.navbar-nav .login-menu:hover {

    background-color: orange;

    color: white;
}


@media (max-width: 768px) {

    .navbar-nav .login-menu {
        margin-top: 10px;
    }

}
```

### 핵심

Bootstrap에서는 다음과 같은 선택자가 이미 사용될 수 있습니다.

```css
.navbar-nav .nav-link
```

따라서 단순히

```css
.login-menu {
    color: white;
}
```

라고 작성했을 때 원하는 스타일이 적용되지 않는 경우가 있습니다.

이럴 때는 선택자를 좀 더 구체적으로 작성합니다.

```css
.navbar-nav .login-menu {
    color: white;
}
```

# 세 문제 핵심 정리

| 문제   | 핵심 내용                   |
| ---- | ----------------------- |
| 문제 1 | Bootstrap에 사용자 클래스 추가   |
| 문제 2 | 특정 컴포넌트만 선택하여 수정        |
| 문제 3 | 선택자 우선순위, hover, 반응형 수정 |

Bootstrap을 사용할 때 가장 기본적인 수정 방법은 다음과 같습니다.

```text
Bootstrap으로 기본 디자인 작성

        ↓

수정할 부분 확인

        ↓

사용자 클래스 추가

        ↓

사용자 CSS에서 필요한 부분만 수정
```

예를 들어 다음과 같이 작성합니다.

```html
<button class="btn btn-primary my-btn">
    주문하기
</button>
```

```text
btn btn-primary
      ↓
Bootstrap 디자인

my-btn
      ↓
사용자가 수정할 디자인
```

따라서 가능하면 다음과 같이 Bootstrap의 공통 클래스를 직접 수정하기보다는

```css
.btn {
}

.card {
}

.nav-link {
}
```

다음과 같이 별도의 사용자 클래스를 만들어 수정하는 것이 안전합니다.

```css
.my-btn {
}

.recommend-card {
}

.recommend-card .card-title {
}
