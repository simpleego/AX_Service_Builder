아래는 위의 **문자열 슬라이싱 10문제 정답**을 문제별로 정리한 것입니다.

## 문자열 슬라이싱 문제 정답

### 1번. 주민번호에서 생년월일 추출

```python
jumin = "990315-1ABCDEF"

print("출생년도 :", jumin[0:2])
print("출생월 :", jumin[2:4])
print("출생일 :", jumin[4:6])
```

실행 결과:

```text
출생년도 : 99
출생월 : 03
출생일 : 15
```

---

### 2번. 주민번호 앞부분 추출

```python
jumin = "020725-3ABCDEF"

print(jumin[0:6])
```

또는:

```python
print(jumin[:6])
```

실행 결과:

```text
020725
```

---

### 3번. 학번에서 입학년도 추출

```python
student = "2026CS015"

print("입학년도 :", student[:4])
```

실행 결과:

```text
입학년도 : 2026
```

---

### 4번. 학번에서 학과 코드 추출

```python

```

```text

```

---

### 5번. 학번에서 학생번호 추출

```python
student = "2026SW128"

print("학생번호 :", student[-3:])
```

실행 결과:

```text
학생번호 : 128
```

### 9번. 상품코드 분리하기

```python
product = "EL-TV-2026-0158"

print("대분류 :", product[0:2])
print("제품종류 :", product[3:5])
print("등록년도 :", product[6:10])
print("상품번호 :", product[-4:])
```

실행 결과:

```text
대분류 : EL
제품종류 : TV
등록년도 : 2026
상품번호 : 0158
```

---

### 10번. 전화번호에서 부분 문자열 추출

```python
phone = "010-1234-5678"

print("통신번호 :", phone[:3])
print("중간번호 :", phone[4:8])
print("마지막번호 :", phone[-4:])
```

실행 결과:

```text
통신번호 : 010
중간번호 : 1234
마지막번호 : 5678
```

### 전체 핵심 정답 요약

| 번호 | 정답 슬라이싱         | 추출 결과    |
| -- | --------------- | -------- |
| 1  | `jumin[0:2]`    | `99`     |
|    | `jumin[2:4]`    | `03`     |
|    | `jumin[4:6]`    | `15`     |
| 2  | `jumin[:6]`     | `020725` |
| 3  | `student[:4]`   | `2026`   |
| 4  | `student[4:6]`  | `AI`     |
| 5  | `student[-3:]`  | `128`    |
| 6  | `employee[:3]`  | `DEV`    |
| 7  | `employee[4:8]` | `2024`   |
| 8  | `employee[-3:]` | `315`    |
| 9  | `product[0:2]`  | `EL`     |
|    | `product[3:5]`  | `TV`     |
|    | `product[6:10]` | `2026`   |
|    | `product[-4:]`  | `0158`   |
| 10 | `phone[:3]`     | `010`    |
|    | `phone[4:8]`    | `1234`   |
|    | `phone[-4:]`    | `5678`   |

학생들에게는 특히 **`문자열[시작:끝]`에서 끝 위치는 포함되지 않는다**는 점과, `[-3:]`, `[-4:]`처럼 **뒤에서부터 추출하는 방법**을 같이 강조하면 좋습니다.
