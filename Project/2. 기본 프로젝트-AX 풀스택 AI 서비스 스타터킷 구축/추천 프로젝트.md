# AX 풀스택 2차 기본 프로젝트 추천 주제 10선

프로젝트 기간: 92시간 | 개발 방식: SDD 기반 AI 협업 개발 | 대상: 풀스택 기초과정 이수자

첨부된 「AI 풀스택 과정 세부 커리큘럼」과 「AX 프로젝트 목록」을 기준으로, 앞서 선정한 10개 프로젝트의 개요, 개발 목적, 핵심 기능, 개발 범위, 추천 이유 및 기대 학습 효과를 정리했습니다.

이번 2차 프로젝트는 React·FastAPI·관계형 DB를 활용하여 실제 비즈니스 서비스를 구현하는 데 중점을 둡니다. AI 도구는 개발 보조 수단으로 활용하되, LLM·RAG·LangChain 등 AI 서비스 기술은 개발 범위에서 제외합니다.

## 6. 최종 운영 제안

이번 2차 프로젝트에서는 팀별로 서로 다른 주제를 선택하되, 필수 기술 스택과 공통 품질 기준을 동일하게 적용하는 것이 좋습니다.

난이도가 낮은 도서 대여·가계부 프로젝트는 검색, 유효성 검증, 권한 관리 등 공통 기능의 완성도를 높이고, 쇼핑몰·구매 발주 프로젝트는 결제나 외부 시스템 연동 등 복잡한 기능을 제외하여 범위를 제한하는 방식이 적절합니다.

가장 추천하는 주제는 ① 팀 협업 관리, ⑥ 재고·판매 관리, ⑦ 고객 문의 티켓, ⑨ CRM입니다. 이 네 가지는 기업의 실질적인 업무를 다루면서도 92시간 안에 프론트엔드·백엔드·DB·인증·API 통합 역량을 고르게 평가하기 좋습니다.

그리고 원래 2차 프로젝트의 목표인 재사용 가능한 풀스택 스타터킷을 유지하려면, 각 팀이 만든 서비스에서 공통 인증, 사용자 관리, API 클라이언트, DB 연결, 예외 처리, 공통 UI 컴포넌트를 별도 모듈로 분리하도록 요구하는 것을 권장합니다. 이렇게 구성하면 3차 기업 프로젝트에서도 활용 가능한 실질적인 개발 기반을 확보할 수 있습니다.
