## 2. AI와 함께하는 명세 주도 개발(SDD)

<img width="1055" height="1491" alt="image" src="https://github.com/user-attachments/assets/01182fe6-e1e6-4126-805b-698ce1b4b62b" />

---


| 단계 | 개발자가 하는 일 | AI에 맡기는 일 | 산출물 |
|---|---|---|---|
| 명세 | 사용자 행동, 입력 제약, 정상·실패 조건, 우선순위 결정 | 요구사항 초안, 모호한 표현과 누락된 예외 제안 | 요구사항 ID와 인수 기준 |
| 설계·계획 | 화면·API·DB 계약과 역할 분담 확정 | ERD·OpenAPI 초안, 설계 선택지, 작업 분할 제안 | 화면 흐름, API 계약, 이슈 목록 |
| 구현 | 작업별 변경분을 검토하고 실행 결과 확인 | 승인된 명세에 맞춘 코드·테스트 초안 생성 | 요구사항 ID가 연결된 PR |
| 검증 | 브라우저·API·DB 결과 확인과 병합 결정 | 경계값·회귀 테스트 제안, 실패 로그 분석 | 테스트 결과와 인수 기록 |

예를 들어 **REQ-SUM-03 — 자신의 이력만 조회 가능**의 인수 테스트에는 사용자 B가 사용자 A의 이력 ID를 직접 요청했을 때 내용이 반환되지 않는지 포함합니다. 계약이 바뀌면 명세와 테스트를 갱신하고 관련 PR에 연결합니다.
