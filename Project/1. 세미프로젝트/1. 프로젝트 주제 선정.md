## 1. AI 부동산 시세·입지 분석 서비스

### 프로젝트 개념
사용자가 지역이나 아파트를 선택하면 실제 거래 데이터를 분석하여 **가격 추세 + 주변 환경 + AI 분석 리포트**를 제공하는 서비스입니다.

예를 들어,

> 광주광역시 북구 A아파트의 최근 3년 가격 흐름을 분석하고  
> 주변 학교·교통·상권 정보를 고려하여 지역 특징을 설명해주세요.

### 실제 데이터

국토교통부 실거래가 공개 API를 중심으로 다음 데이터를 결합할 수 있습니다.

**실거래가 + 아파트 정보 + 지역 인구 + 금리 + 교통/학교**

### 데이터 흐름

```text
공공데이터 API
   ↓
Python 수집
   ↓
Pandas 전처리
   ↓
PostgreSQL
   ↓
FastAPI
   ↓
┌───────────────┐
│ 통계/분석 API │
└───────────────┘
        ↓
LangChain + RAG
        ↓
LLM 부동산 분석
        ↓
React Dashboard
```

### 대시보드

- 지역별 평균 거래가격
- 평당 가격
- 월별/연도별 거래량
- 가격 상승률
- 아파트별 가격 비교
- 지도 기반 거래현황
- AI 분석 리포트

# 2. AI 전·월세 안전진단 서비스

최근 전세 관련 문제를 데이터 프로젝트로 바꾸기에 좋은 주제입니다.

사용자가

```text
보증금 : 2억원
아파트 매매가 : 2억5천만원
지역 : 광주광역시
```

등을 입력하면 데이터를 이용하여 위험 요소를 설명합니다.

### 핵심 분석

```text
전세가율
= 전세보증금 / 매매가격 × 100
```

여기에

- 최근 매매가격 변화
- 주변 전세 가격
- 거래량
- 지역별 전세가율

등을 결합합니다.

LLM은 단순히

```text
위험
안전
```

이라고 판단하는 것이 아니라,

> 주변 유사 아파트와 비교하면 해당 전세가격은 매매가격 대비 상대적으로 높은 편입니다.

처럼 **근거가 있는 설명**을 생성하게 합니다.

교육적으로는 **LLM에게 최종 결정을 맡기지 않고 데이터 분석 결과를 설명시키는 구조**를 가르치기 좋습니다.

```text
매출
```

## 첫 세미프로젝트에서는 범위를 이렇게 제한하는 것이 좋습니다

비전공자 비중이 높은 과정에서 첫 프로젝트부터 기능을 많이 넣으면 **데이터 수집 단계에서 프로젝트가 멈추는 경우**가 많습니다. 그래서 프로젝트 필수 요구사항을 다음 정도로 고정하는 방식을 권합니다.

```text
[필수]

1. 실제 데이터 소스       1~2개
2. 데이터 수집             API 또는 CSV
3. 데이터 전처리           Pandas
4. 데이터베이스            PostgreSQL
5. Backend                 FastAPI
6. Frontend                React
7. Dashboard               Chart
8. Vector DB               Chroma / FAISS 등
9. RAG                     LangChain
10. LLM                    OpenAI / Gemini 등
```

그리고 전체 구조를 모든 팀이 공통으로 사용하게 하면 좋습니다.

```text
                    외부 데이터
                         │
                         ▼
                 데이터 수집 Python
                         │
                         ▼
                  데이터 전처리
                    Pandas
                         │
             ┌───────────┴───────────┐
             ▼                       ▼
        PostgreSQL               Vector DB
       정형 데이터                문서 데이터
             │                       │
             │                       ▼
             │                     RAG
             │                       │
             └──────────┬────────────┘
                        ▼
                     FastAPI
                        │
                        ▼
                   LLM Service
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
          데이터 API          AI Insight
              │                   │
              └─────────┬─────────┘
                        ▼
                     React
                        │
                        ▼
                AI Dashboard
```
