**Claude Code 명령어는 입력 위치에 따라 두 가지로 구분합니다.**

- **일반 터미널**: `claude`, `claude -c`처럼 입력합니다.
- **Claude Code 실행 후 대화창**: `/help`, `/init`처럼 입력합니다.

## 1. 터미널 실행 명령어

프로젝트 폴더로 이동한 다음 실행합니다. 아래는 Windows PowerShell 예시입니다.

```powershell
cd C:\ai_human\my_project
claude
```

| 명령어 | 기능 |
|---|---|
| `claude` | 대화형으로 시작 |
| `claude "프로젝트 구조를 설명해줘"` | 첫 요청과 함께 시작 |
| `claude -p "main.py를 설명해줘"` | 요청을 처리하고 종료 |
| `claude -c` | 현재 폴더의 가장 최근 대화 이어가기 |
| `claude -r` | 이전 대화를 선택하여 재개 |
| `claude -r "성적관리"` | 이름이 지정된 대화 재개 |
| `claude --model sonnet` | 사용할 모델을 지정하여 시작 |
| `claude --permission-mode plan` | 계획 모드로 시작 |
| `claude --add-dir ../shared` | 추가 폴더에 접근 허용 |
| `claude --help` | 실행 옵션 확인 |
| `claude --version` | 설치 버전 확인 |
| `claude update` | 최신 버전으로 업데이트 |
| `claude doctor` | 설치와 설정 상태 진단 |
| `claude auth login` | 로그인 |
| `claude auth status --text` | 로그인 상태 확인 |
| `claude auth logout` | 로그아웃 |

**`-c`는 최근 대화, `-r`은 선택한 대화를 이어가는 용도입니다.** `-p`는 대화창을 계속 열어두지 않는 방식입니다. [Claude Code Docs](https://code.claude.com/docs/en/cli-reference?utm_source=chatgpt.com)

## 2. 대화창 슬래시 명령어

`claude`를 실행한 뒤 입력합니다. **`/`만 입력하면 현재 환경에서 사용할 수 있는 명령어 목록이 표시됩니다.** 버전·요금제·환경에 따라 목록이 다를 수 있습니다.

| 명령어 | 기능 | 사용하는 상황 |
|---|---|---|
| `/help` | 도움말 | 사용법 확인 |
| `/init` | 기본 `CLAUDE.md` 생성 | 프로젝트 시작 |
| `/memory` | 프로젝트 지침 확인·편집 | 개발 규칙 정리 |
| `/plan` | 계획 모드로 전환 | 구현 전 설계 |
| `/model` | 모델 선택 | 모델 변경 |
| `/permissions` | 도구 실행 승인 규칙 관리 | 권한 설정 |
| `/config` | 설정 화면 | 환경 조정 |
| `/context` | 컨텍스트 사용 현황 | 대화가 길어졌을 때 |
| `/compact` | 기존 대화를 요약하여 공간 확보 | 작업 이어가기 |
| `/clear` | 빈 컨텍스트로 새 대화 시작 | 작업 주제 변경 |
| `/resume` | 이전 대화 재개 | 중단한 작업 복귀 |
| `/diff` | 변경 내용 확인 | 수정 결과 검토 |
| `/rewind` | 체크포인트 복원 메뉴 | 이전 상태로 돌아가기 |
| `/mcp` | MCP 연결 관리 | 외부 도구 연동 |
| `/doctor` | 환경 점검과 문제 해결 | 실행 문제 진단 |
| `/exit` | 종료 | 작업 마무리 |

예를 들어 요약할 때 유지할 내용을 지정할 수 있습니다.

```text
/compact DB 테이블 구조, API 목록, 남은 작업을 중심으로 요약해줘
```

**`/compact`는 요약하면서 계속하고, `/clear`는 새 대화를 시작합니다.** `/clear`가 프로젝트 파일을 삭제하는 것은 아닙니다. [Claude Code Docs](https://code.claude.com/docs/en/commands?utm_source=chatgpt.com)

## 3. 파일 참조와 셸 명령 실행

### `@` — 파일을 지정하여 질문

```text
@main.py 이 파일의 API를 설명해줘
```

```text
@frontend/index.html @backend/main.py
프론트엔드와 백엔드의 요청 주소와 데이터 형식이 일치하는지 확인해줘
```

### `!` — 셸 명령 직접 실행

```text
!git status
```

```text
!python --version
```

```text
!pytest
```

`!`로 실행한 명령의 결과는 대화에 추가됩니다. `@`는 파일 경로 자동완성을 제공합니다. [Claude Code Docs](https://code.claude.com/docs/en/interactive-mode?utm_source=chatgpt.com)

## 4. 주요 단축키

| 단축키 | 기능 |
|---|---|
| `Esc` | 현재 응답·작업 중단 또는 메뉴 닫기 |
| `Ctrl + C` | 실행 중인 작업 중단 또는 입력 지우기 |
| `Shift + Tab` | 권한 모드 전환 |
| `Ctrl + O` | 상세 실행 기록 보기 |
| `Ctrl + R` | 이전 입력 검색 |
| `↑` / `↓` | 이전 입력 탐색 |
| `Ctrl + J` | 입력 중 줄바꿈 |
| 빈 입력에서 `Esc` 두 번 | 되돌리기 메뉴 |
| 빈 입력에서 `?` | 단축키 도움말 |

**작업 중단은 이미 완료된 파일 수정을 자동으로 취소하지 않습니다.** 되돌리려면 `/rewind`에서 복원 대상을 확인합니다. 단축키 동작은 터미널에 따라 달라질 수 있습니다. [Claude Code Docs](https://code.claude.com/docs/en/interactive-mode?utm_source=chatgpt.com)

## 5. 프로젝트 사용 예시

FastAPI 성적관리 프로젝트를 시작한다면 다음 순서로 활용할 수 있습니다.

**① 일반 터미널에서 시작**

```powershell
cd C:\ai_human\student_scores
claude
```

**② 대화창에서 프로젝트 지침 생성**

```text
/init
```

생성된 `CLAUDE.md`를 확인하고 다음과 같은 규칙을 추가합니다.

```text
이 프로젝트의 개발 규칙을 CLAUDE.md에 반영해줘.

- 백엔드는 FastAPI를 사용한다.
- 프론트엔드는 HTML, CSS, 바닐라 JavaScript를 사용한다.
- DB는 MariaDB를 사용한다.
- 학생별 총점, 평균, 학점은 Python에서 계산한다.
- 과목별 통계는 SQL 집계함수로 계산한다.
```

**③ 구현 전 계획 수립**

```text
/plan
```

```text
학생 성적 등록, 조회, 수정, 삭제 기능의 구현 계획을 작성해줘.
DB 구조, API 목록, 화면 구성을 먼저 설명해줘.
```

**④ 계획 검토 후 구현 요청**

```text
검토한 계획대로 학생 성적 등록 기능부터 구현해줘.
```

**⑤ 수정 내용 확인**

```text
/diff
```

```text
입력값 검증과 프론트엔드 연동을 확인하고 테스트 결과를 설명해줘.
```

**⑥ 종료 후 다음 작업에서 재개**

```text
/exit
```

다음에는 일반 터미널에서 실행합니다.

```powershell
claude -c
```

자주 사용하는 명령부터 익힌다면 **`claude`, `claude -c`, `/init`, `/plan`, `/diff`, `/compact`, `/clear`**를 먼저 기억하면 됩니다.
