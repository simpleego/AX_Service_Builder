# 검증 기록

검증일: 2026-10-30.

## 통과

- GitHub의 고정 커밋 트리에서 chapter_08~chapter_15의 JSX 13개를 확인하고 모두 읽었다.
- 원본 package.json과 src/index.js를 확인해 의존성과 기본 렌더링 대상 Blocks를 대조했다.
- 추가 예제의 JS/JSX 10개 파일을 로컬 @babel/parser로 파싱했다. 문법 오류 없음.
- Node.js assert로 온도 함수의 변환 3건, 잘못된 입력 6건, 음수 소수 1건, 끓는점 미만 경계값 1건을 확인했다. 총 11건 통과.
- 원본과 추가 예제를 별도 디렉터리로 구분했다. 원본은 변경하지 않았다.
- Markdown 내부의 로컬 파일 링크 6개가 존재하는지 확인했다. 통합 강의안은 506줄이다.
- 의존성 75개 설치 및 package-lock.json 생성 완료.
- Vite 프로덕션 빌드 성공: 모듈 48개, JS 약 185.21kB / gzip 약 62.63kB. 결과는 examples/dist에 있다.

## 실행 범위와 제한

Node.js v22.23.4 환경에서 검사했다. 첫 설치가 지연되어 중단했고 오프라인 재시도는 ENOTCACHED로 실패했으나, 네트워크 재시도는 정상 완료되었다. 첫 빌드는 Windows sandbox의 realpath EPERM 오류로 실패했고 같은 빌드를 권한이 허용된 환경에서 재실행해 성공했다. 문법 파싱과 빌드는 브라우저 조작 검증을 대신하지 않는다.

브라우저에서 클릭·키보드·화면 폭 변경을 통한 전체 UI 검증은 수행하지 않았다. 수업 전 examples/README.md와 강사운영안.md의 동작 시나리오를 실행한다.
