    같은 이미지, 여러 컨테이너

    이미지는 그대로 두고 docker run을 할 때마다 그 위에 얇은 쓰기 층을 얹어 컨테이너를 만듭니다. 그래서 simple-was를 지우고 다시 만들어도 이미지는 다시 받지 않습니다. 이미지 목록은 docker images, 컨테이너 목록은 docker ps -a로 따로 봅니다.

    컨테이너 vs VM

    VM은 집을 따로 짓는 것(커널까지 따로), 컨테이너는 한 건물 안 칸막이 사무실(커널 공유)입니다. docker run --rm ubuntu:24.04 uname -r이 호스트와 같은 커널 버전을 보여 주는 이유입니다.

    격리를 여는 옵션

    -p 창구 하나, -v 폴더 공유, --network 이름 같은 네트워크끼리 대화, --network host 네트워크 격리 해제, --privileged 대부분 해제(비권장).

    포트는 바깥 창구와 안쪽 번호가 다르다

    누가어디로 접속거치는 길도착
    Windows 브라우저localhost:8001WSL 전달 → -p 8001:8000simple-was :8000
    HeidiSQL127.0.0.1:3307WSL 전달 → -p 3307:3306simple-mysql :3306
    simple-was 컨테이너simple-mysql:3306simple-net 안에서 직접 (창구 안 거침)simple-mysql :3306
    학생 VirtualBoxVM_IP:8001, VM_IP:3307브리지 또는 NAT 포트 포워딩같음

    호스트 포트 하나에는 컨테이너 하나만 연결됩니다. 그래서 학생마다 8000 + 번호로 포트를 나눠 줍니다.
