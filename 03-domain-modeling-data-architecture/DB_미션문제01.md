# SQL 기초 응용문제 20문제

## 1단계 — SELECT / WHERE

### 문제 1. 특정 가격 이상의 도서 조회 ★

가격이 **10,000원 이상인 도서**의 도서번호, 도서명, 출판사, 가격을 출력하시오.

출력 컬럼:

```text

```

```sql
FROM
WHERE
```

# 5단계 — GROUP BY + HAVING

### 문제 14. 여러 번 주문한 고객 찾기 ★★★

도서를 **2번 이상 주문한 고객**의 고객번호와 주문 횟수를 출력하시오.

결과:

```text
custid | 주문횟수
```

사용 예상 문법:

```sql
GROUP BY
HAVING
COUNT()
```

교재에서는 `WHERE`가 그룹화 이전의 행을 제한하고 `HAVING`이 그룹화 이후 결과를 제한하는 형태로 사용됩니다. 3장 강의_SQL 기초

- 총 구매금액을 출력한다.
- **2권 이상 구매한 고객만 출력한다.**
- **총 구매금액이 20,000원 이상인 고객만 출력한다.**
- 총 구매금액이 높은 고객부터 출력한다.

출력 형태:

```text
고객이름 | 주문횟수 | 총구매금액
```
