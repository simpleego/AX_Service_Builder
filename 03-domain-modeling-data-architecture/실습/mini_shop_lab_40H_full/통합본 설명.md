#  기존 키트에 Alembic + FastAPI 연동 코드를 추가해서 전체 재패키징

### 📥 최종 통합본 다운로드
**mini_shop_lab_40H_full.zip - Alembic + FastAPI 포함**

#### 새로 추가된 파일
- `alembic.ini` / `alembic/env.py` / `alembic/script.py.mako` - `.env`의 `DATABASE_URL`을 읽어서 자동 마이그레이션
- `app/database.py` - `SessionLocal`, `get_db()` 커넥션 풀 설정
- `app/main.py` - FastAPI 메인 ( `/docs` Swagger 자동 생성 )
- `app/schemas.py` - Pydantic 응답 모델
- `app/crud.py` - Day4/5 핵심 로직: 커서 페이징, `FOR UPDATE` 재고 차감, 장바구니→주문 트랜잭션
- `requirements.txt` / `.env.example` / `run.sh` - 원클릭 실행 스크립트

#### 수업에서 이렇게 실행 (Day3 오후~Day5)

```bash
# 1. 설치
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # DATABASE_URL 수정

# 2. Alembic 최초 마이그레이션
alembic revision --autogenerate -m "init mini shop"
alembic upgrade head

# 3. 10만건 시드
python seed_faker_100k.py --total 100000 --reset --users 5000 --orders 20000

# 4. FastAPI 실행
uvicorn app.main:app --reload --port 8000
# http://localhost:8000/docs 접속
```

#### FastAPI에서 바로 검증 가능한 엔드포인트

- `GET /products?cursor=50000&limit=20` - Day5 커서 페이징 vs OFFSET 성능 비교
- `POST /carts/{user_id}/items` - 장바구니 담기
- `POST /orders` - `SELECT ... FOR UPDATE` 로 재고 동시성 제어 실습
- `GET /stats/best-sellers` - Day4 베스트셀러 집계 쿼리
- `GET /health/db` / `/admin/alembic/current` - DB 연결 및 마이그레이션 버전 확인

이 상태면 Day3에 ORM 만들고 Day5까지 FastAPI에서 바로 부하테스트까지 이어갈 수 있습니다.
