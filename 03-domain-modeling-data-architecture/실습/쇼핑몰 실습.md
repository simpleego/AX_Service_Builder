## 사용법

1.  **Day2:** `day2_starter.dbml`로 시작 → 학생들이 Cart/Order/Payment 붙여서 `day2_full.dbml` 형태로 확장
2.  **Day3:** 
    ```bash
    pip install sqlalchemy pymysql alembic faker tqdm
    # starter로 코딩 후 정답 비교
    python seed_faker_100k.py --reset --total 100000 --users 5000 --orders 20000
    ```
    - `--total 10000`으로 줄이면 1만건으로 테스트 가능
    - MySQL이면 `DATABASE_URL`만 본인 계정으로 수정
3.  **Day4:** `day4_queries.sql` 8개를 AI에게 "이 쿼리 검증해줘" 시키고, 학생이 직접 오류 찾기
4.  **Day5:** `day5_index_lab.sql`에서 `EXPLAIN ANALYZE` 전/후 비교 → OFFSET vs 커서 페이징 체감
