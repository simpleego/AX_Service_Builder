# 컴포넌트 사용법

`Counter`를 쓰려면 먼저 `Counter.jsx`에서 컴포넌트를 내보내고(`export`), 상위 컴포넌트 `App.jsx`에서 가져와(`import`) 화면에 그리면 됩니다.

## 1. Counter.jsx: `export default` 한 줄 추가

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0); // [현재값, 변경함수] = useState(초기값)

  return (
    <div>
      <p>현재 값: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      {/* 이전 값을 기준으로 바꿀 때는 함수형 업데이트가 안전합니다 */}
      <button onClick={() => setCount(prev => prev - 1)}>-1</button>
    </div>
  );
}

export default Counter; // 다른 파일에서 쓸 수 있게 내보냅니다
```

## 2. App.jsx: Counter를 사용하는 상위 컴포넌트

```jsx
import Counter from './Counter'; // 같은 폴더의 Counter.jsx를 가져옵니다

function App() {
  return (
    <div>
      <h1>카운터 예제</h1>

      <h2>첫 번째 카운터</h2>
      <Counter />

      <h2>두 번째 카운터</h2>
      <Counter />
    </div>
  );
}

export default App;
```

> 💡 `<Counter />`를 두 번 쓰면 **각자 따로 state를 가집니다.** 첫 번째 카운터의 +1을 눌러도 두 번째 값은 바뀌지 않습니다.

## 3. main.jsx: App을 화면에 붙이기 (Vite 프로젝트 기준)

```jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

## 파일 구조

```
src/
├── main.jsx      ← App을 index.html의 #root에 붙임
├── App.jsx       ← 상위 컴포넌트 (Counter를 사용)
└── Counter.jsx   ← 하위 컴포넌트
```

## 실행 흐름

```
main.jsx → <App /> 렌더링 → <Counter /> 두 개 렌더링
                                 ↓ 버튼 클릭
                       해당 Counter의 setCount 실행
                                 ↓
                       그 Counter만 다시 렌더링
```
