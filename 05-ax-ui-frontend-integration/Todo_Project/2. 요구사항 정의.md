## 기능 요구사항 정의(Functional Requirements)

(FR)은 시스템이 무엇을 해야 하는가를 정의한다.   
- "사용자가할 일을 추가할 수 있다"처럼 시스템이 반드시 수행해야 하는 동작을 구체적으로 나열하는 것이다.   
- 기술 스택 선정과 요구사항 정의가 선행되어야 나머지 설계와 구현 단계에서 흔들림 없이 진행할 수 있다.  
- 무엇을 만들지 명확하지 않은 상태에서 코드를 작성하면 방향이 틀어지거나 중간에 설계를 뒤엎는 상황이 생기기 때문이다.
