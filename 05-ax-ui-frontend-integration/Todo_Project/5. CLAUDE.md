# Tika 프로젝트의 PRD를 작성해줘. 다음 정보를 포함해야 해:

1. **제품 개요**: 티켓 기반 칸반 보드 TODO 앱
2. **MVP 범위**: 단일 사용자, 고정 4컬럼(Backlog/TODO/In Progress/Done), 티켓 CRUD, 드래그 앤 드롭, 계획시작일, 시작일, 계획종료일, 종료일

5. **핵심 기능 목록**: REQUIREMENTS.md의 FR-001~008과 대응하는 기능 설명
6. **기술 스택 요약표**: 선정 이유 포함(CLAUDE.md 참고)
7. **와이어프레임 참고**: 좌측 Backlog 사이드바 + 우측 3컬럼 보드 Swimlane 레이아웃
