# LLM 서비스 엔지니어링 & RAG

LLM API를 서비스에 통합하고, 문서 기반 RAG와 도구 호출을 활용한 AI 기능을 설계·구현하는 과정을 정리한 학습 자료입니다. 교과목 계획은 **56시간(7일)** 기준입니다.

## 학습 목표

- LLM API 호출 구조와 토큰·비용 최적화 방법 이해
- LangChain을 활용한 RAG 파이프라인 구성
- 문서 청킹, 임베딩, 벡터 DB 검색 및 검색 품질 평가
- Function Calling과 Tool Use를 적용한 에이전트 설계
- SSE 기반 스트리밍 응답을 서비스에 통합
- ReAct 및 멀티 에이전트 프레임워크의 특징 비교

## 권장 학습 순서

1. 기본 문서에서 LLM API 통합, 토큰 최적화와 RAG 구성 요소를 학습합니다.
2. 청킹과 벡터 검색을 익히고, 평가 질문을 사용해 검색 품질을 비교합니다.
3. Function Calling과 스트리밍을 적용해 서비스 흐름을 완성합니다.
4. ReAct 및 멀티 에이전트 자료를 읽고 에이전트 구성 방식과 사용 목적을 비교합니다.
5. 예제 자료를 참고해 과제와 도메인 RAG 챗봇 프로젝트를 진행합니다.
