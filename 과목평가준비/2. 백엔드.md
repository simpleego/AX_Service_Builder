# 2. 백엔드 Backend

### 핵심 정의

**백엔드(Backend)**는 웹 서비스에서

> 사용자의 요청을 처리하고 데이터와 비즈니스 로직을 관리하는 서버 측 영역

입니다. :chatgpt-content-reference{index="2"}

간단히 표현하면:

```text
사용자
  ↓ 요청
프론트엔드
  ↓
백엔드
  ↓
데이터 처리 / 비즈니스 로직 / DB
  ↓
응답
```

### 시험용 문장

> 백엔드는 사용자 요청을 처리하고 데이터베이스와 연결하며 서비스의 비즈니스 로직을 수행하는 서버 측 영역이다.

# 3. FastAPI의 기본 구조

가장 기본적인 FastAPI 코드는 다음 구조를 기억하면 됩니다.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello"}
```

시험에서 가장 중요한 부분은

```python
@app.get("/")
```

입니다.

의미는:

```text
@app.get("/")
   │     └── URL 경로
   └──────── GET 요청
```

즉,

> `/` 주소로 GET 요청이 들어오면 아래 함수를 실행하라는 의미

입니다.

### 반드시 암기

```python
@app.get("/")
```

# 4. JSON

웹에서 클라이언트와 서버가 데이터를 주고받을 때 많이 사용하는 형식입니다.

예:

```json
{
    "name": "Kim",
    "age": 20

```

Python/FastAPI에서는

```python
return {
    "name": "Kim",
    "age": 20
```

와 같이 반환하면 JSON 형태로 클라이언트에게 전달할 수 있습니다.

시험에서는 JSON을 MP3, PNG, EXE와 구별할 수 있어야 합니다. :chatgpt-content-reference{index="6"}

### 암기

```text
웹 데이터 교환 → JSON
```

# 6. Pydantic 모델

FastAPI에서 요청 데이터를 정의하고 검증할 때 대표적으로 사용하는 것이 **Pydantic 모델**입니다. :chatgpt-content-reference{index="9"}

예:

```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int
```

클라이언트가

```json
{
    "name": "홍길동",
    "age": 25
}
```

처럼 데이터를 보내면 FastAPI/Pydantic이 데이터 구조를 확인합니다.

예를 들어

```json
{
    "name": "홍길동",
    "age": "스물다섯"
}
```

처럼 잘못된 값이 들어오는 상황을 검증하는 데 활용할 수 있습니다.

### 시험 핵심

```text
요청 데이터 구조 정의
        +
입력 데이터 검증
        ↓
    Pydantic
```

회원가입 데이터의 이름·이메일 등의 형식이나 필수 입력 여부를 검사하는 방법도 Pydantic 모델을 사용하는 것입니다. :chatgpt-content-reference{index="10"}

# 7. HTTP 상태 코드

이번 시험에서는 다음 정도를 구별하면 됩니다.

| 코드 | 의미 | 시험에서의 상황 |
|---:|---|---|
| **200** | 정상 처리 | 요청 성공 |
| **404** | 찾을 수 없음 | 상품 번호 없음 |
| **500** | 서버 오류 | 서버 내부 오류 |
| **301** | 이동 관련 코드 | 정상 처리/데이터 없음과 구별 |

파일에서는 **정상적으로 데이터를 찾고 처리한 경우 200**을 묻고 있습니다. :chatgpt-content-reference{index="11"}

상품번호가 존재하지 않는 경우에는:

```text
상품 요청
   ↓
상품 검색
   ↓
상품 없음
   ↓
404
```

입니다. :chatgpt-content-reference{index="12"}

### 시험 직전 암기

```text
200 = 성공
404 = 없음
500 = 서버 오류
```

# 8. 예외 처리

프로그램 실행 중 예상하지 못한 오류가 발생할 수 있습니다.

그때 프로그램이 무조건 종료되도록 하는 것이 아니라 오류 상황을 처리하는 것을 **예외 처리(Exception Handling)**라고 합니다. :chatgpt-content-reference{index="13"}

Python에서는 대표적으로:

```python
try:
    result = 10 / 0

except Exception as e:
    print("오류 발생:", e)
```

### 기억하기

```text
정상 상황 → 일반 처리

오류 상황 → 예외 처리
```

# 9. Path Parameter

다음 URL을 보겠습니다.

```text
/products/10
```

여기서

```text
/products/10
          ↑
```

`10`은 **Path Parameter(경로 매개변수)**입니다. :chatgpt-content-reference{index="14"}

FastAPI에서는:

```python
@app.get("/products/{product_id}")
def get_product(product_id: int):
    return {"product_id": product_id}
```

사용자가

```text
/products/10
```

을 요청하면

```python
product_id = 10
```

이 됩니다.

### 시험 암기

```text
/products/10

10 = Path Parameter
```

# 10. API Key와 `.env`

이번 시험에서 중요도가 높은 보안 내용입니다.

다음과 같이 작성하면 좋지 않습니다.

```python
API_KEY = "abcd123456789"
```

왜냐하면 소스코드를 GitHub에 올릴 경우 API Key가 노출될 수 있기 때문입니다.

시험에서 제시하는 적절한 방식은 **환경변수 또는 `.env` 파일로 분리하여 관리하는 것**입니다. :chatgpt-content-reference{index="15"}

15번에서도 같은 내용을 다시 묻고 있습니다. :chatgpt-content-reference{index="16"}

예:

`.env`

```text
API_KEY=abcd123456789
```

Python:

```python
import os
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("API_KEY")
```

### 시험 핵심

```text
API Key
  ↓
코드에 직접 작성 X
  ↓
.env / 환경변수
```

# 11. AI가 생성한 코드는 반드시 검증

이번 평가의 **AI-Augmented** 부분에서 가장 중요한 개념입니다.

AI가 FastAPI 코드를 만들어 주었다고 해서

```text
AI 생성
 ↓
바로 배포
```

하면 안 됩니다.

올바른 과정은:

```text
AI 코드 생성
    ↓
코드 이해
    ↓
실행
    ↓
테스트
    ↓
오류 확인
    ↓
보안 확인
    ↓
예외 처리 확인
    ↓
수정
    ↓
배포
```

시험에서는 **동작·보안·예외 처리를 직접 확인한 뒤 사용해야 한다**는 태도를 강조합니다. :chatgpt-content-reference{index="17"}

AI 코드에서 오류가 발생했을 때도 무시하거나 파일을 삭제할 것이 아니라 **코드의 의미와 오류 발생 부분을 확인하고 테스트해야 합니다.** :chatgpt-content-reference{index="18"}

# 12. API의 기본 처리 흐름 ★중요

19번 서술형에서 직접 설명해야 하는 내용입니다.

문제에서는 **할 일 추가 API**를 예로 들고 있습니다. :chatgpt-content-reference{index="19"}

반드시 다음 순서를 기억하세요.

```text
① 요청 수신
      ↓
② 입력 검증
      ↓
③ 처리 / 저장
      ↓
④ 응답
```

예를 들어 사용자가:

```json
{
    "title": "FastAPI 공부"
}
```

를 서버에 보낸다면

### ① 요청 수신

```text
클라이언트가 title을 서버로 전송
```

### ② 입력 검증

```text
title이 존재하는지 확인
올바른 데이터인지 확인
```

### ③ 처리 / 저장

```text
할 일 데이터를 처리
필요하면 DB에 저장
```

### ④ 응답

```json
{
    "message": "할 일이 추가되었습니다."
}
```

### 시험 답안 형태

> 클라이언트가 할 일 제목을 서버에 요청하면 서버는 요청을 수신한다. 이후 입력값이 올바른지 검증하고, 정상적인 데이터이면 필요한 처리를 수행하거나 저장한다. 마지막으로 처리 결과를 JSON 형태 등의 응답으로 클라이언트에게 반환한다.

# 13. 로그인 코드를 배포하기 전 확인할 내용

문제는 **AI가 생성한 FastAPI 로그인 코드를 바로 배포하지 말고 무엇을 확인해야 하는지 3가지 이상** 묻습니다. :chatgpt-content-reference{index="20"}

첨부 평가의 앞 문항에서 강조한 내용을 연결하면 다음처럼 준비하면 됩니다.

### 답안 예시

```text
1. 로그인 기능이 정상적으로 동작하는지 테스트한다.
2. 잘못된 입력에 대한 검증이 이루어지는지 확인한다.
3. 오류 발생 시 예외 처리가 적절한지 확인한다.
4. API Key 등의 중요 정보가 코드에 노출되어 있지 않은지 확인한다.
5. 코드의 의미와 처리 과정을 개발자가 직접 확인한다.
```

시험에서는 이 중 **3개 이상을 정확하게 서술**하는 형태로 준비하는 것이 좋습니다.

```text
Backend
→ 사용자 요청 + 데이터 + 비즈니스 로직

FastAPI GET
→ @app.get("/")

웹 데이터
→ JSON

데이터 검증
→ Pydantic

200
→ 정상

404
→ 데이터 없음
```
